🔢 Frequency Based

HashMap mein har element ki count/frequency store karo. Counting, majority, top-k type problems ke liye best.

O(n) time O(n) space Count problems
📊
Core Concept
🇬🇧 English
Traverse the array/string once and store element → count in a HashMap. Then query the map in O(1) to answer frequency questions. Used when you need to count occurrences, find majority elements, or detect duplicates.
🇮🇳 Hinglish
Array ya string ek baar traverse karo aur element → count map mein store karo. Phir O(1) mein koi bhi frequency query answer kar sakte ho. Jab bhi "count karo", "kitni baar aaya", "majority element" — seedha frequency map!

🔵 C++ · Two Sum
vector<int> twoSum(vector<int>& nums, int target) {
    unordered_map<int,int> mp; // value → index

    for (int i = 0; i < nums.size(); i++) {
        int need = target - nums[i];

        if (mp.count(need))              // complement map mein hai?
            return {mp[need], i};        // pair mil gaya!

        mp[nums[i]] = i;                 // nahi mila → store karo
    }
    return {};
}
💡 Key insight: mp.count(key) O(1) lookup hai. Pehle check karo, phir insert — warna same index pair return ho sakta hai (e.g. target=4, num=2).

🔵 C++ · Top K Frequent (Bucket Sort)
vector<int> topKFrequent(vector<int>& nums, int k) {
    int n = nums.size();
    unordered_map<int,int> freq;
    for (int x : nums) freq[x]++;       // Step 1: frequency count

    // Step 2: Bucket sort — index = frequency
    vector<vector<int>> bucket(n + 1);
    for (auto& [num, cnt] : freq)
        bucket[cnt].push_back(num);

    // Step 3: Right se collect karo top k
    vector<int> result;
    for (int i = n; i >= 1 && result.size() < k; i--)
        for (int x : bucket[i])
            result.push_back(x);

    return result;
}

// Alternative: Min-Heap approach O(n log k)
vector<int> topKFreqHeap(vector<int>& nums, int k) {
    unordered_map<int,int> freq;
    for (int x : nums) freq[x]++;

    // min-heap of size k: {count, num}
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    for (auto& [num, cnt] : freq) {
        pq.push({cnt, num});
        if (pq.size() > k) pq.pop(); // k se zyada nahi rakhna
    }
    vector<int> res;
    while (!pq.empty()) { res.push_back(pq.top().second); pq.pop(); }
    return res;
}
💡 Bucket Sort approach O(n) hai — heap se better! Max frequency n se zyada nahi ho sakti, isliye bucket array ka size n+1 enough hai.
Problem 3 — Valid Anagram
🔤
Valid AnagramLeetCode 242
🇬🇧 Intuition
Two strings are anagrams if they have exactly the same character frequencies. Build frequency map for string s, then decrement for each char in t. If all counts are 0 → anagram!
🇮🇳 Hinglish
Do strings anagram hain agar dono mein same characters same frequency pe hain. s ke liye map mein count badhao (+1), t ke liye ghatao (-1). Agar sab counts 0 ho gaye → anagram hai!
🔵 C++ · Valid Anagram
bool isAnagram(string s, string t) {
    if (s.size() != t.size()) return false;

    int freq[26] = {0};               // 26 letters ka array
    for (char c : s) freq[c - 'a']++;  // s ke chars count badhao
    for (char c : t) freq[c - 'a']--;  // t ke chars count ghatao

    for (int x : freq)
        if (x != 0) return false;       // koi bhi non-zero → anagram nahi

    return true;
}

// Unicode chars ke liye (unicode strings): use unordered_map
bool isAnagramUnicode(string s, string t) {
    unordered_map<char,int> mp;
    for (char c : s) mp[c]++;
    for (char c : t) mp[c]--;
    for (auto& [ch, cnt] : mp)
        if (cnt != 0) return false;
    return true;
}
💡 Sirf lowercase letters ke liye int[26] array use karo — unordered_map se 3-4x faster hai aur O(1) space (26 fixed).

🔍 Lookup Based

HashMap ko O(1) lookup table ki tarah use karo — pehle se dekhe elements fast retrieve karo.

O(1) lookup Seen-before check Index storage
🗂️
Core Concept
🇬🇧 English
Store elements you have already seen in a HashMap. When processing a new element, look it up in the map in O(1). The map acts as a memory — "have I seen this before? Where?" Pattern: store → lookup → act.

Jo elements pehle dekh chuke ho unhe HashMap mein store karo. Naya element aane par O(1) mein check karo — "yeh pehle aaya tha kya? Kahan?" Map ek memory ki tarah kaam karta hai. Pattern: store → lookup → decision lo.

🔵 C++ · Contains Duplicate
bool containsDuplicate(vector<int>& nums) {
    unordered_set<int> seen;
    for (int x : nums) {
        if (seen.count(x)) return true;  // pehle dekha tha → duplicate!
        seen.insert(x);
    }
    return false;
}

// Variant: Contains Duplicate II — within k distance (LeetCode 219)
bool containsNearbyDuplicate(vector<int>& nums, int k) {
    unordered_map<int,int> mp; // value → last index
    for (int i = 0; i < nums.size(); i++) {
        if (mp.count(nums[i]) && i - mp[nums[i]] <= k)
            return true;
        mp[nums[i]] = i; // last seen index update karo
    }
    return false;
}
💡 Simple duplicate check ke liye unordered_set use karo. Jab index bhi chahiye (k distance wala) tab unordered_map<val, index>.
Problem 3 — Roman to Integer
🏛️
Roman to IntegerLeetCode 13
🇬🇧 Intuition
Build a lookup map of char → value. Traverse right to left. If current value < next value → subtract (subtractive case like IV=4). Else → add. HashMap makes the char lookup O(1).
🇮🇳 Hinglish
HashMap mein char → value store karo (I=1, V=5, X=10...). Right se left traverse karo. Agar current value next se choti hai → subtract karo (IV = 5-1 = 4). Badi hai → add karo. HashMap se O(1) lookup!
🔵 C++ · Roman to Integer
int romanToInt(string s) {
    unordered_map<char,int> val = {
        {'I',1},{'V',5},{'X',10},{'L',50},
        {'C',100},{'D',500},{'M',1000}
    };
    int result = 0, n = s.size();

    for (int i = 0; i < n; i++) {
        // next char se chota hai → subtract (e.g. IV, IX, CM)
        if (i + 1 < n && val[s[i]] < val[s[i+1]])
            result -= val[s[i]];
        else
            result += val[s[i]];
    }
    return result;
}
💡 HashMap yahan lookup table ki tarah use ho raha hai. Char ko value mein convert karna O(1) ho gaya. Right-to-left ya subtractive check dono kaam karta hai.

🧮 Set Based

HashSet use karo jab sirf existence check chahiye — count nahi, index nahi. O(1) membership test.

O(1) membership No duplicates Existence check
🎯
Core Concept
🇬🇧 English
When you only need to know if an element exists (not how many times or at what index), use an unordered_set. It gives O(1) average insert, delete, and lookup. Set-based patterns shine in sequence/connectivity problems.
🇮🇳 Hinglish
Jab sirf yeh jaanna ho ki "element hai ya nahi" (count ya index nahi chahiye) — unordered_set use karo. Insert, delete, lookup teeno O(1) average. Sequence ya connectivity problems mein set-based pattern sabse clean solution deta hai.

🔵 C++ · Longest Consecutive Sequence
int longestConsecutive(vector<int>& nums) {
    unordered_set<int> numSet(nums.begin(), nums.end());
    int maxLen = 0;

    for (int n : numSet) {
        // Sirf sequence start se count karo
        if (!numSet.count(n - 1)) {
            int cur = n, len = 1;
            while (numSet.count(cur + 1)) {
                cur++; len++;
            }
            maxLen = max(maxLen, len);
        }
    }
    return maxLen;
}
💡 Key trick: n-1 set mein nahi hai → yahi sequence ka start hai. Agar start se hi count karenge toh har number sirf ek baar process hoga → O(n)!
⚠️ Sorting se O(n log n) hoga. HashSet approach O(n) hai — interviews mein yahi expect karte hain!
Problem 2 — Intersection of Two Arrays
🔗
Intersection of Two ArraysLeetCode 349
🇬🇧 Intuition
Insert all elements of nums1 into a HashSet. Iterate through nums2 — if element exists in set → add to result set (to avoid duplicates). Return result as vector.
🇮🇳 Hinglish
nums1 ke saare elements ek set mein daalo. nums2 traverse karo — jo element set mein mila woh dono arrays mein common hai! Result set mein daalo (duplicates avoid karne ke liye). Ant mein vector mein convert karo.
🔵 C++ · Intersection of Two Arrays
vector<int> intersection(vector<int>& nums1, vector<int>& nums2) {
    unordered_set<int> s(nums1.begin(), nums1.end());
    unordered_set<int> result;

    for (int x : nums2)
        if (s.count(x)) result.insert(x); // common element mila!

    return {result.begin(), result.end()};
}

// Variant: Intersection II — with duplicates (LeetCode 350)
vector<int> intersect(vector<int>& nums1, vector<int>& nums2) {
    unordered_map<int,int> freq;
    for (int x : nums1) freq[x]++;       // nums1 ki frequency
    vector<int> res;
    for (int x : nums2) {
        if (freq[x] > 0) {               // nums1 mein bacha hai?
            res.push_back(x);
            freq[x]--;                    // ek use ho gaya
        }
    }
    return res;
}
💡 Unique intersection → set+set. Duplicate counts ke saath intersection → map with frequency decrement.
HashMap Patterns · Pattern 4 of 5

📍 Index Mapping

HashMap mein value ke saath uska index store karo — prefix sum + index problems ke liye essential.

Prefix Sum combo O(n) time Subarray problems
🗺️
Core Concept
🇬🇧 English
Store value → index in the map (not just existence). This is powerful when combined with prefix sums. If prefix sum at index j equals prefix sum at earlier index i, then subarray (i, j] has sum = 0 (or target). O(n) solution for O(n²) problems!
🇮🇳 Hinglish
Map mein value → index store karo. Yeh prefix sum ke saath combination mein bahut powerful hai. Agar prefix[j] == prefix[i] (i < j) toh subarray (i, j] ka sum = 0. Agar prefix[j] - prefix[i] == k toh sum = k. O(n²) problems ko O(n) mein solve karo!
Problem 1 — Subarray Sum Equals K
∑

Maintain prefix sum. For each index i, we want to find how many previous indices j exist where prefixSum[i] - prefixSum[j] == k, i.e., prefixSum[j] == prefixSum[i] - k.
Store prefixSum → count in map. Initialize map with {0:1} (empty subarray base case).
🇮🇳 Hinglish
Prefix sum maintain karo. Har index i par check karo: pehle kitni baar prefixSum[i] - k wala prefix sum aaya? Woh saare subarrays sum=k dete hain!
Map mein prefixSum → count store karo. {0:1} se initialize karo (empty prefix base case).

🔵 C++ · Subarray Sum = K
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int,int> prefixCount;
    prefixCount[0] = 1;  // empty prefix base case

    int prefix = 0, count = 0;
    for (int x : nums) {
        prefix += x;
        count += prefixCount[prefix - k]; // pehle kitne aise prefix the?
        prefixCount[prefix]++;            // current prefix store karo
    }
    return count;
}
💡 {0:1} initialization critical hai — agar poora subarray [0..i] ka sum == k ho tab bhi count mile. Yahi base case hai!
⚠️ Yeh approach negative numbers ke liye bhi kaam karta hai — sliding window nahi karta negatives ke saath!
Problem 2 — First Non-Repeating Character
1️⃣
First Non-Repeating CharLeetCode 387
🇬🇧 Intuition
Two-pass approach: Pass 1 → build frequency map. Pass 2 → scan string left to right, return index of first character with frequency = 1.
🇮🇳 Hinglish
Do pass: Pass 1 → frequency map banao. Pass 2 → left se right scan karo, pehla character jiska frequency = 1 ho uska index return karo. Map ne index dhundna O(1) kar diya!
🔵 C++ · First Non-Repeating Character
int firstUniqChar(string s) {
    int freq[26] = {0};
    for (char c : s) freq[c - 'a']++;  // Pass 1: count karo

    for (int i = 0; i < s.size(); i++)    // Pass 2: pehla unique dhundo
        if (freq[s[i] - 'a'] == 1)
            return i;

    return -1;
}

// Stream version: First Unique Character in a Data Stream
// LinkedHashMap (ordered map in C++) use karo
class FirstUnique {
    unordered_map<int,int> freq;
    queue<int> q;   // insertion order maintain
public:
    FirstUnique(vector<int>& nums) {
        for (int x : nums) add(x);
    }
    int showFirstUnique() {
        while (!q.empty() && freq[q.front()] > 1) q.pop();
        return q.empty() ? -1 : q.front();
    }
    void add(int val) { freq[val]++; q.push(val); }
};

🗂️ Grouping Pattern

Similar elements ko ek saath group karo — map key ek "canonical form" hota hai jo similar elements share karte hain.

Canonical Key O(n·k) time Cluster problems
🧩
Core Concept
🇬🇧 English
Create a canonical key that represents a "class" of equivalent elements. All elements that should be grouped together will produce the same key. Store key → list of elements. Examples: sorted string as key for anagrams, frequency pattern as key for isomorphic strings.
🇮🇳 Hinglish
Ek canonical key banao jo similar elements ki "class" represent kare. Jo bhi elements ek group mein jaane chahiye woh same key produce karenge. key → list of elements store karo. Example: anagrams ke liye sorted string key, isomorphic ke liye character mapping pattern.
Problem 1 — Group Anagrams
📦
Group AnagramsLeetCode 49
🇬🇧 Intuition
Canonical key = sorted version of the string. All anagrams produce the same sorted string. Map each sorted key to a list of original strings. Final answer = all map values.

Optimization: Instead of sorting, use a character frequency array of size 26 as the key — O(k) instead of O(k log k).
🇮🇳 Hinglish
Canonical key = string ko sort karo. Sare anagrams ek hi sorted string produce karte hain. Sorted key → original strings ki list map karo. Final answer = sab map values.

Optimization: Sort karne ki jagah char frequency array (size 26) ko key banao — O(k) time, O(k log k) se better!

🔵 C++ · Group Anagrams
vector<vector<string>> groupAnagrams(vector<string>& strs) {
    unordered_map<string, vector<string>> groups;

    for (string& s : strs) {
        string key = s;
        sort(key.begin(), key.end());  // canonical key = sorted string
        groups[key].push_back(s);
    }

    vector<vector<string>> result;
    for (auto& [key, group] : groups)
        result.push_back(group);
    return result;
}

// O(n*k) version — freq array as key (faster!)
vector<vector<string>> groupAnagramsFast(vector<string>& strs) {
    map<vector<int>, vector<string>> groups;

    for (string& s : strs) {
        vector<int> freq(26, 0);
        for (char c : s) freq[c - 'a']++; // freq array = canonical key
        groups[freq].push_back(s);
    }

    vector<vector<string>> result;
    for (auto& [key, group] : groups)
        result.push_back(group);
    return result;
}
💡 Grouping pattern ki beauty: do strings anagram hain ya nahi — directly compare karne ki zaroorat nahi! Bas same canonical key produce karein → automatically grouped!

🔵 C++ · Isomorphic Strings
bool isIsomorphic(string s, string t) {
    unordered_map<char,char> sToT, tToS;

    for (int i = 0; i < s.size(); i++) {
        char sc = s[i], tc = t[i];

        // s→t mapping check
        if (sToT.count(sc) && sToT[sc] != tc) return false;
        // t→s mapping check (reverse)
        if (tToS.count(tc) && tToS[tc] != sc) return false;

        sToT[sc] = tc;
        tToS[tc] = sc;
    }
    return true;
}

// Cleaner: normalize both strings to index-pattern, compare
string normalize(string s) {
    unordered_map<char,int> mp;
    string pattern;
    int idx = 0;
    for (char c : s) {
        if (!mp.count(c)) mp[c] = idx++;
        pattern += to_string(mp[c]) + ",";
    }
    return pattern;
}
// normalize("egg") == normalize("add") → "0,1,1," == "0,1,1,"

bool wordPattern(string pattern, string s) {
    istringstream iss(s);
    vector<string> words;
    string w;
    while (iss >> w) words.push_back(w);  // string split karo

    if (pattern.size() != words.size()) return false;

    unordered_map<char,string> cToW;
    unordered_map<string,char> wToC;

    for (int i = 0; i < pattern.size(); i++) {
        char c = pattern[i];
        string& word = words[i];

        if (cToW.count(c) && cToW[c] != word)   return false;
        if (wToC.count(word) && wToC[word] != c) return false;

        cToW[c] = word;
        wToC[word] = c;
    }
    return true;
}
💡 Isomorphic Strings = char↔char mapping. Word Pattern = char↔word mapping. Same algorithm, different data types!

Common Mistakes & Gotchas
⚠️ Two Sum: Pehle check karo, phir insert. Warna same index pair return ho sakta hai (e.g. target=6, arr=[3,3]).
⚠️ Subarray Sum: Map ko {0:1} se initialize karna mat bhoolo. Warna poore prefix ke subarrays miss ho jaayenge.
⚠️ Isomorphic / Word Pattern: Sirf ek direction ka map rakhoge toh "ab" → "aa" jaise cases fail ho jaayenge. Dono direction mandatory!
⚠️ Longest Consecutive: Sorting mat karo — O(n log n) ho jaayega. HashSet approach O(n) hai aur expected answer hai interviews mein.
💡 Pro tip: unordered_map mein non-existent key access karne par (e.g. mp[x]) automatically 0 insert ho jaata hai. Kabhi kabhi yeh bug ban sakta hai. Safe check ke liye mp.count(x) ya mp.find(x) != mp.end() use karo.
