🔁 Recursion — Basics

Function apne aap ko call karta hai — har call ek smaller subproblem solve karta hai. Base case se ruka karta hai.

Self-calling Call Stack Base Case critical
🔁
What is Recursion?
🇬🇧 English
A function that calls itself with a smaller input until it reaches a base case (stopping condition). Every recursive solution has:
1. Base Case — smallest problem jo directly solve ho jaye (no more recursion)
2. Recursive Case — problem ko smaller subproblem mein todna + recursive call
3. Return value — subproblem ka result use karke current problem solve karna
🇮🇳 Hinglish
Ek function jo apne aap ko chhote input ke saath call karta hai jab tak base case na mile. Har recursion mein teen cheezein:
1. Base Case — sabse chhota problem jo direct solve hota hai (yahan ruk jaao)
2. Recursive Case — problem chhoti karo + apne aap ko call karo
3. Return — chhote problem ka answer lekar bada answer banao
🔵 C++ · Factorial — Recursion Template
// Recursion ka sabse simple example: Factorial
int factorial(int n) {
    // Base Case: n==0 ya n==1 par directly return karo
    if (n <= 1) return 1;

    // Recursive Case: n! = n * (n-1)!
    return n * factorial(n - 1);
}
// factorial(4) = 4 * factorial(3)
//             = 4 * 3 * factorial(2)
//             = 4 * 3 * 2 * factorial(1)
//             = 4 * 3 * 2 * 1 = 24
💡 Golden Rule: Har recursive function mein base case pehle likhna — warna infinite recursion → Stack Overflow!

Recursion → Backtracking

🔙 Backtracking

Explore karo, galat gaye toh undo karo aur doosra raasta try karo. Decision tree pe DFS jaisa kaam.

Explore all paths Undo on fail Exponential O(2ⁿ / n!)
🧩
Core Template — Choose → Explore → Unchoose
🇬🇧 English
Every backtracking problem follows this 3-step pattern:
1. Choose: Pick a candidate (add to current path/state)
2. Explore: Recurse deeper with this choice
3. Unchoose (Backtrack): Undo the choice — remove from state
This guarantees all states are explored and the state is clean between branches.
🇮🇳 Hinglish
Har backtracking problem isi 3-step pattern follow karti hai:
1. Choose: Ek candidate choose karo (path/state mein add karo)
2. Explore: Is choice ke saath aur deep jaao (recursive call)
3. Unchoose: Choice ko undo karo — state se hatao
Isse saari possibilities explore hoti hain aur state clean rehti hai branches ke beech.
🔵 C++ · Backtracking Template
void backtrack(state& current, vector<result>& results, /* other params */) {
    // Base case: goal reached → save result
    if (goalReached(current)) {
        results.push_back(current);
        return;
    }

    for (each candidate in candidates) {
        // 1. CHOOSE — state mein add karo
        current.add(candidate);

        // 2. EXPLORE — deeper jaao
        backtrack(current, results, ...);

        // 3. UNCHOOSE — undo karo (backtrack!)
        current.remove(candidate);
    }
}
// Pruning: invalid states ko early reject karo → speed up
// if (!isValid(candidate)) continue;  ← loop ke andar, choose se pehle
💡 Backtracking = Brute force + Smart pruning. Bina pruning ke sab combinations try karte hain. Pruning se invalid branches early cut hoti hain.
Problem 1 — Subsets (Power Set)
⚡
Subsets / Power SetLeetCode 78
🇬🇧 Intuition
For each element, we have two choices: include it or exclude it. Recurse on both choices. At each node in the recursion tree, record the current subset. Total subsets = 2ⁿ.
🇮🇳 Hinglish
Har element ke liye do choices hain: include karo ya exclude karo. Dono choices pe recurse karo. Recursion tree ke har node pe current subset save karo. Total = 2ⁿ subsets.

... same for [2], [3], [2,3], []
✅ Total 2³ = 8 subsets: [], [1], [2], [3], [1,2], [1,3], [2,3], [1,2,3]
🔵 C++ · Subsets (Backtracking)
vector<vector<int>> subsets(vector<int>& nums) {
    vector<vector<int>> result;
    vector<int> current;

    backtrack(nums, 0, current, result);
    return result;
}

void backtrack(vector<int>& nums, int start,
               vector<int>& curr, vector<vector<int>>& res) {
    res.push_back(curr);          // Har node pe current subset save karo

    for (int i = start; i < nums.size(); i++) {
        curr.push_back(nums[i]);  // CHOOSE
        backtrack(nums, i + 1, curr, res); // EXPLORE
        curr.pop_back();          // UNCHOOSE (backtrack!)
    }
}

// Subsets II (with duplicates — LeetCode 90)
void backtrackII(vector<int>& nums, int start,
                 vector<int>& curr, vector<vector<int>>& res) {
    res.push_back(curr);
    for (int i = start; i < nums.size(); i++) {
        // Duplicate skip karo same recursion level pe
        if (i > start && nums[i] == nums[i-1]) continue;
        curr.push_back(nums[i]);
        backtrackII(nums, i + 1, curr, res);
        curr.pop_back();
    }
}
💡 Time: O(2ⁿ × n) — 2ⁿ subsets, har subset copy karne mein O(n). Space: O(n) recursion depth.
Problem 2 — Permutations & Combinations (nCr)
🔀
PermutationsLeetCode 46
🇬🇧 Intuition
Permutations use every element exactly once in every order. Use a visited[] array to track which elements are used. When current.size() == n → permutation complete!
Combinations (nCr): Use start index — only pick elements after the last chosen. This avoids [1,2] and [2,1] being counted separately.
🇮🇳 Hinglish
Permutations mein har element exactly ek baar, kisi bhi order mein. visited[] array track karta hai kaun use hua. Jab current.size() == n → permutation complete!
Combinations (nCr): start index use karo — sirf last chosen ke baad wale pick karo. Isse [1,2] aur [2,1] alag count nahi hote.
🔵 C++ · Permutations
vector<vector<int>> permute(vector<int>& nums) {
    vector<vector<int>> res;
    vector<bool> visited(nums.size(), false);
    vector<int> curr;
    bt(nums, visited, curr, res);
    return res;
}
void bt(vector<int>& nums, vector<bool>& vis,
        vector<int>& curr, vector<vector<int>>& res) {
    if (curr.size() == nums.size()) { res.push_back(curr); return; }

    for (int i = 0; i < nums.size(); i++) {
        if (vis[i]) continue;         // pehle se use hua → skip
        vis[i] = true;               // CHOOSE
        curr.push_back(nums[i]);
        bt(nums, vis, curr, res);    // EXPLORE
        curr.pop_back();             // UNCHOOSE
        vis[i] = false;
    }
}

// Combinations (nCr) — LeetCode 77
void combine(int n, int k, int start, vector<int>& curr,
             vector<vector<int>>& res) {
    if (curr.size() == k) { res.push_back(curr); return; }

    for (int i = start; i <= n; i++) {
        curr.push_back(i);           // CHOOSE
        combine(n, k, i+1, curr, res); // EXPLORE (i+1 se — order fix)
        curr.pop_back();             // UNCHOOSE
    }
}
💡 Permutation vs Combination: Permutation mein order matters (visited[] use karo). Combination mein order nahi (start index use karo).

🔵 C++ · Word Search
bool exist(vector<vector<char>>& board, string word) {
    int m = board.size(), n = board[0].size();
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (dfs(board, word, i, j, 0)) return true;
    return false;
}

bool dfs(vector<vector<char>>& board, string& word,
         int r, int c, int idx) {
    if (idx == word.size()) return true; // word pura match!
    if (r < 0 || r >= board.size() || c < 0 || c >= board[0].size()
        || board[r][c] != word[idx]) return false; // bounds / mismatch

    char tmp = board[r][c];
    board[r][c] = '#';        // CHOOSE — visited mark karo

    bool found = dfs(board, word, r+1, c, idx+1) // EXPLORE 4 dirs
               || dfs(board, word, r-1, c, idx+1)
               || dfs(board, word, r, c+1, idx+1)
               || dfs(board, word, r, c-1, idx+1);

    board[r][c] = tmp;         // UNCHOOSE — restore karo
    return found;
}
💡 Grid pe backtracking mein visited mark karne ki jagah '#' substitute karo — extra visited[][] array ki zaroorat nahi. Restore karna mat bhoolo!
Problem 4 — Palindrome Partitioning
🪞
Palindrome PartitioningLeetCode 131
🇬🇧 Intuition
At each step, try all substrings starting at current index. If the substring is a palindrome → add it to current partition and recurse on the rest. Backtrack: remove it and try longer substrings.
🇮🇳 Hinglish
Har step mein current index se shuru hone wale saare substrings try karo. Agar substring palindrome hai → current partition mein add karo aur baaki string pe recurse karo. Backtrack: hatao aur agle (lambe) substring try karo.

🔵 C++ · Palindrome Partitioning
vector<vector<string>> partition(string s) {
    vector<vector<string>> res;
    vector<string> curr;
    bt(s, 0, curr, res);
    return res;
}

void bt(string& s, int start, vector<string>& curr,
        vector<vector<string>>& res) {
    if (start == s.size()) { res.push_back(curr); return; }

    for (int end = start; end < s.size(); end++) {
        if (isPalin(s, start, end)) {    // palindrome check (pruning)
            curr.push_back(s.substr(start, end - start + 1)); // CHOOSE
            bt(s, end + 1, curr, res);  // EXPLORE
            curr.pop_back();             // UNCHOOSE
        }
    }
}

bool isPalin(string& s, int l, int r) {
    while (l < r) if (s[l++] != s[r--]) return false;
    return true;
}
💡 Palindrome check inside backtracking = built-in pruning! Non-palindrome substrings automatically skip ho jaate hain.
Recursion → Backtracking

✂️ Pruning / State Tracking

Invalid branches early cut karo — constraints check karke unnecessary recursion bachao.

Early termination Constraint propagation State tracking
✂️
What is Pruning?
🇬🇧 English
Pruning = cutting off branches in the recursion tree that cannot possibly lead to a valid solution. Check constraints before recursing. The earlier you prune, the faster the algorithm. N-Queens and Sudoku are the classic pruning problems.
🇮🇳 Hinglish
Pruning = recursion tree ki woh branches cut karo jo kabhi valid solution tak nahi pahunch sakti. Recurse karne se pehle constraints check karo. Jitna jaldi pruning, utna fast algorithm. N-Queens aur Sudoku classic pruning problems hain.

Row by row queens place karo. Har row mein har column try karo. Prune karo agar column, left-diagonal ya right-diagonal already attacked hai. Teen sets se O(1) mein track karo.

🔵 C++ · N-Queens
vector<vector<string>> solveNQueens(int n) {
    vector<vector<string>> res;
    vector<string> board(n, string(n, '.'));
    unordered_set<int> cols, diag1, diag2;
    bt(board, 0, n, cols, diag1, diag2, res);
    return res;
}

void bt(vector<string>& board, int row, int n,
        unordered_set<int>& cols, unordered_set<int>& diag1,
        unordered_set<int>& diag2, vector<vector<string>>& res) {
    if (row == n) { res.push_back(board); return; }

    for (int col = 0; col < n; col++) {
        // PRUNE: column ya diagonal already attacked?
        if (cols.count(col) || diag1.count(row-col) || diag2.count(row+col))
            continue;

        // CHOOSE
        board[row][col] = 'Q';
        cols.insert(col); diag1.insert(row-col); diag2.insert(row+col);

        bt(board, row+1, n, cols, diag1, diag2, res); // EXPLORE

        // UNCHOOSE
        board[row][col] = '.';
        cols.erase(col); diag1.erase(row-col); diag2.erase(row+col);
    }
}
// diag1: row-col same → same left diagonal
// diag2: row+col same → same right diagonal
💡 row-col same wale cells ek hi left diagonal pe hain. row+col same = right diagonal. Yeh trick O(1) diagonal check deti hai!
Problem 2 — Sudoku Solver
🔢
Sudoku SolverLeetCode 37
🇬🇧 Intuition
Find first empty cell. Try digits 1–9. Prune: digit already in same row, column, or 3×3 box → skip. Place digit and recurse. If recursion fails → remove digit (backtrack). If all cells filled → solved!
🇮🇳 Hinglish
Pehli empty cell dhundo. 1–9 try karo. Prune: digit same row, column ya 3×3 box mein already hai → skip. Digit place karo aur recurse karo. Recursion fail ho → digit hatao (backtrack). Sab cells bhar gaye → solved!
🔵 C++ · Sudoku Solver
bool solveSudoku(vector<vector<char>>& board) {
    for (int r = 0; r < 9; r++) {
        for (int c = 0; c < 9; c++) {
            if (board[r][c] != '.') continue; // already filled

            for (char d = '1'; d <= '9'; d++) {
                if (isValid(board, r, c, d)) {
                    board[r][c] = d;                 // CHOOSE
                    if (solveSudoku(board)) return true; // EXPLORE
                    board[r][c] = '.';            // UNCHOOSE
                }
            }
            return false; // koi digit nahi chali → backtrack
        }
    }
    return true; // sab cells filled → solved!
}

bool isValid(vector<vector<char>>& b, int r, int c, char d) {
    for (int i = 0; i < 9; i++) {
        if (b[r][i] == d || b[i][c] == d) return false; // row/col check
        // 3x3 box check
        int br = 3*(r/3) + i/3, bc = 3*(c/3) + i%3;
        if (b[br][bc] == d) return false;
    }
    return true;
}
💡 3*(r/3) + i/3 aur 3*(c/3) + i%3 — yeh formula 3×3 box ke cells iterate karta hai. Ek baar samajh lo, hamesha kaam aayega!
Recursion → Divide & Conquer

⚔️ Divide & Conquer

Problem ko do (ya zyada) chhote subproblems mein todo, recursively solve karo, phir results merge karo.

Split → Solve → Merge O(n log n) typical Independent subproblems
⚔️
Core Concept
🇬🇧 English
3 steps: Divide — split problem into independent subproblems (usually halves). Conquer — recursively solve each subproblem. Combine — merge results.
Key difference from Backtracking: subproblems are independent (no backtracking needed). Typical complexity: T(n) = 2T(n/2) + O(n) → O(n log n) by Master Theorem.
🇮🇳 Hinglish
3 steps: Divide — problem ko independent subproblems mein toddo (aksar do halves). Conquer — har subproblem recursively solve karo. Combine — results merge karo.
Backtracking se fark: subproblems independent hain (backtrack nahi karna). Typical: T(n) = 2T(n/2) + O(n) → O(n log n).
Pattern 1 — Merge Sort Pattern
🔀
Merge SortClassic D&C
🇬🇧 Intuition
Divide array in half. Recursively sort both halves. Merge two sorted halves into one sorted array using two pointers. The merge step is O(n), depth is O(log n) → Total O(n log n). Stable sort!
🇮🇳 Hinglish
Array do halves mein divide karo. Dono halves recursively sort karo. Phir two pointers se do sorted halves merge karo. Merge O(n), depth O(log n) → Total O(n log n). Stable sort hai!

🔵 C++ · Merge Sort
void mergeSort(vector<int>& arr, int l, int r) {
    if (l >= r) return;           // base case: 1 element

    int mid = l + (r - l) / 2;
    mergeSort(arr, l, mid);        // DIVIDE + CONQUER left
    mergeSort(arr, mid+1, r);     // DIVIDE + CONQUER right
    merge(arr, l, mid, r);         // COMBINE
}

void merge(vector<int>& arr, int l, int mid, int r) {
    vector<int> tmp;
    int i = l, j = mid + 1;

    while (i <= mid && j <= r) {
        if (arr[i] <= arr[j]) tmp.push_back(arr[i++]);
        else                  tmp.push_back(arr[j++]);
    }
    while (i <= mid) tmp.push_back(arr[i++]);
    while (j <= r)   tmp.push_back(arr[j++]);

    for (int k = l; k <= r; k++)
        arr[k] = tmp[k - l];
}
💡 Merge Sort ka pattern bahut useful hai — Count Inversions bhi isi se solve hota hai. Template yaad karo!
Pattern 2 — Quick Select (Kth Largest)
🎯
Quick Select — Kth LargestLeetCode 215
🇬🇧 Intuition
Like Quick Sort but we only recurse on one side. Pick a pivot. Partition array around it. If pivot lands at index k → found! If pivot > k → recurse left. If pivot < k → recurse right.
Average O(n), Worst O(n²). Use random pivot to avoid worst case.
🇮🇳 Hinglish
Quick Sort jaisa but sirf ek side pe recurse karo. Pivot choose karo. Pivot ke around partition karo. Pivot ka index == k? → mil gaya! Pivot > k → left mein jaao. Pivot < k → right mein.
Average O(n), Worst O(n²). Random pivot se worst case avoid karo.

🔵 C++ · Quick Select (Kth Largest)
int findKthLargest(vector<int>& nums, int k) {
    // kth largest = (n-k)th smallest (0-indexed)
    return quickSelect(nums, 0, nums.size()-1, nums.size()-k);
}

int quickSelect(vector<int>& nums, int l, int r, int k) {
    if (l == r) return nums[l];

    // Random pivot (worst case avoid karo)
    int pivIdx = l + rand() % (r - l + 1);
    swap(nums[pivIdx], nums[r]);
    int pivot = nums[r], p = l;

    for (int i = l; i < r; i++)
        if (nums[i] <= pivot) swap(nums[p++], nums[i]);
    swap(nums[p], nums[r]);  // pivot apni final position pe

    if (p == k) return nums[p];            // found!
    if (p <  k) return quickSelect(nums, p+1, r, k); // right
    return quickSelect(nums, l, p-1, k);              // left
}
💡 Quick Select O(n) average — heap se O(n log k) se better! Sirf ek side pe recurse karta hai → linear average time.
Pattern 3 — Count Inversions
🔄
Count InversionsClassic Merge Sort
🇬🇧 Intuition
An inversion is a pair (i, j) where i < j but arr[i] > arr[j]. Brute force O(n²). Instead, modify Merge Sort: during the merge step, when a right-half element is placed before left-half elements, those left elements all form inversions. Count them!
🇮🇳 Hinglish

🔵 C++ · Count Inversions (Modified Merge Sort)
long long mergeCount(vector<int>& arr, int l, int r) {
    if (l >= r) return 0;

    int mid = l + (r - l) / 2;
    long long inv = 0;
    inv += mergeCount(arr, l, mid);      // left half inversions
    inv += mergeCount(arr, mid+1, r);   // right half inversions
    inv += mergeAndCount(arr, l, mid, r); // cross inversions
    return inv;
}

long long mergeAndCount(vector<int>& arr, int l, int mid, int r) {
    vector<int> tmp;
    int i = l, j = mid + 1;
    long long inv = 0;

    while (i <= mid && j <= r) {
        if (arr[i] <= arr[j]) {
            tmp.push_back(arr[i++]);
        } else {
            // arr[j] < arr[i..mid] → saare left inversions
            inv += (mid - i + 1);
            tmp.push_back(arr[j++]);
        }
    }
    while (i <= mid) tmp.push_back(arr[i++]);
    while (j <= r)   tmp.push_back(arr[j++]);
    for (int k = l; k <= r; k++) arr[k] = tmp[k-l];
    return inv;
}
💡 Count inversions = Merge Sort + count when right element placed before left. (mid - i + 1) — remaining left elements saare inversions form karte hain us right element ke saath.

Common Mistakes
⚠️ Base Case bhool gaye: Infinite recursion → Stack Overflow. Hamesha base case pehle likho!
⚠️ Unchoose step bhool gaye: State pollute ho jaati hai between branches. pop_back() / unmark karna MANDATORY hai.
⚠️ Grid word search mein restore nahi kiya: board[r][c] = tmp restore karna mat bhoolo warna agle paths wrong honge.
⚠️ Subsets II mein duplicate skip nahi kiya: Sort pehle karo, phir i > start && nums[i]==nums[i-1] se skip karo.
💡 Recursion debug tip: Recursion tree draw karo. Root = original call, leaves = base cases. Agar tree infinitely deep ja rahi hai → base case check karo. Agar wrong answers → unchoose step check karo.
