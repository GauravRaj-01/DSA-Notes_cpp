Sliding Window on Strings

String ke upar ek window khiskaate hain — characters add/remove karte hain. Substring problems ke liye best.

O(n) time HashMap use Substring problems
🪟
Core Concept
🇬🇧 English
A window [l, r] slides over the string. We expand by moving r right and shrink by moving l right when a condition is violated. A HashMap/frequency array tracks characters inside the window. This avoids O(n²) brute force.
🇮🇳 Hinglish
String pe ek window [l, r] slide karti hai. Right se expand karo (r++), condition fail hone par left se shrink karo (l++). HashMap se window ke andar characters track karo. Yeh brute force ke O(n²) ko O(n) mein badal deta hai!

🔵 C++ · Longest Substring Without Repeating
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> lastSeen; // char ki last index store karo
    int l = 0, maxLen = 0;

    for (int r = 0; r < s.size(); r++) {
        // duplicate mila aur woh current window ke andar hai
        if (lastSeen.count(s[r]) && lastSeen[s[r]] >= l)
            l = lastSeen[s[r]] + 1; // l ko seedha aage le jao

        lastSeen[s[r]] = r;          // position update karo
        maxLen = max(maxLen, r - l + 1);
    }
    return maxLen;
}
💡 Key trick: lastSeen[s[r]] >= l check karna zaroori hai — warna purana index use ho jaayega jo already window se bahar hai.
Problem 2 — Minimum Window Substring
🎯
Minimum Window SubstringLeetCode 76 · Hard
🇬🇧 Intuition
Two HashMaps — need (required chars from t) and have_map (current window). Track have = how many unique chars have met their required frequency.

🔵 C++ · Minimum Window Substring
string minWindow(string s, string t) {
    unordered_map<char,int> need, have_map;
    for (char c : t) need[c]++;   // t ke required chars

    int have = 0, need_cnt = need.size();
    int l = 0, minLen = INT_MAX, start = 0;

    for (int r = 0; r < s.size(); r++) {
        have_map[s[r]]++;
        // agar yeh char zaroori hai aur frequency match ho gayi
        if (need.count(s[r]) && have_map[s[r]] == need[s[r]])
            have++;

        while (have == need_cnt) {      // sab chars cover ho gaye → shrink!
            if (r - l + 1 < minLen) {
                minLen = r - l + 1;
                start = l;              // minimum window ka start save karo
            }
            have_map[s[l]]--;
            if (need.count(s[l]) && have_map[s[l]] < need[s[l]])
                have--;                 // char hataya → condition fail
            l++;
        }
    }
    return minLen == INT_MAX ? "" : s.substr(start, minLen);
}
⚠️ have count tab badhta hai jab frequency EXACTLY match ho (==), aur tab ghatta hai jab frequency required se kam ho (<). Strict equality use karo!

🔵 C++ · Find All Anagrams
vector<int> findAnagrams(string s, string p) {
    if (s.size() < p.size()) return {};
    vector<int> pFreq(26, 0), wFreq(26, 0), result;
    int k = p.size();

    for (char c : p) pFreq[c - 'a']++;      // pattern ki frequency

    for (int r = 0; r < s.size(); r++) {
        wFreq[s[r] - 'a']++;                  // window mein add karo

        if (r >= k)
            wFreq[s[r - k] - 'a']--;          // purana char hatao

        if (r >= k - 1 && wFreq == pFreq)      // frequency arrays match?
            result.push_back(r - k + 1);
    }
    return result;
}

// Alternate: Permutation in String (LeetCode 567) — same logic, return bool
bool checkInclusion(string s1, string s2) {
    if (s1.size() > s2.size()) return false;
    vector<int> p(26,0), w(26,0);
    int k = s1.size();
    for (char c : s1) p[c-'a']++;
    for (int r = 0; r < s2.size(); r++) {
        w[s2[r]-'a']++;
        if (r >= k) w[s2[r-k]-'a']--;
        if (r >= k-1 && w == p) return true;
    }
    return false;
}
💡 26-size frequency array compare karna O(26) = O(1) hai practically. HashMap se better hai yahan kyunki sirf lowercase letters hain.

🔵 C++ · Valid Palindrome
bool isPalindrome(string s) {
    int l = 0, r = s.size() - 1;
    while (l < r) {
        while (l < r && !isalnum(s[l])) l++; // left se non-alphanum skip
        while (l < r && !isalnum(s[r])) r--; // right se non-alphanum skip
        if (tolower(s[l]) != tolower(s[r]))
            return false;                    // mismatch → palindrome nahi
        l++; r--;
    }
    return true;
}

// Bonus: Longest Palindromic Substring — Expand Around Center
string longestPalindrome(string s) {
    int start = 0, maxLen = 1;
    auto expand = [&](int l, int r) {
        while (l >= 0 && r < s.size() && s[l] == s[r]) {
            if (r - l + 1 > maxLen) {
                maxLen = r - l + 1;
                start = l;
            }
            l--; r++;
        }
    };
    for (int i = 0; i < s.size(); i++) {
        expand(i, i);      // odd length palindrome (center = i)
        expand(i, i + 1); // even length palindrome (center = i,i+1)
    }
    return s.substr(start, maxLen);
}
💡 Expand Around Center: Har character se (aur adjacent pair se) bahar ki taraf expand karo. Odd + even dono cases handle karo.
Problem 2 — Reverse Words / Characters
↩️
Reverse Words in a StringLeetCode 151
🇮🇳 Hinglish
Trick: Pehle poori string reverse karo. Phir har word ko individually reverse karo. Extra spaces handle karna mat bhoolna — leading, trailing, aur multiple spaces sab hata do.
🔵 C++ · Reverse Words in String
string reverseWords(string s) {
    // Step 1: Poori string reverse karo
    reverse(s.begin(), s.end());

    int n = s.size(), i = 0, j = 0;

    while (i < n) {
        while (i < n && s[i] == ' ') i++; // leading spaces skip
        if (i == n) break;

        if (j != 0) s[j++] = ' ';         // words ke beech ek space

        int wordStart = j;
        while (i < n && s[i] != ' ')
            s[j++] = s[i++];               // word copy karo

        // Step 2: Iss word ko reverse karo
        reverse(s.begin() + wordStart, s.begin() + j);
    }
    s.resize(j);
    return s;
}

// Simpler version using stringstream
string reverseWordsSimple(string s) {
    istringstream iss(s);
    string word, result;
    vector<string> words;
    while (iss >> word) words.push_back(word);
    for (int i = words.size()-1; i >= 0; i--) {
        result += words[i];
        if (i) result += " ";
    }
    return result;
}
🔵 C++ · Reverse String (in-place)
// LeetCode 344 — O(n) time, O(1) space
void reverseString(vector<char>& s) {
    int l = 0, r = s.size() - 1;
    while (l < r) {
        swap(s[l++], s[r--]); // do characters swap karo, dono pointers move
    }
}

🔵 C++ · String Compression
int compress(vector<char>& chars) {
    int write = 0, read = 0, n = chars.size();

    while (read < n) {
        char cur = chars[read];
        int count = 0;

        // same characters count karo
        while (read < n && chars[read] == cur) {
            read++; count++;
        }

        chars[write++] = cur;   // character likho

        if (count > 1) {         // count > 1 ho tabhi number likho
            string cnt = to_string(count);
            for (char c : cnt)
                chars[write++] = c; // digit by digit likho
        }
    }
    return write;
}
💡 Count ko string mein convert karo phir digit-by-digit likho — multi-digit counts (e.g. 12 → '1','2') ke liye zaroori hai.

Pattern Matching

String ke andar pattern dhundho efficiently. Naive O(n·m) se better — O(n+m) ya O(n·m) with hashing.

KMP O(n+m) Rabin-Karp O(n+m) avg Z-Algo O(n+m)
Algorithm 1 — KMP (Knuth-Morris-Pratt)
⚡
KMP AlgorithmO(n + m)
🇬🇧 Core Idea
Naive approach re-checks characters unnecessarily on mismatch. KMP uses a LPS (Longest Proper Prefix which is also Suffix) array to know how far to jump back on a mismatch — never going backward in the text.

LPS array: For pattern "AABAAB", LPS = [0,1,0,1,2,3]. It tells: if mismatch at position i, jump to LPS[i-1] in pattern.
🇮🇳 Hinglish
Naive mein mismatch hone par text mein peeche jaate hain — time waste! KMP mein hum pehle LPS array banate hain pattern ke liye. Yeh batata hai: "mismatch hone par pattern mein kitna peeche jaao, text mein nahi!" Text pointer kabhi peeche nahi jaata — isliye O(n+m).

LPS = Longest Proper Prefix jo Suffix bhi ho. Pattern ka koi suffix hai jo prefix bhi ho — uski length store karo.

🔵 C++ · KMP Algorithm (Full)
// Step 1: LPS Array build karo
vector<int> buildLPS(string& pat) {
    int m = pat.size();
    vector<int> lps(m, 0);
    int len = 0, i = 1;          // len = current longest prefix-suffix

    while (i < m) {
        if (pat[i] == pat[len]) {
            lps[i++] = ++len;     // match! len badhao
        } else if (len > 0) {
            len = lps[len - 1];  // peeche jao — i mat badhao!
        } else {
            lps[i++] = 0;       // koi prefix-suffix nahi
        }
    }
    return lps;
}

// Step 2: KMP Search — text mein pattern dhundho
vector<int> kmpSearch(string text, string pat) {
    int n = text.size(), m = pat.size();
    vector<int> lps = buildLPS(pat);
    vector<int> result;
    int i = 0, j = 0;            // i = text pointer, j = pattern pointer

    while (i < n) {
        if (text[i] == pat[j]) {
            i++; j++;             // dono match → dono aage
        }
        if (j == m) {
            result.push_back(i - j); // pura pattern mila!
            j = lps[j - 1];        // overlap possible → LPS se jump
        } else if (i < n && text[i] != pat[j]) {
            if (j > 0)
                j = lps[j - 1];    // pattern mein peeche jao
            else
                i++;               // text aage badho
        }
    }
    return result;
}
💡 KMP ka magic: text pointer i kabhi peeche nahi jaata. Sirf pattern pointer j LPS ke hisaab se jump karta hai. Isliye O(n+m) guaranteed!
Algorithm 2 — Rabin-Karp (Rolling Hash)
#️⃣
Rabin-Karp AlgorithmO(n+m) avg · O(nm) worst
🇬🇧 Core Idea
Instead of comparing characters one by one, compare hash values of the window with the pattern's hash. Use a rolling hash — remove leftmost char's contribution and add new rightmost char. Hash match → verify (to handle collisions). No match → slide on.

Hash formula: hash = (hash * base + char) % mod
🇮🇳 Hinglish
Characters compare karne ki jagah hash values compare karo — ek number se poori window represent hoti hai. Rolling hash = purana character hatao, naya add karo — O(1) mein hash update hota hai. Hash match ho toh actual comparison karo (collision se bachne ke liye). Yeh approach multiple patterns dhundhne mein bhi kaam aata hai!

🔵 C++ · Rabin-Karp Algorithm
vector<int> rabinKarp(string text, string pat) {
    int n = text.size(), m = pat.size();
    const long long BASE = 26, MOD = 1e9 + 7;
    vector<int> result;

    long long patHash = 0, winHash = 0, power = 1;

    // BASE^(m-1) % MOD — leftmost char hatane ke liye chahiye
    for (int i = 0; i < m - 1; i++) power = (power * BASE) % MOD;

    // Pattern aur pehli window ka hash banao
    for (int i = 0; i < m; i++) {
        patHash = (patHash * BASE + pat[i]) % MOD;
        winHash = (winHash * BASE + text[i]) % MOD;
    }

    for (int i = 0; i <= n - m; i++) {
        if (winHash == patHash) {
            // Hash match! — actual comparison karo (collision handle)
            if (text.substr(i, m) == pat)
                result.push_back(i);
        }
        // Rolling hash: purana char hatao, naya add karo
        if (i < n - m) {
            winHash = (winHash - ((long long)text[i] * power) % MOD + MOD) % MOD;
            winHash = (winHash * BASE + text[i + m]) % MOD;
        }
    }
    return result;
}
⚠️ Hash collision possible hai — isliye hash match hone par actual string comparison karo. Large MOD (1e9+7) use karo collision minimize karne ke liye.
💡 Rabin-Karp best hai jab multiple patterns ek saath dhundhne ho — sab patterns ke hash precompute karo aur ek pass mein check karo!
Algorithm 3 — Z-Algorithm
Z
Z-AlgorithmO(n + m)
🇬🇧 Core Idea
Build a Z-array for the combined string pat + "$" + text. Z[i] = length of the longest substring starting at i that matches a prefix of the whole string.

If Z[i] == m (pattern length) at any position in the text part → pattern found there!

Z-box optimization: maintain a window [l, r] of the rightmost matching segment to avoid re-comparisons.
🇮🇳 Hinglish
Pattern + "$" + text ko join karo. Phir Z-array banao — Z[i] batata hai: "index i se shuru hone wala substring poori string ke prefix se kitna match karta hai?"

Agar text ke kisi index pe Z[i] == pattern.length() → pattern wahan se mila!

Z-box optimization: ek window [l,r] maintain karo jisme already match hua hai — us range mein dobara compare karne ki zaroorat nahi.

// Z-array banao for string s
vector<int> buildZ(string s) {
    int n = s.size();
    vector<int> Z(n, 0);
    int l = 0, r = 0;          // Z-box window [l, r]

    for (int i = 1; i < n; i++) {
        if (i < r) {
            // Z-box ke andar hain — pehle se computed value use karo
            Z[i] = min(r - i, Z[i - l]);
        }
        // Ab manually extend karo
        while (i + Z[i] < n && s[Z[i]] == s[i + Z[i]])
            Z[i]++;

        // Z-box update karo agar aage gaye
        if (i + Z[i] > r) {
            l = i;
            r = i + Z[i];
        }
    }
    return Z;
}

// Pattern search using Z-algorithm
vector<int> zSearch(string text, string pat) {
    string combined = pat + "$" + text; // "$" separator — pattern mein nahi hona chahiye
    int m = pat.size();
    vector<int> Z = buildZ(combined);
    vector<int> result;

    for (int i = m + 1; i < combined.size(); i++) {
        if (Z[i] == m)                  // pattern ki full length match!
            result.push_back(i - m - 1); // text mein original index
    }
    return result;
}
💡 Z-box trick: pehle se computed range [l,r] mein dobara kaam nahi karna. Z[i] = min(r-i, Z[i-l]) se seedha start karo — yahi O(n) complexity deta hai.
