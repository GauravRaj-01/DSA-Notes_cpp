🧠 Dynamic Programming — Basics

DP = Overlapping subproblems + Optimal substructure. Recursion ki memory ke saath — already solved problems dubara mat solve karo!

Memoization Tabulation Overlapping Subproblems Optimal Substructure
🧠
Dynamic Programming kya hai?
🇬🇧 English
Dynamic Programming is an optimization technique to solve problems by breaking them into overlapping subproblems and storing their results to avoid recomputation.

Two key properties required:
1. Overlapping Subproblems — same smaller problems appear again and again.
2. Optimal Substructure — optimal solution is built from optimal solutions of subproblems.

Think of it as: Recursion + Caching = Dynamic Programming.
🇮🇳 Hinglish
Dynamic Programming ek technique hai jisme problem ko chhote pieces mein todke solve karte hain — aur jo already solve ho gaya usse yaad rakh lete hain (cache karte hain), dobara solve nahi karte.

Do cheezein zaruri hain:
1. Overlapping Subproblems — same chhote problems baar baar aate hain.
2. Optimal Substructure — bada problem ka best answer chhote problems ke best answers se banta hai.

Simple formula: Recursion + Memory = DP
💡 DP vs Greedy: Greedy locally best choice leta hai. DP har choice try karke globally best dhundta hai. Agar "max/min/count ways" wala problem ho → DP try karo first!
Memoization (Top-Down) vs Tabulation (Bottom-Up)
⚡
Fibonacci Example — Memoization vs Tabulation
🇬🇧 English
Memoization (Top-Down): Start from the big problem, recurse down, cache results in a map/array. Natural to write — just add memo to recursion.
Tabulation (Bottom-Up): Start from base cases, build up the table iteratively. Usually more space-efficient.
🇮🇳 Hinglish
Memoization (Top-Down): Bade problem se shuru, recursion se chhote mein jaao, result ko map/array mein save karo. Likhna easy hai — bas recursion mein cache add karo.
Tabulation (Bottom-Up): Base cases se shuru, iteratively table fill karo. Zyada space-efficient hota hai.
🔵 C++ · Fibonacci — 3 Approaches
// 1. Pure Recursion — O(2^n) time, O(n) space — SLOW ❌
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // same subproblems computed again!
}

// 2. Memoization (Top-Down) — O(n) time, O(n) space ✅
int memo[1001];
int fibMemo(int n) {
    if (n <= 1) return n;
    if (memo[n] != -1) return memo[n];  // already solved? return it!
    return memo[n] = fibMemo(n-1) + fibMemo(n-2);
}

// 3. Tabulation (Bottom-Up) — O(n) time, O(n) space ✅✅
int fibTab(int n) {
    vector<int> dp(n+1);
    dp[0] = 0; dp[1] = 1;          // base cases
    for (int i = 2; i <= n; i++)
        dp[i] = dp[i-1] + dp[i-2]; // build from small to big
    return dp[n];
}

// 4. Space Optimized — O(n) time, O(1) space 🚀
int fibOpt(int n) {
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int c = a + b;
        a = b; b = c;
    }
    return (n == 0) ? 0 : b;
}

1D DP vs 2D DP — Kab kya use karein?
📐
DP Dimensions Guide
🇬🇧 English
1D DP: State depends on ONE variable (index i). Array dp[i].
Examples: Climbing stairs, House robber, Coin change.

2D DP: State depends on TWO variables (i, j). Matrix dp[i][j].
Examples: LCS, Edit distance, Grid path, 0/1 Knapsack (item index + capacity).
🇮🇳 Hinglish
1D DP: State ek variable par depend karta hai (index i). Array dp[i].
Examples: Climbing stairs, House robber, Coin change.

2D DP: State do variables par depend karta hai (i, j). Matrix dp[i][j].
Examples: LCS, Edit distance, Grid path, 0/1 Knapsack.
💡 DP banane ka formula: (1) State define karo — dp[i] ka matlab kya hai? (2) Transition likhо — dp[i] kaise banta hai? (3) Base case set karo. (4) Answer kahan hai?
Dynamic Programming · Pattern 1 of 6

📈 Linear DP (1D)

Single array dp[i] — state sirf ek index par depend karta hai. Climbing stairs se LIS tak.

dp[i] = f(dp[i-1]) O(n) or O(n²) 1D Array State
Problem 1 — Climbing Stairs
🪜
Climbing StairsLeetCode 70
🇬🇧 Intuition
You can climb 1 or 2 steps at a time. How many ways to reach step n?
dp[i] = number of ways to reach step i.
Transition: dp[i] = dp[i-1] + dp[i-2] (come from 1 below OR 2 below).
Base: dp[1]=1, dp[2]=2. It's literally Fibonacci!
🇮🇳 Hinglish
Ek ya do step ek baar mein chadh sakte ho. n steps tak kitne tarike?
dp[i] = step i tak pahunchne ke kitne ways hain.
Transition: dp[i] = dp[i-1] + dp[i-2] (ya ek neeche se aao ya do neeche se).
Base: dp[1]=1, dp[2]=2. Bilkul Fibonacci jaisa hai!
🔵 C++ · Climbing Stairs
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; i++) {
        int c = a + b;
        a = b; b = c;
    }
    return b;
}

Problem 2 — House Robber
🏠
House RobberLeetCode 198
🇬🇧 Intuition
Rob houses in a row — can't rob two adjacent houses. Maximize money.
dp[i] = max money robbing from house 0..i.
Transition: dp[i] = max(dp[i-1], dp[i-2] + nums[i]).
Either skip house i (take dp[i-1]) OR rob house i (take dp[i-2] + nums[i]).
🇮🇳 Hinglish
Line mein ghar loot lo — do adjacent ghar nahi loot sakte. Maximum money chahiye.
dp[i] = ghar 0 se i tak max kitna loot sakte hain.
Transition: dp[i] = max(dp[i-1], dp[i-2] + nums[i]).
Ya ghar i skip karo (dp[i-1] lo) YA ghar i loot lo (dp[i-2] + nums[i]).
🔵 C++ · House Robber
int rob(vector<int>& nums) {
    int n = nums.size();
    if (n == 1) return nums[0];
    int prev2 = nums[0], prev1 = max(nums[0], nums[1]);
    for (int i = 2; i < n; i++) {
        int curr = max(prev1,          // skip house i
                       prev2 + nums[i]); // rob house i
        prev2 = prev1;
        prev1 = curr;
    }
    return prev1;
}

Problem 3 — Longest Increasing Subsequence (LIS)
📊
LIS — Longest Increasing SubsequenceLeetCode 300
🇬🇧 Intuition
Find the length of the longest strictly increasing subsequence.
dp[i] = length of LIS ending at index i.
Transition: For each j < i, if nums[j] < nums[i]: dp[i] = max(dp[i], dp[j]+1).
Answer = max of all dp[i]. Time: O(n²). O(n log n) exists with binary search.
🇮🇳 Hinglish
Strictly increasing subsequence ki max length nikalo.
dp[i] = index i par khatam hone wali LIS ki length.
Transition: Har j < i ke liye, agar nums[j] < nums[i]: dp[i] = max(dp[i], dp[j]+1).
Answer = dp[] ka maximum. Time: O(n²). Binary search se O(n log n) bhi hota hai.
🔵 C++ · LIS O(n²)
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size(), ans = 1;
    vector<int> dp(n, 1);  // every element alone is LIS of length 1
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++) {
            if (nums[j] < nums[i])
                dp[i] = max(dp[i], dp[j] + 1);
        }
        ans = max(ans, dp[i]);
    }
    return ans;
}

Dynamic Programming · Pattern 2 of 6

🎒 Knapsack / Decision DP

Har item ke liye decision — lo ya chhodo. Classic interview pattern! 0/1 Knapsack + Unbounded + Subset Sum.

Take or Skip dp[i][w] O(n × W) Most Asked Pattern
0/1 Knapsack — Core Pattern
🎒
0/1 Knapsack
🇬🇧 Intuition
n items, each with weight[i] and value[i]. Knapsack capacity W. Max value you can carry?
Each item: either take it (0/1 = one copy) or skip it.
dp[i][w] = max value using first i items with capacity w.
Transition:
— If weight[i] > w: dp[i][w] = dp[i-1][w] (can't take)
— Else: dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i]] + val[i])
🇮🇳 Hinglish
n items hain, har item ka weight[i] aur value[i] hai. Bag ki capacity W hai. Max value?
Har item: ya lo (ek hi baar) ya chhodo.
dp[i][w] = pehle i items use karke capacity w mein max value.
Transition:
— Agar weight[i] > w: dp[i][w] = dp[i-1][w] (le nahi sakte)
— Nahi toh: dp[i][w] = max(dp[i-1][w], dp[i-1][w-wt[i]] + val[i])
🔵 C++ · 0/1 Knapsack
int knapsack01(int W, vector<int>& wt, vector<int>& val, int n) {
    vector<vector<int>> dp(n+1, vector<int>(W+1, 0));
    for (int i = 1; i <= n; i++) {
        for (int w = 0; w <= W; w++) {
            dp[i][w] = dp[i-1][w];  // skip item i
            if (wt[i-1] <= w)
                dp[i][w] = max(dp[i][w],
                    dp[i-1][w - wt[i-1]] + val[i-1]); // take item i
        }
    }
    return dp[n][W];
}

Unbounded Knapsack — Coin Change
🪙
Coin Change — Unbounded KnapsackLeetCode 322
🇬🇧 Intuition
Given coin denominations, find min coins to make amount.
Unbounded = each coin can be used unlimited times.
dp[w] = min coins to make amount w.
Transition: dp[w] = min(dp[w], dp[w - coin] + 1) for each coin.
Key difference from 0/1: inner loop uses dp[w - coin] (current row, not previous).
🇮🇳 Hinglish
Coins di hain, amount banane ke liye minimum coins chahiye.
Unbounded = ek coin unlimited baar use kar sakte hain.
dp[w] = amount w banane ke liye min coins.
Transition: dp[w] = min(dp[w], dp[w - coin] + 1) har coin ke liye.
0/1 se fark: current row ka use karo (same item dobara lene ki permission hai).
🔵 C++ · Coin Change
int coinChange(vector<int>& coins, int amount) {
    vector<int> dp(amount+1, INT_MAX);
    dp[0] = 0;  // 0 coins to make amount 0
    for (int w = 1; w <= amount; w++) {
        for (int c : coins) {
            if (c <= w && dp[w-c] != INT_MAX)
                dp[w] = min(dp[w], dp[w-c] + 1);
        }
    }
    return dp[amount] == INT_MAX ? -1 : dp[amount];
}

Subset Sum / Partition Equal Subset
⚖️
Partition Equal Subset SumLeetCode 416
🇬🇧 Intuition
Can we partition array into two subsets with equal sum?
Total sum must be even. Then: can we find a subset with sum = total/2?
dp[w] = true if subset with sum w is possible.
Transition: dp[w] |= dp[w - num]. Loop w from target → num (to avoid reuse).
🇮🇳 Hinglish
Array ko do equal-sum subsets mein todna hai?
Total sum even hona chahiye. Phir check karo: kya sum = total/2 ka subset banta hai?
dp[w] = true agar w sum ka subset possible hai.
Transition: dp[w] |= dp[w - num]. w ko target se num tak reverse mein loop karo.
🔵 C++ · Partition Equal Subset
bool canPartition(vector<int>& nums) {
    int total = accumulate(nums.begin(), nums.end(), 0);
    if (total % 2 != 0) return false;
    int target = total / 2;
    vector<bool> dp(target+1, false);
    dp[0] = true;  // empty subset makes sum 0
    for (int num : nums) {
        for (int w = target; w >= num; w--)  // reverse loop! 0/1 property
            dp[w] = dp[w] || dp[w - num];
    }
    return dp[target];
}
⚠️ Reverse loop kyun? 0/1 Knapsack mein har item sirf ek baar use hona chahiye. Agar forward loop karoge toh same item multiple times use ho sakta hai. Reverse se ensure hota hai ki current item phir se na lage.
Dynamic Programming · Pattern 3 of 6

🔤 Sequence DP (2D)

Do strings ya sequences par DP. dp[i][j] state — i characters of s1, j characters of s2. LCS, Edit Distance, Grid.

dp[i][j] State Two Strings O(m×n)
LCS — Longest Common Subsequence
🔤
LCSLeetCode 1143
🇬🇧 Intuition
Find length of longest subsequence common to both strings.
dp[i][j] = LCS length of s1[0..i-1] and s2[0..j-1].
Transition:
— If s1[i-1] == s2[j-1]: dp[i][j] = dp[i-1][j-1] + 1 (both chars match!)
— Else: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) (skip one char from either)
🇮🇳 Hinglish
Dono strings mein jo common subsequence hai uski max length nikalo.
dp[i][j] = s1 ke pehle i chars aur s2 ke pehle j chars ka LCS.
Transition:
— Agar s1[i-1] == s2[j-1]: dp[i][j] = dp[i-1][j-1] + 1 (match mila!)
— Warna: dp[i][j] = max(dp[i-1][j], dp[i][j-1]) (ek string se ek char skip karo)
🔵 C++ · LCS
int longestCommonSubsequence(string s1, string s2) {
    int m = s1.size(), n = s2.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1, 0));
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (s1[i-1] == s2[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}

Edit Distance
✏️
Edit Distance (Levenshtein)LeetCode 72
🇬🇧 Intuition
Min operations (insert, delete, replace) to convert word1 to word2.
dp[i][j] = min ops to convert word1[0..i-1] to word2[0..j-1].
Transition:
— If chars match: dp[i][j] = dp[i-1][j-1] (no operation needed)
— Else: dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) (delete, insert, replace)
🇮🇳 Hinglish
word1 ko word2 mein convert karne ke liye minimum operations (insert, delete, replace).
dp[i][j] = word1 ke i chars ko word2 ke j chars mein convert karne ke min ops.
Transition:
— Agar chars match: dp[i][j] = dp[i-1][j-1] (kuch nahi karna)
— Warna: dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) (delete, insert, replace)
🔵 C++ · Edit Distance
int minDistance(string w1, string w2) {
    int m = w1.size(), n = w2.size();
    vector<vector<int>> dp(m+1, vector<int>(n+1));
    for (int i = 0; i <= m; i++) dp[i][0] = i;  // delete all
    for (int j = 0; j <= n; j++) dp[0][j] = j;  // insert all
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (w1[i-1] == w2[j-1])
                dp[i][j] = dp[i-1][j-1];
            else
                dp[i][j] = 1 + min({dp[i-1][j],    // delete
                                      dp[i][j-1],    // insert
                                      dp[i-1][j-1]}); // replace
        }
    }
    return dp[m][n];
}

Dynamic Programming · Pattern 4 of 6

✂️ Partition / Interval DP

String ya array ke kisi bhi point par partition karo. dp[i][j] = subarray i to j ka answer. MCM, Palindrome, Burst Balloons.

dp[i][j] Interval Cut at every k O(n³)
Matrix Chain Multiplication — Classic Interval DP
🔢
Matrix Chain Multiplication
🇬🇧 Intuition
Given n matrices, find min cost to multiply them all (by choosing bracket order).
dp[i][j] = min cost to multiply matrices from i to j.
Transition: Try every split point k: dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j]).
Fill by increasing length of intervals (len=2, 3, ... n).
🇮🇳 Hinglish
n matrices hain, unhe multiply karne ka min cost nikalo (bracket order choose karke).
dp[i][j] = i se j tak matrices multiply karne ka min cost.
Transition: Har split point k try karo: dp[i][j] = min(dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j]).
Increasing length se fill karo (len=2, 3, ... n).
🔵 C++ · Matrix Chain Multiplication
int mcm(vector<int>& p) {   // p has n+1 values for n matrices
    int n = p.size() - 1;
    vector<vector<int>> dp(n+1, vector<int>(n+1, 0));
    for (int len = 2; len <= n; len++) {     // interval length
        for (int i = 1; i <= n-len+1; i++) {
            int j = i + len - 1;
            dp[i][j] = INT_MAX;
            for (int k = i; k < j; k++) {       // try all splits
                dp[i][j] = min(dp[i][j],
                    dp[i][k] + dp[k+1][j] + p[i-1]*p[k]*p[j]);
            }
        }
    }
    return dp[1][n];
}
Burst Balloons — Interval DP
🎈
Burst BalloonsLeetCode 312
🇬🇧 Intuition
Burst balloons to maximize coins. Bursting balloon i gives nums[i-1]*nums[i]*nums[i+1] coins.
Key insight: Think reverse — which balloon is burst last in range [i,j]?
dp[i][j] = max coins from bursting all balloons between i and j (exclusive).
Transition: dp[i][j] = max over k: dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j].
🇮🇳 Hinglish
Balloons burst karo, max coins chahiye. Balloon i burst karne par nums[i-1]*nums[i]*nums[i+1] coins milte hain.
Key insight: Ulta socho — range [i,j] mein last kaun burst hoga?
dp[i][j] = i aur j ke beech ke sab balloons burst karne par max coins.
Transition: dp[i][j] = max over k: dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j].
💡 Interval DP pattern: Jab bhi "range/interval mein koi action karo" wala problem ho aur optimal bracket/split order chahiye — Interval DP try karo. O(n³) expected.
Palindrome Partitioning — Min Cuts
🔁
Palindrome Partitioning IILeetCode 132
🇬🇧 Intuition
Min cuts to make every substring a palindrome.

🚀 Advanced DP

Hard-level patterns — Bitmask DP (subsets), Digit DP (number range), DP on Trees. Competitive programming aur FAANG hard rounds mein aate hain.

Bitmask Digit DP Tree DP Hard Level
Bitmask DP — TSP / Assignment Problems
🔢
Bitmask DP — Travelling Salesman Problem
🇬🇧 English
Use a bitmask to represent which subset of nodes/items has been visited/used.
dp[mask][i] = min cost to visit all nodes in mask, ending at node i.
Transition: For each unvisited node j: dp[mask|(1<<j)][j] = min(..., dp[mask][i] + cost[i][j]).
Used when n ≤ 20 (2^20 states). Classic: TSP, Job assignment, Hamiltonian path.
🇮🇳 Hinglish
Bitmask se represent karo ki kaun kaun se nodes visit ho chuke hain.
dp[mask][i] = mask wale sab nodes visit karke node i par khatam hone ka min cost.
Transition: Har unvisited j ke liye: dp[mask|(1<<j)][j] = min(..., dp[mask][i] + cost[i][j]).
Jab n ≤ 20 ho tab use karo (2^20 states). Classic problems: TSP, Job assignment.
🔵 C++ · TSP with Bitmask DP
int tsp(vector<vector<int>>& cost, int n) {
    int FULL = (1<<n) - 1;
    vector<vector<int>> dp(1<<n, vector<int>(n, INT_MAX));
    dp[1][0] = 0;  // start at node 0, mask = 0001
    for (int mask = 1; mask <= FULL; mask++) {
        for (int u = 0; u < n; u++) {
            if (!(mask >> u & 1) || dp[mask][u] == INT_MAX) continue;
            for (int v = 0; v < n; v++) {
                if (mask >> v & 1) continue; // already visited
                int nmask = mask | (1<<v);
                dp[nmask][v] = min(dp[nmask][v], dp[mask][u] + cost[u][v]);
            }
        }
    }
    int ans = INT_MAX;
    for (int u = 1; u < n; u++)
        ans = min(ans, dp[FULL][u] + cost[u][0]); // return to start
    return ans;
}
ℹ️ Bitmask DP — Common operations:
mask | (1<<i) = set bit i (mark i as visited)
mask & (1<<i) = check if bit i set (is i visited?)
mask ^ (1<<i) = toggle bit i
mask & (-mask) = lowest set bit (rightmost visited node)
Digit DP — Count numbers in range with property
🔢
Digit DP — Numbers with no repeated digits
🇬🇧 English
Count numbers in range [1, N] with some digit property.
Build the number digit by digit. State: (position, tight_constraint, extra_property).
tight = are we still bounded by N's digits? Once we place a smaller digit, tight = false.
Common properties: no repeated digits, digit sum = k, count of specific digit ≤ k.
🇮🇳 Hinglish
Range [1, N] mein kitne numbers mein koi property hai — count karo.
Number digit by digit banao. State: (position, tight, extra_property).
tight = kya hum abhi bhi N se bound hain? Ek baar chhota digit rakh diya toh tight = false.
Common: no repeated digits, digit sum = k, specific digit ≤ k times.
🔵 C++ · Digit DP Template
string num;
int memo[20][2][2];  // [pos][tight][started]

int solve(int pos, bool tight, bool started) {
    if (pos == num.size()) return started ? 1 : 0;
    if (memo[pos][tight][started] != -1)
        return memo[pos][tight][started];
    int limit = tight ? (num[pos]-'0') : 9;
    int res = 0;
    for (int d = 0; d <= limit; d++) {
        // add your condition here, e.g., no repeated digit
        res += solve(pos+1, tight && (d==limit), started || d!=0);
    }
    return memo[pos][tight][started] = res;
}
// call: memset(memo,-1,sizeof(memo)); solve(0,true,false);
DP on Trees
🌳
DP on Trees — Diameter / Max Independent Set
🇬🇧 English
Run DFS on tree, compute DP values bottom-up (leaf to root).
Each node's DP value depends on its children's values.
Classic: Tree diameter, Max independent set on tree, Tree knapsack.
dp[node][0] = answer without taking node, dp[node][1] = with taking node.
🇮🇳 Hinglish
Tree par DFS chalao, DP values bottom-up compute karo (leaf se root tak).
Har node ki DP value uske children ki values se banti hai.
Classic: Tree diameter, Max independent set on tree, Tree knapsack.
dp[node][0] = node liye bina, dp[node][1] = node lekar answer.
🔵 C++ · Max Independent Set on Tree
vector<int> adj[100005];
int dp[100005][2];  // dp[node][0/1] = max nodes without/with node

void dfs(int u, int par) {
    dp[u][0] = 0;  // don't take u
    dp[u][1] = 1;  // take u
    for (int v : adj[u]) {
        if (v == par) continue;
        dfs(v, u);
        dp[u][0] += max(dp[v][0], dp[v][1]);  // child can be taken or not
        dp[u][1] += dp[v][0];               // if u taken, child can't be taken
    }
}
// answer = max(dp[root][0], dp[root][1])

Common DP Mistakes
⚠️ 0/1 Knapsack: Inner loop ko reverse karna mat bhoolo (target → 0). Forward loop chalane se ek item multiple times use ho jaata hai — Unbounded ban jaata hai!
⚠️ Interval DP: Length ke order mein fill karo, random order mein nahi. Chhote intervals pehle solve honge toh bade intervals unhe use kar payenge.
⚠️ State Definition: dp[i] ka meaning clearly define nahi kiya toh transitions galat ho jaate hain. Pehle state define karo, tab code likho.
⚠️ Base Cases: Bade problems mein base cases miss ho jaate hain. Empty string, 0 items, 0 capacity — sab explicitly set karo.
💡 Memoization shortcut: Agar recursion already likh li hai, sirf ek map/array add karo: if memo[state] exists: return it. Top-down DP instant ban jaata hai!
💡 Space Optimization: Agar dp[i] sirf dp[i-1] par depend karta hai → 1D array use karo. Agar dp[i][j] sirf dp[i-1][...] par depend karta hai → 1D rolling array use karo!
