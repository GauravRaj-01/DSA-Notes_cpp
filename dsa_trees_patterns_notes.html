Tree Traversal

🌳

struct TreeNode {
    int val;

    TreeNode* right;

DFS — Pre / In / Post Order
🔽
DFS TraversalsRecursive + Iterative
🇬🇧 English
DFS dives deep before going wide. Three orders based on when you visit the root:
• Preorder: Root → Left → Right (copy tree, prefix expression)
• Inorder: Left → Root → Right (BST mein sorted order deta hai)
• Postorder: Left → Right → Root (delete tree, height calculate)
🇮🇳 Hinglish
DFS pehle depth mein jaata hai. Teen orders hain — root kab visit karo iske basis pe:
• Preorder: Pehle root, phir left, phir right → "Root pehle!"
• Inorder: Left, phir root, phir right → BST mein sorted result deta hai
• Postorder: Left, right, phir root → "Root baad mein!" — height/delete ke liye

🔵 C++ · DFS — Recursive (Teeno ek saath)
// PREORDER: Root → Left → Right
void preorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    res.push_back(root->val);   // pehle root visit karo
    preorder(root->left, res);
    preorder(root->right, res);
}

// INORDER: Left → Root → Right (BST mein sorted order!)
void inorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    inorder(root->left, res);
    res.push_back(root->val);   // beech mein root
    inorder(root->right, res);
}

// POSTORDER: Left → Right → Root
void postorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    postorder(root->left, res);
    postorder(root->right, res);
    res.push_back(root->val);   // last mein root
}
🔵 C++ · DFS — Iterative using Stack
// Iterative Inorder (stack use karke)
vector<int> inorderIterative(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> st;
    TreeNode* curr = root;

    while (curr || !st.empty()) {
        while (curr) {
            st.push(curr);          // left mein jaate waqt stack mein daalo
            curr = curr->left;
        }
        curr = st.top(); st.pop();  // leftmost node process karo
        res.push_back(curr->val);
        curr = curr->right;         // ab right subtree
    }
    return res;
}

// Iterative Preorder (much simpler)
vector<int> preorderIterative(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    stack<TreeNode*> st;
    st.push(root);
    while (!st.empty()) {
        TreeNode* node = st.top(); st.pop();
        res.push_back(node->val);   // pehle process karo
        if (node->right) st.push(node->right); // right pehle push (LIFO)
        if (node->left)  st.push(node->left);
    }
    return res;
}
💡 Yaad rakhne ka trick: Preorder = Root Prefix (pehle). Inorder = Root In middle (beech mein). Postorder = Root Post (baad mein).
BFS — Level Order Traversal
📶
Level Order BFSLeetCode 102
🇬🇧 English
BFS uses a queue. Process all nodes at the current level before moving to the next. At each level, record queue size first — that's how many nodes are at this level. Process exactly that many nodes, then move on.
🇮🇳 Hinglish
Queue use karo. Ek level ke saare nodes process karo pehle, phir next level pe jao. Trick: level shuru hone pe queue ka size note karo — utne hi nodes is level mein hain. Utne process karo, phir baaki next level ke hain.
BFS on Tree: root=1, left=2, right=3, ...
Level 0
Queue: [1] → size=1 → process 1 → add children 2,3
[[1]]
Level 1
Queue: [2,3] → size=2 → process 2(add 4,5), 3(add 6,7)
[[1],[2,3]]
Level 2
Queue: [4,5,6,7] → size=4 → process all → no children
[[1],[2,3],[4,5,6,7]]
🔵 C++ · BFS Level Order
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;

    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int levelSize = q.size(); // is level mein kitne nodes hain!
        vector<int> level;

        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left)  q.push(node->left);  // next level ke liye
            if (node->right) q.push(node->right);
        }
        result.push_back(level);
    }
    return result;
}
💡 BFS ka core: Queue + levelSize trick. int levelSize = q.size() — yeh line level boundary mark karti hai. Iske bina sab ek hi vector mein mix ho jaayenge!
BFS Variations — Zigzag & Right Side View
↔️
Zigzag Level Order + Right Side ViewLC 103 · LC 199
Dono BFS ke variations hain. Zigzag mein alternate levels ko reverse karo. Right Side View mein har level ka last node lo — woh right se dikhega.
🔵 C++ · Zigzag Level Order
vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
    vector<vector<int>> result;
    if (!root) return result;
    queue<TreeNode*> q;
    q.push(root);
    bool leftToRight = true;

    while (!q.empty()) {
        int sz = q.size();
        vector<int> level(sz);

        for (int i = 0; i < sz; i++) {
            TreeNode* node = q.front(); q.pop();
            // direction ke hisaab se index set karo
            int idx = leftToRight ? i : (sz - 1 - i);
            level[idx] = node->val;
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);
        leftToRight = !leftToRight; // har level pe direction flip karo!
    }
    return result;
}

// Right Side View — har level ka last node
vector<int> rightSideView(TreeNode* root) {
    vector<int> result;
    if (!root) return result;
    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int sz = q.size();
        for (int i = 0; i < sz; i++) {
            TreeNode* node = q.front(); q.pop();
            if (i == sz - 1) result.push_back(node->val); // last = rightmost
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
    }
    return result;
}
💡 Zigzag trick: Reverse karne ki zaroorat nahi — sirf index leftToRight ? i : sz-1-i se directly sahi jagah dalo. Bohot efficient!
Trees Patterns · Pattern 2 of 4

Recursion Patterns

Tree problems mein do main recursion approaches — Top Down (pass info neeche) aur Bottom Up (collect info upar).

Top Down · Pass params Bottom Up · Return values
🧠
Core Concept — Do approaches
🇬🇧 English
Top Down: Pass information from parent to children via function parameters. Like preorder — process parent first, then recurse.

Bottom Up: Get information from children, combine at current node, return to parent. Like postorder — process children first, then current node.
🇮🇳 Hinglish
Top Down: Parent se information parameters mein neeche bhejo. Root se shuru, leaf tak jaao. "Main root hoon, meri depth 0 hai — tumhari 1 hogi" — yeh top down hai.

Bottom Up: Pehle children se information lo, upar return karo. "Mujhe apna height nahi pata, pehle apne bachon se poochhta hoon" — yeh bottom up hai.
Top Down kab use karein?Path sum check, max depth with path tracking, root-to-leaf problems. Parent ka state child ko chahiye.
Bottom Up kab use karein?Height, diameter, max path sum. Child ka result combine karke parent ko dena ho.
Top Down Approach
⬇️
Path Sum — Root to LeafLeetCode 112
Root se leaf tak jaate hain, remaining target ko parameter mein le jaate hain. Leaf node pe check karo kya remaining == node.val. Parent ki information neeche pass ho rahi hai — Top Down!

🔵 C++ · Path Sum (Top Down)
bool hasPathSum(TreeNode* root, int target) {
    if (!root) return false;

    // Leaf node pe check karo
    if (!root->left && !root->right)
        return root->val == target;

    // Remaining target neeche pass karo (Top Down!)
    return hasPathSum(root->left, target - root->val) ||
           hasPathSum(root->right, target - root->val);
}

// Path Sum II — saare valid paths collect karo
void dfs(TreeNode* node, int rem, vector<int>& path,
         vector<vector<int>>& res) {
    if (!node) return;
    path.push_back(node->val);

    if (!node->left && !node->right && rem == node->val)
        res.push_back(path);                 // valid path mila!

    dfs(node->left,  rem - node->val, path, res);
    dfs(node->right, rem - node->val, path, res);
    path.pop_back();                         // backtrack — path se hatao
}
📏
Max Depth of Binary TreeLeetCode 104
Top down: depth parameter pass karo. Bottom up: children se height lo, max+1 return karo. Dono work karte hain — bottom up zyada clean hai.
🔵 C++ · Max Depth — Top Down & Bottom Up
// Bottom Up (zyada common aur clean)
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    int leftH  = maxDepth(root->left);   // left child se pucho
    int rightH = maxDepth(root->right);  // right child se pucho
    return max(leftH, rightH) + 1;       // max lo + apne aap ko add karo
}

// Top Down version (depth parameter pass karo)
int maxD = 0;
void dfsDepth(TreeNode* root, int depth) {
    if (!root) return;
    maxD = max(maxD, depth);              // abhi tak ki max depth track karo
    dfsDepth(root->left,  depth + 1);  // depth+1 neeche pass karo
    dfsDepth(root->right, depth + 1);
}
Bottom Up Approach
⬆️
Symmetric Tree + Same TreeLeetCode 101 · 100
Dono subtrees ko compare karo — bottom up mein har node apna result return karta hai. Symmetric mein left aur right mirror image hone chahiye. Same tree mein structure + values dono same.
🔵 C++ · Symmetric Tree + Same Tree
// Same Tree
bool isSameTree(TreeNode* p, TreeNode* q) {
    if (!p && !q) return true;           // dono null → same
    if (!p || !q) return false;          // ek null ek nahi → different
    if (p->val != q->val) return false;  // values different
    return isSameTree(p->left, q->left) &&
           isSameTree(p->right, q->right);
}

// Symmetric Tree — left subtree = mirror of right
bool isMirror(TreeNode* l, TreeNode* r) {
    if (!l && !r) return true;
    if (!l || !r) return false;
    // Values match karni chahiye aur subtrees mirror honni chahiye
    return (l->val == r->val) &&
           isMirror(l->left,  r->right) &&
           isMirror(l->right, r->left);
}

bool isSymmetric(TreeNode* root) {
    return !root || isMirror(root->left, root->right);
}

// Invert Binary Tree (Bottom Up classic)
TreeNode* invertTree(TreeNode* root) {
    if (!root) return nullptr;
    TreeNode* left  = invertTree(root->left);   // pehle children invert karo
    TreeNode* right = invertTree(root->right);
    root->left  = right;  // phir swap karo
    root->right = left;
    return root;
}
💡 Bottom Up pattern: Base case → children se result lo → combine → return. Preorder nahi, postorder style mein socho!

Path Based Problems

Tree mein paths ke saath kaam karna — max sum, diameter, height. Aksar global variable + bottom up recursion use hoti hai.

Max Path Sum · LC 124 Diameter · LC 543 Height / Depth
💡
Core Insight — Global Variable Pattern
🇬🇧 English
Path problems often need a global variable to track the answer, while the recursive function returns something different (like single-arm contribution). The function and the answer are two different things — this is the key insight!
🇮🇳 Hinglish
Path problems mein ek global variable answer track karta hai. Recursive function kuch alag return karta hai (single path). Yeh do cheezein alag hain — yahi sabse bada confusion point hai! Function jo return karta hai aur final answer alag hote hain.
Max Path Sum
📈
Binary Tree Maximum Path SumLeetCode 124 · Hard
🇬🇧 Intuition
A path can go: left subtree → current node → right subtree (cannot pass through parent).

The recursive function returns max gain from one arm (left or right, not both — can't branch). But we compute left + node + right locally and update the global max. If a subtree gives negative gain, ignore it (take 0).
🇮🇳 Hinglish
Path teen tarah se ho sakta hai: sirf left, sirf right, ya left+node+right. Par function sirf ek arm return karta hai (parent ke liye).

Har node pe: localMax = left + node.val + right se global max update karo. Function sirf node.val + max(left, right) return kare — parent use karegi. Negative gain? 0 le lo (us branch ko ignore karo).
Tree: -10→(9, 20→(15, 7)) → Expected: 42
node=15
Leaf. left=0, right=0. localMax=15. return 15
gain=15
node=7
Leaf. return 7
gain=7
node=20
left=15, right=7. localMax=15+20+7=42 → globalMax=42. return 20+max(15,7)=35
globalMax=42!
node=9
Leaf. return 9
gain=9
root=-10
left=9, right=35. localMax=9+(-10)+35=34 < 42. globalMax stays 42
✅ return 42
🔵 C++ · Binary Tree Maximum Path Sum
int globalMax;

int gain(TreeNode* node) {
    if (!node) return 0;

    // Negative gain? 0 lo — us branch ko ignore karo
    int leftGain  = max(0, gain(node->left));
    int rightGain = max(0, gain(node->right));

    // Is node se guzarne wale path ka max sum (dono arms + node)
    int localMax = node->val + leftGain + rightGain;
    globalMax = max(globalMax, localMax); // global answer update karo

    // Parent ke liye sirf ek arm return karo (branch nahi kar sakte)
    return node->val + max(leftGain, rightGain);
}

int maxPathSum(TreeNode* root) {
    globalMax = INT_MIN;
    gain(root);
    return globalMax;
}
⚠️ Function jo return karta hai (single arm) aur globalMax alag hain — yahi confusion hota hai. Function parent ke liye single path return karta hai, answer alag track hota hai!

🔵 C++ · Diameter + Height
// Diameter of Binary Tree
int dia = 0;

int height(TreeNode* node) {
    if (!node) return 0;
    int l = height(node->left);
    int r = height(node->right);
    dia = max(dia, l + r);    // is node se guzarne wali diameter
    return max(l, r) + 1;    // parent ke liye height return karo
}

int diameterOfBinaryTree(TreeNode* root) {
    dia = 0;
    height(root);
    return dia;
}

// Balanced Binary Tree check (LeetCode 110)
int checkHeight(TreeNode* node) {
    if (!node) return 0;
    int l = checkHeight(node->left);
    if (l == -1) return -1;   // already unbalanced signal
    int r = checkHeight(node->right);
    if (r == -1) return -1;
    if (abs(l - r) > 1) return -1; // unbalanced! -1 signal upar bhejo
    return max(l, r) + 1;
}

bool isBalanced(TreeNode* root) {
    return checkHeight(root) != -1;
}
💡 Diameter aur Max Path Sum same pattern follow karte hain: function height/gain return kare, global variable answer track kare. Ek hi traversal mein dono!
🔗
Lowest Common Ancestor (LCA)LeetCode 236
Tree mein do nodes ka sabse lower common ancestor dhundho. Agar current node p ya q hai → return current. Agar left aur right dono ne kuch return kiya → current node hi LCA hai!
🔵 C++ · Lowest Common Ancestor
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root; // mil gaya

    TreeNode* left  = lowestCommonAncestor(root->left,  p, q);
    TreeNode* right = lowestCommonAncestor(root->right, p, q);

    // Dono sides se kuch mila → current node LCA hai!
    if (left && right) return root;

    // Sirf ek side se mila → wahi return karo
    return left ? left : right;
}
Trees Patterns · Pattern 4 of 4

Binary Search Tree (BST)

BST mein left < root < right. Yeh property har operation ko O(log n) average mein deti hai. Inorder traversal sorted order deta hai!

Search O(log n) Insert O(log n) Delete O(log n) Inorder = Sorted
🌲
BST Property — Core Rule
🇮🇳 Hinglish
BST ka golden rule: har node ke liye — left subtree mein sab chhote, right subtree mein sab bade. Sirf direct children nahi — poora subtree! Isliye search O(log n) hota hai — har step pe half eliminate ho jaata hai.
BST Example — Inorder: [1, 3, 4, 6, 7, 8, 10]

🔵 C++ · BST Search + Insert
// BST Search
TreeNode* searchBST(TreeNode* root, int val) {
    if (!root || root->val == val) return root;
    if (val < root->val)
        return searchBST(root->left, val);   // left mein jao
    return searchBST(root->right, val);     // right mein jao
}

// BST Insert
TreeNode* insertIntoBST(TreeNode* root, int val) {
    if (!root) return new TreeNode(val); // sahi jagah mili — insert!
    if (val < root->val)
        root->left  = insertIntoBST(root->left, val);
    else
        root->right = insertIntoBST(root->right, val);
    return root;
}

// BST Delete — 3 cases!
TreeNode* deleteNode(TreeNode* root, int key) {
    if (!root) return nullptr;

    if (key < root->val)
        root->left  = deleteNode(root->left, key);
    else if (key > root->val)
        root->right = deleteNode(root->right, key);
    else {
        // Case 1: Leaf node → seedha delete karo
        if (!root->left && !root->right) return nullptr;
        // Case 2: Ek hi child → us child se replace karo
        if (!root->left)  return root->right;
        if (!root->right) return root->left;
        // Case 3: Do children → inorder successor (right ka leftmost) se replace karo
        TreeNode* succ = root->right;
        while (succ->left) succ = succ->left;  // right subtree ka min
        root->val   = succ->val;              // value replace karo
        root->right = deleteNode(root->right, succ->val); // successor delete
    }
    return root;
}
⚠️ Delete ke 3 cases yaad rakho: (1) Leaf → null. (2) One child → replace. (3) Two children → inorder successor se replace karo!

Validate Binary Search TreeLeetCode 98

Wrong approach: sirf direct children compare → fail on [5, 1, 4, null, null, 3, 6]
Problem
root=5, right=4 → 4<5 ye toh galat hai. Par agar 5→(3→(1,4), 7) — node 4 locally 1<4<3 looks ok but globally 4>3=parent → INVALID!
range check zaroori!
🔵 C++ · Validate BST (Min-Max Range)
bool validate(TreeNode* node, long long minVal, long long maxVal) {
    if (!node) return true;
    // Node ki value valid range mein honi chahiye
    if (node->val <= minVal || node->val >= maxVal) return false;

    // Left: max bound update karo (node.val se kam hona chahiye)
    // Right: min bound update karo (node.val se zyada hona chahiye)
    return validate(node->left,  minVal, node->val) &&
           validate(node->right, node->val, maxVal);
}

bool isValidBST(TreeNode* root) {
    return validate(root, LLONG_MIN, LLONG_MAX); // long long use karo overflow ke liye
}

// Alternate: Inorder traversal sorted honi chahiye
bool isValidBSTInorder(TreeNode* root) {
    long long prev = LLONG_MIN;
    function<bool(TreeNode*)> inorder = [&](TreeNode* node) -> bool {
        if (!node) return true;
        if (!inorder(node->left)) return false;
        if (node->val <= prev) return false; // sorted nahi → invalid
        prev = node->val;
        return inorder(node->right);
    };
    return inorder(root);
}
💡 Validate BST = min-max range pass karo. Ya inorder traversal strictly increasing honi chahiye. Dono O(n) hain.
Kth Smallest + Other BST Problems
🔢
Kth Smallest + BST to Sorted ArrayLeetCode 230
BST ka inorder traversal = sorted order. Kth smallest = inorder traversal mein kth element. Counter use karo — kth element milte hi return karo, poora traversal karne ki zaroorat nahi.
🔵 C++ · Kth Smallest + BST Operations
// Kth Smallest in BST
int cnt, ans;
void inorderK(TreeNode* node, int k) {
    if (!node || cnt >= k) return;
    inorderK(node->left, k);
    cnt++;                              // ek aur node visit hua
    if (cnt == k) { ans = node->val; return; } // kth mila!
    inorderK(node->right, k);
}

int kthSmallest(TreeNode* root, int k) {
    cnt = 0; ans = -1;
    inorderK(root, k);
    return ans;
}

// Convert Sorted Array to BST (LeetCode 108)
TreeNode* sortedArrayToBST(vector<int>& nums, int l, int r) {
    if (l > r) return nullptr;
    int mid = l + (r - l) / 2;
    TreeNode* root = new TreeNode(nums[mid]); // middle = root (balanced)
    root->left  = sortedArrayToBST(nums, l, mid - 1);
    root->right = sortedArrayToBST(nums, mid + 1, r);
    return root;
}

// Lowest Common Ancestor in BST (simpler than general LCA!)
TreeNode* lcaBST(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (p->val < root->val && q->val < root->val)
        return lcaBST(root->left, p, q);   // dono left mein
    if (p->val > root->val && q->val > root->val)
        return lcaBST(root->right, p, q);  // dono right mein
    return root;                             // split point = LCA!
}
💡 BST LCA bahut simple hai — BST property use karo. Agar dono nodes ek taraf hain toh us taraf jao. Split hote hi current node LCA hai!
