Graph Representation
🇬🇧 English
Adjacency List (preferred): vector<vector<int>> adj(V). Space O(V+E). Fast neighbor traversal.
Adjacency Matrix: int mat[V][V]. Space O(V²). Fast edge check O(1) but wastes space for sparse graphs.

🇮🇳 Hinglish

🔍 Traversal — BFS & DFS

Graph ke saare nodes visit karo. BFS = level by level (queue). DFS = depth first (stack/recursion).

BFS = Queue DFS = Recursion/Stack O(V+E) both
🌊
BFS — Breadth First Search
🇬🇧 English
Use a queue. Enqueue start node, mark visited. While queue not empty: dequeue node, process, enqueue unvisited neighbors. Visits all nodes at distance 1, then 2, etc. Guarantees shortest path in unweighted graph.
🇮🇳 Hinglish
Queue use karo. Start node enqueue karo, visited mark karo. Queue khali na ho tab tak: dequeue, process, unvisited neighbors enqueue karo. Pehle distance 1 wale, phir 2 wale. Unweighted graph mein shortest path guarantee!

🔵 C++ · BFS Template
void bfs(int start, vector<vector<int>>& adj, int V) {
    vector<bool> visited(V, false);
    queue<int> q;
    q.push(start); visited[start] = true;

    while (!q.empty()) {
        int node = q.front(); q.pop();
        cout << node << " ";                 // process node

        for (int nb : adj[node]) {
            if (!visited[nb]) {
                visited[nb] = true;
                q.push(nb);
            }
        }
    }
}

// Disconnected graph handle karo (multiple components)
for (int i = 0; i < V; i++)
    if (!visited[i]) bfs(i, adj, V);
💡 BFS = shortest path in unweighted graph. DFS = connected components, cycle detection, topological sort. Dono O(V+E) hain!
DFS — Depth First Search
🌀
DFS — Depth First Search
🇬🇧 English
Use recursion (or explicit stack). Visit a node, mark visited, recurse on all unvisited neighbors. Goes as deep as possible before backtracking. Used for: cycle detection, topological sort, connected components, path finding.
🇮🇳 Hinglish
Recursion use karo. Node visit karo, visited mark karo, unvisited neighbors pe recurse karo. Jitna deep ja sako jao, phir backtrack karo. Use: cycle detection, topo sort, connected components, path finding.
🔵 C++ · DFS Template (Recursive + Iterative)
// ══ Recursive DFS ══
void dfs(int node, vector<vector<int>>& adj,
         vector<bool>& visited) {
    visited[node] = true;
    cout << node << " ";

    for (int nb : adj[node])
        if (!visited[nb])
            dfs(nb, adj, visited);
}

// ══ Iterative DFS (explicit stack) ══
void dfsIterative(int start, vector<vector<int>>& adj, int V) {
    vector<bool> visited(V, false);
    stack<int> st;
    st.push(start);

    while (!st.empty()) {
        int node = st.top(); st.pop();
        if (visited[node]) continue;
        visited[node] = true;
        cout << node << " ";
        for (int nb : adj[node])
            if (!visited[nb]) st.push(nb);
    }
}
// Connected components: loop over all nodes, call dfs if !visited
BFS best forShortest path (unweighted), level order, min hops, flood fill distance
DFS best forCycle detection, topo sort, connected components, maze solving, SCC

🔄 Cycle Detection

Directed aur Undirected graphs mein cycle dhundho — dono ke liye alag approach.

Directed: DFS color Undirected: Parent track DSU alternate
➡️
Cycle in Directed Graph (DFS 3-color)
🇬🇧 English
Use 3 states: WHITE(0)=unvisited, GRAY(1)=in current DFS path, BLACK(2)=fully processed.
If DFS reaches a GRAY node → back edge found → cycle exists!
If reaches BLACK → already processed, no cycle here.
🇮🇳 Hinglish
3 states: WHITE(0)=nahi dekha, GRAY(1)=current DFS path mein hai, BLACK(2)=poori tarah process ho gaya.
DFS mein GRAY node mila → back edge → cycle hai!
BLACK mila → already done, yahan cycle nahi.
Directed: 0→1→2→0 (cycle!)

2=W
Mark 0 as GRAY (in path)
DFS(1)
0=GRAY
1=GRAY
2=W
DFS(2)
0=GRAY
1=GRAY
2=GRAY
2's neighbor = 0. 0 is GRAY! → CYCLE!
CYCLE ✅
🔵 C++ · Cycle in Directed Graph
// 0=WHITE, 1=GRAY (in stack), 2=BLACK (done)
bool dfsCycle(int node, vector<vector<int>>& adj,
              vector<int>& color) {
    color[node] = 1; // GRAY — currently in DFS path

    for (int nb : adj[node]) {
        if (color[nb] == 1) return true;  // GRAY → back edge → cycle!
        if (color[nb] == 0)              // WHITE → explore
            if (dfsCycle(nb, adj, color)) return true;
    }
    color[node] = 2; // BLACK — fully processed
    return false;
}

bool hasCycleDirected(int V, vector<vector<int>>& adj) {
    vector<int> color(V, 0); // all WHITE initially
    for (int i = 0; i < V; i++)
        if (color[i] == 0)
            if (dfsCycle(i, adj, color)) return true;
    return false;
}
💡 Directed graph mein GRAY = currently on DFS stack. Back edge to GRAY node = cycle. BLACK node pe wapas aana = no cycle (already processed subtree).
Cycle in Undirected Graph
↔️
Cycle in Undirected Graph (Parent tracking)
🇬🇧 English
DFS with parent tracking. If a visited neighbor is NOT the parent → back edge → cycle! Must track parent to avoid false positives (u→v→u is not a cycle in undirected).
🇮🇳 Hinglish
DFS mein parent track karo. Agar visited neighbor parent nahi hai → back edge → cycle! Parent track karna zaroori hai — undirected mein u→v→u ko false cycle mat samjho (woh toh same edge hai).
🔵 C++ · Cycle in Undirected Graph
bool dfsUndirected(int node, int parent,
                    vector<vector<int>>& adj,
                    vector<bool>& visited) {
    visited[node] = true;
    for (int nb : adj[node]) {
        if (!visited[nb]) {
            if (dfsUndirected(nb, node, adj, visited))
                return true;
        } else if (nb != parent) {  // visited + not parent = cycle!
            return true;
        }
    }
    return false;
}

bool hasCycleUndirected(int V, vector<vector<int>>& adj) {
    vector<bool> visited(V, false);
    for (int i = 0; i < V; i++)
        if (!visited[i])
            if (dfsUndirected(i, -1, adj, visited)) return true;
    return false;
}
// Alternative: Use DSU (Union-Find) — add edge u-v,
// if find(u)==find(v) before union → cycle!
⚠️ Undirected graph mein visited neighbor = parent hona normal hai (same edge). Sirf non-parent visited neighbor = cycle.
Graphs · Pattern 3 of 7

📋 Topological Sort

DAG (Directed Acyclic Graph) ke nodes ko linear order mein arrange karo — sabse pehle woh node jo kisi pe depend nahi karta.

Only for DAG Kahn's = BFS DFS post-order
📋
Core Concept
🇬🇧 English
Topological order: for every directed edge u→v, u comes before v in the ordering. Only possible in a DAG (no cycles). Used in: course schedule, build order, task dependencies.
🇮🇳 Hinglish
Topo order: har directed edge u→v ke liye, u order mein v se pehle aata hai. Sirf DAG mein possible (cycles nahi). Use: course schedule, build order, task dependencies ka sequence.
Algorithm 1 — Kahn's Algorithm (BFS / In-degree)
🔢
Kahn's AlgorithmBFS In-degree
🇬🇧 Intuition
1. Compute in-degree of all nodes.
2. Enqueue all nodes with in-degree 0 (no dependencies).
3. BFS: dequeue node, add to result, decrease in-degree of neighbors. If neighbor in-degree → 0, enqueue.
4. If result has all V nodes → valid topo order. Else → cycle exists!
🇮🇳 Hinglish
1. Saare nodes ka in-degree calculate karo.
2. In-degree 0 wale nodes queue mein daalo (kisi pe depend nahi).
3. BFS: dequeue, result mein add, neighbors ka in-degree ghataao. 0 ho gaya → queue mein daalo.
4. Result mein V nodes → valid. Kam hain → cycle hai!

🔵 C++ · Kahn's Algorithm (BFS Topo Sort)
vector<int> topoSortKahn(int V, vector<vector<int>>& adj) {
    vector<int> indegree(V, 0);
    for (int u = 0; u < V; u++)
        for (int v : adj[u]) indegree[v]++;

    queue<int> q;
    for (int i = 0; i < V; i++)
        if (indegree[i] == 0) q.push(i);

    vector<int> order;
    while (!q.empty()) {
        int node = q.front(); q.pop();
        order.push_back(node);
        for (int nb : adj[node])
            if (--indegree[nb] == 0) q.push(nb);
    }
    // Cycle check: if order.size() != V → cycle exists
    return order.size() == V ? order : vector<int>{};
}

Algorithm 2 — DFS-based Topological Sort
🌀
DFS Topo SortPost-order Stack
🇬🇧 Intuition
DFS on all unvisited nodes. After fully processing a node (all descendants done) → push to a stack. Pop stack at end = topological order. Node pushed last = processed first = no dependencies!
🇮🇳 Hinglish
Saare unvisited nodes pe DFS karo. Node poori tarah process hone ke baad (saare descendants done) → stack mein push karo. Ant mein stack pop karo = topological order. Jo pehle process hua woh stack mein baad mein push hua → pop karne par pehle aayega.
🔵 C++ · DFS Topological Sort
void dfsTopo(int node, vector<vector<int>>& adj,
             vector<bool>& visited, stack<int>& st) {
    visited[node] = true;
    for (int nb : adj[node])
        if (!visited[nb])
            dfsTopo(nb, adj, visited, st);
    st.push(node);  // POST-ORDER: saare descendants ke baad push
}

vector<int> topoSortDFS(int V, vector<vector<int>>& adj) {
    vector<bool> visited(V, false);
    stack<int> st;
    for (int i = 0; i < V; i++)
        if (!visited[i]) dfsTopo(i, adj, visited, st);

    vector<int> order;
    while (!st.empty()) { order.push_back(st.top()); st.pop(); }
    return order;
}
💡 Kahn's preferred hai — cycle detect bhi karta hai. DFS topo sort use karo jab DFS already chal rahi ho (e.g. SCC algorithms mein).

📍 Shortest Path

Source se destination tak minimum cost path. Algorithm choice depends on: negative edges? single/all pairs?

Dijkstra: no neg edges Bellman-Ford: neg edges Floyd-Warshall: all pairs
🗺️
Dijkstra's AlgorithmO((V+E) log V)
🇬🇧 Intuition
Greedy: always expand the node with minimum known distance. Use a min-heap (priority queue). Initialize dist[source]=0, all others=INF. At each step: pop minimum distance node, relax neighbors. Only works with non-negative edge weights.
🇮🇳 Hinglish
Greedy approach: hamesha minimum known distance wala node expand karo. Min-heap (priority queue) use karo. dist[source]=0, baaki INF. Har step: minimum distance node pop karo, neighbors relax karo. Sirf non-negative weights ke saath!

🔵 C++ · Dijkstra's Algorithm
vector<int> dijkstra(int src, int V,
    vector<vector<pair<int,int>>>& adj) { // {neighbor, weight}

    vector<int> dist(V, INT_MAX);
    dist[src] = 0;
    // min-heap: {distance, node}
    priority_queue<pair<int,int>, vector<pair<int,int>>,
                   greater<pair<int,int>>> pq;
    pq.push({0, src});

    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();

        if (d > dist[u]) continue; // stale entry skip karo

        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;  // RELAX
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
💡 if (d > dist[u]) continue — stale entries skip karna important hai! Same node ko multiple baar process hone se bachata hai. O((V+E) log V).
⚠️ Negative weights ke saath Dijkstra WRONG answers deta hai. Negative edges → Bellman-Ford use karo!
Bellman-Ford — Negative Edges
⚡
Bellman-FordO(V·E)
🇬🇧 Intuition
Relax ALL edges V-1 times. After V-1 relaxations, shortest paths are found (shortest path can have at most V-1 edges). Check for negative cycles: if any edge can still be relaxed after V-1 iterations → negative cycle!
🇮🇳 Hinglish
V-1 baar saare edges relax karo. V-1 relaxations ke baad shortest paths mil jaate hain (max V-1 edges ho sakti hain path mein). Negative cycle check: agar V-1 ke baad bhi koi edge relax ho sake → negative cycle!
🔵 C++ · Bellman-Ford
vector<int> bellmanFord(int src, int V,
    vector<tuple<int,int,int>>& edges) { // {u, v, weight}

    vector<int> dist(V, INT_MAX);
    dist[src] = 0;

    // V-1 baar saare edges relax karo
    for (int i = 0; i < V - 1; i++) {
        for (auto [u, v, w] : edges) {
            if (dist[u] != INT_MAX && dist[u] + w < dist[v])
                dist[v] = dist[u] + w;  // RELAX
        }
    }

    // Negative cycle check — Vth iteration mein bhi relax? → cycle!
    for (auto [u, v, w] : edges) {
        if (dist[u] != INT_MAX && dist[u] + w < dist[v]) {
            cout << "Negative cycle exists!";
            return {};
        }
    }
    return dist;
}
DijkstraNon-negative weights. O((V+E)logV). Faster. Priority Queue.
Bellman-FordNegative weights OK. Detects negative cycles. O(V·E). Slower.
Floyd-Warshall — All Pairs Shortest Path
🔲
Floyd-WarshallO(V³)
🇬🇧 Intuition
Find shortest path between every pair of nodes. DP approach: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]) for every intermediate node k. Simple triple nested loop!
🇮🇳 Hinglish
Har pair ke beech shortest path nikalo. DP: har intermediate node k ke liye: dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]). Simple triple nested loop! Dense graphs ke liye use karo.
🔵 C++ · Floyd-Warshall
vector<vector<int>> floydWarshall(int V,
    vector<vector<int>> dist) { // dist matrix, INF if no edge

    // dist[i][i] = 0 (self)
    for (int i = 0; i < V; i++) dist[i][i] = 0;

    // k = intermediate node
    for (int k = 0; k < V; k++)
        for (int i = 0; i < V; i++)
            for (int j = 0; j < V; j++)
                if (dist[i][k] != INF && dist[k][j] != INF)
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j]);

    // Negative cycle: dist[i][i] < 0 → cycle!
    return dist;
}
💡 Floyd-Warshall O(V³) — small graphs (V≤500) ke liye. Large graphs mein V baar Dijkstra run karo (O(V(V+E)logV)) — better hoga.
Graphs · Pattern 5 of 7

🌲 Minimum Spanning Tree

Saare nodes ko connect karo minimum total weight se — exactly V-1 edges, no cycles.

Kruskal: sort edges Prim: grow from node Both O(E log E)
🌿
Kruskal's AlgorithmSort + DSU
🇬🇧 Intuition
Sort all edges by weight. Greedily pick the smallest edge. If it connects two different components (DSU check) → add to MST. If same component → skip (would create cycle). Repeat until V-1 edges picked.
🇮🇳 Hinglish
Saare edges weight se sort karo. Greedy: sabse chhota edge lo. Agar dono endpoints alag components mein hain (DSU check) → MST mein add karo. Same component → skip (cycle ban jaata). V-1 edges tak repeat karo.
🔵 C++ · Kruskal's MST
// DSU (Union-Find) — needed for Kruskal
struct DSU {
    vector<int> parent, rank;
    DSU(int n) : parent(n), rank(n,0) {
        iota(parent.begin(), parent.end(), 0); }
    int find(int x) {
        return parent[x]==x ? x : parent[x]=find(parent[x]); }
    bool unite(int a, int b) {
        a=find(a); b=find(b); if(a==b) return false;
        if(rank[a]<rank[b]) swap(a,b);
        parent[b]=a; if(rank[a]==rank[b]) rank[a]++;
        return true; }
};

int kruskalMST(int V, vector<tuple<int,int,int>>& edges) {
    sort(edges.begin(), edges.end()); // sort by weight
    DSU dsu(V);
    int mstWeight = 0, edgeCount = 0;

    for (auto [w, u, v] : edges) {
        if (dsu.unite(u, v)) {  // different components → add!
            mstWeight += w;
            if (++edgeCount == V-1) break; // MST complete
        }
    }
    return mstWeight;
}
Prim's Algorithm
🌱
Prim's AlgorithmMin-Heap + visited
🇬🇧 Intuition
Start from any node. Grow the MST one edge at a time — always add the minimum weight edge connecting the current MST to an unvisited node. Use a min-heap to efficiently pick minimum edge. Similar to Dijkstra structure!
🇮🇳 Hinglish
Kisi bhi node se start karo. MST ko ek edge at a time badhao — hamesha current MST ko unvisited node se connect karne wali minimum weight edge lo. Min-heap se efficiently pick karo. Dijkstra jaisi structure!
🔵 C++ · Prim's MST
int primMST(int V, vector<vector<pair<int,int>>>& adj) {
    vector<bool> inMST(V, false);
    priority_queue<pair<int,int>,
        vector<pair<int,int>>, greater<>> pq; // {weight, node}
    pq.push({0, 0}); // start from node 0, weight 0
    int mstWeight = 0;

    while (!pq.empty()) {
        auto [w, u] = pq.top(); pq.pop();
        if (inMST[u]) continue; // already in MST → skip
        inMST[u] = true;
        mstWeight += w;

        for (auto [v, wt] : adj[u])
            if (!inMST[v]) pq.push({wt, v});
    }
    return mstWeight;
}
KruskalEdge list sort + DSU. Better for sparse graphs. Simpler code.
Prim'sAdjacency list + min-heap. Better for dense graphs. Dijkstra-like.
Graphs · Pattern 6 of 7

🔗 Union-Find (DSU)

Disjoint Set Union — efficiently find which component a node belongs to, and merge components in near O(1).

Nearly O(1) ops Path compression Union by rank
🔗
DSU Full Implementation
🇬🇧 English
Two key optimizations: Path Compression (flatten tree during find → O(1) amortized) and Union by Rank (always attach smaller tree under larger → balanced tree). Together give nearly O(1) = O(α(n)) where α is inverse Ackermann.
🇮🇳 Hinglish
Do optimizations: Path Compression (find mein tree flatten karo → O(1) amortized) aur Union by Rank (chhote tree ko bade ke neeche lagao → balanced tree). Dono milake nearly O(1) = O(α(n)).
🔵 C++ · DSU with Path Compression + Union by Rank
class DSU {
    vector<int> parent, rank_, size_;
public:
    DSU(int n) : parent(n), rank_(n,0), size_(n,1) {
        iota(parent.begin(), parent.end(), 0);
    }

    // Path compression: parent directly root pe point karo
    int find(int x) {
        if (parent[x] != x)
            parent[x] = find(parent[x]); // path compression!
        return parent[x];
    }

    // Union by rank: chhota tree bade ke neeche
    bool unite(int a, int b) {
        a = find(a); b = find(b);
        if (a == b) return false;  // same component → cycle!
        if (rank_[a] < rank_[b]) swap(a, b);
        parent[b] = a;
        size_[a] += size_[b];
        if (rank_[a] == rank_[b]) rank_[a]++;
        return true;
    }

    bool connected(int a, int b) { return find(a)==find(b); }
    int  getSize(int a) { return size_[find(a)]; }
};
DSU — Cycle Detection in Undirected Graph
🔍
Cycle Detection using DSULeetCode 684, 685
🇬🇧 Intuition
Process edges one by one. For each edge (u,v): if find(u) == find(v) → both already in same component → adding this edge creates a cycle! Otherwise → unite(u,v).
🇮🇳 Hinglish
Edges ek ek karke process karo. Har edge (u,v) ke liye: agar find(u) == find(v) → dono pehle se same component mein hain → yeh edge add karne se cycle ban jaayega! Warna → unite(u,v).
🔵 C++ · Redundant Connection (LC 684)
vector<int> findRedundantConnection(vector<vector<int>>& edges) {
    int n = edges.size();
    DSU dsu(n + 1); // 1-indexed

    for (auto& e : edges) {
        if (!dsu.unite(e[0], e[1]))  // unite returns false = same comp
            return e;               // this edge creates cycle!
    }
    return {};
}
// Number of Connected Components (LC 323):
// count unique find() values after all unions
int countComponents(int n, vector<vector<int>>& edges) {
    DSU dsu(n);
    int components = n;
    for (auto& e : edges)
        if (dsu.unite(e[0], e[1])) components--;
    return components;
}
💡 DSU 3 problems solve karta hai elegantly: cycle detection, connected components count, minimum spanning tree (Kruskal). Ek template yaad kar lo!

Bipartite Check — 2-Coloring
🇬🇧 English
A graph is bipartite if nodes can be split into 2 groups such that every edge connects nodes from different groups. Check using BFS: color each node alternately (0 or 1). If a neighbor has the same color → NOT bipartite (odd cycle)!
🇮🇳 Hinglish
Bipartite graph = nodes ko 2 groups mein split kar sako aur har edge alag groups ke beech ho. BFS se check: har node ko alternately color karo (0 ya 1). Neighbor ka same color → bipartite NAHI (odd cycle mila)!
🔵 C++ · Bipartite Check
bool isBipartite(vector<vector<int>>& graph) {
    int n = graph.size();
    vector<int> color(n, -1);
    for (int start = 0; start < n; start++) {
        if (color[start] != -1) continue;
        queue<int> q;
        q.push(start); color[start] = 0;
        while (!q.empty()) {
            int node = q.front(); q.pop();
            for (int nb : graph[node]) {
                if (color[nb] == -1) { color[nb] = 1 - color[node]; q.push(nb); }
                else if (color[nb] == color[node]) return false;
            }
        }
    }
    return true;
}
💡 1 - color[node] opposite color deta hai. Bipartite = no odd cycles. LC 785, 886.
0-1 BFS — Deque based Shortest Path
0️⃣1️⃣
0-1 BFSDeque O(V+E)
🇬🇧 English
When edge weights are only 0 or 1: use a deque. Weight=0 → push_front (free move). Weight=1 → push_back (costs 1). O(V+E) instead of Dijkstra's O((V+E)logV)!
🇮🇳 Hinglish
Jab weights sirf 0 ya 1 hoon: deque use karo. Weight=0 → push_front. Weight=1 → push_back. O(V+E) milta hai! LC 1368.
🔵 C++ · 0-1 BFS
vector<int> zeroOneBFS(int src, int V,
    vector<vector<pair<int,int>>>& adj) {
    vector<int> dist(V, INT_MAX);
    dist[src] = 0;
    deque<int> dq;
    dq.push_back(src);
    while (!dq.empty()) {
        int u = dq.front(); dq.pop_front();
        for (auto [v, w] : adj[u]) {
            if (dist[u] + w < dist[v]) {
                dist[v] = dist[u] + w;
                if (w == 0) dq.push_front(v);
                else         dq.push_back(v);
            }
        }
    }
    return dist;
}
💡 0-1 BFS = Dijkstra ka O(V+E) version for 0/1 weights. Deque front = free (weight 0), back = cost 1.

Common Mistakes
⚠️ Dijkstra with negative edges: Wrong answers! Negative weights → Bellman-Ford use karo.
⚠️ Directed cycle detection: Simple visited[] nahi — 3-color (GRAY/BLACK) zaroori hai!
⚠️ Undirected cycle: nb != parent check karo — u→v→u ko false cycle mat samjho.
⚠️ Topo sort on cyclic graph: Kahn's result size check karo — V se kam = cycle hai!
⚠️ Floyd-Warshall overflow: INF+INF overflow hoga! Guard condition zaroori hai.
💡 Disconnected graphs: Hamesha outer loop — for(i=0;i<V;i++) if(!visited[i]) bfs/dfs(i). Warna components miss ho jaate hain!
