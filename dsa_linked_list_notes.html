Linked List Pointer Techniques

Pointers ko relative speeds ya bounds me manipulate karke elements check karne wali algorithms. Isme Fast & Slow (Hare & Tortoise) pointer pattern sabse dominant hai.

Fast & Slow Pointers O(N) Time complexity O(1) Auxiliary Space
Pattern 1 — Finding Middle of a Linked List
📍
Middle of ListLeetCode 876
🇬🇧 Core Concept
Use two pointers, slow and fast, starting at the head of the linked list. The slow pointer moves one step at a time, while the fast pointer moves two steps. By the time the fast pointer reaches the end, the slow pointer will be exactly at the middle node of the list.
🇮🇳 Hinglish
Linked list ke start pe do pointers rakho: slow aur fast.
**Logic**: slow ek time me 1 step chalta hai aur fast ek time me 2 steps. Jab fast pointer list ke end (aakhri node ya NULL) par pahunchega, tab tak slow pointer bilkul center (middle) node pe hoga! Kyunki fast ki speed slow se double hai.

🔵 C++ · Finding Middle Node
ListNode* middleNode(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    
    // Fast checks fast->next and fast->next->next safety
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;       // moves 1 step
        fast = fast->next->next; // moves 2 steps
    }
    return slow; // slow points to middle node
}
Pattern 2 — Cycle Detection (Floyd's Cycle Finding)
🔄
Cycle DetectionLeetCode 141 & 142
🇬🇧 Core Idea
Use the Floyd's Tortoise and Hare algorithm. Move the slow pointer by 1 step and the fast pointer by 2 steps. If a cycle exists, the fast pointer will eventually loop around and meet the slow pointer from behind. If fast reaches the end (NULL), no cycle exists.
**Finding Cycle Start (LeetCode 142)**: Once they meet, reset slow to head. Move both pointers 1 step at a time. The node where they meet again is the start of the cycle.
🇮🇳 Hinglish
Agar linked list me aakhri node kisi pichle node se connect ho jaye, toh hume cycle milti hai. Hum slow ko 1 step aur fast ko 2 steps chalate hain.
**Analogy**: Socho ek circular racetrack hai. Uspe ek race car (fast) aur ek bicycle (slow) chal rahi hain. Racetrack circular hone ke karan, thodi der baad sports car piche se aakar bicycle ke barabar pahunch hi jayegi! Agar meeting ho gayi -> Cycle hai. Agar fast end (NULL) pe pahunch gaya -> Cycle nahi hai.
🔵 C++ · Linked List Cycle Detection
bool hasCycle(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
        
        if (slow == fast) {
            return true; // Meeting point found! Cycle exists.
        }
    }
    return false;
}
🔵 C++ · Find Cycle Start Node
ListNode* detectCycleStart(ListNode* head) {
    ListNode* slow = head;
    ListNode* fast = head;
    bool hasCycle = false;
    
    while (fast != nullptr && fast->next != nullptr) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            hasCycle = true;
            break;
        }
    }
    
    if (!hasCycle) return nullptr;
    
    // Reset slow to head, move both 1 step at a time
    slow = head;
    while (slow != fast) {
        slow = slow->next;
        fast = fast->next;
    }
    return slow; // Meeting point is the cycle start node
}

Linked List Reversal Patterns

Node connections aur links direction ko in-place change karne wale patterns. Isme constant O(1) extra space complexity maintain karna mandatory hota hai.

In-Place Pointer Manipulation Swap Directions O(1) Space
Pattern 3 — Full Reverse of a Linked List
↩️
Full ReverseLeetCode 206
🇬🇧 Core Concept
Iterate through the linked list. Maintain three pointers: prev (initially NULL), curr (initially head), and nextTemp. In each step, save curr->next, change the link direction by setting curr->next = prev, and shift both pointers forward.
🇮🇳 Hinglish
Poore list ke connections ko ulta (reverse) karna. Hum 3 pointers maintain karte hain:
- curr: Jis node par hum abhi hain.
- prev: Iske pichla node (jo reversed path banayega).
- nextTemp: Current ke agle node ko bachane ke liye (kyunki direction badalne par aage ka path gum ho jayega!).
**Transition**: Har step me curr->next = prev (link ko piche modein) aur teeno ko aage shift karein.

🔵 C++ · Iterative Full Reverse
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    ListNode* nextTemp = nullptr;
    
    while (curr != nullptr) {
        nextTemp = curr->next; // Step 1: Save next node
        curr->next = prev;     // Step 2: Reverse the link direction
        prev = curr;           // Step 3: Shift pointers forward
        curr = nextTemp;
    }
    return prev; // prev is the new head
}
Pattern 4 — Partial Reversal (k-Group Reversal)
🧱
Reverse Nodes in k-GroupLeetCode 25 · Hard
🇬🇧 Core Idea
Partition the linked list into segments of size k. For each segment, first check if there are at least k nodes left. If yes, reverse that segment in-place. If there are fewer than k nodes remaining, leave them as they are. Connect the reversed segments back together dynamically using boundary pointers.
🇮🇳 Hinglish
Isme hum list ko k length ke groups me todte hain. Har group ke liye pehle check karte hain ki aage minimum k nodes hain ya nahi. Agar hain, toh us group ko reverse kar do. Agar bache hue nodes k se chote hain (end part), toh unhe bina chede chhod do. Is segment reversal ko maintain karne ke liye pre-reversed connections ko aapas me adjust karna padta hai.
🔵 C++ · Reverse Nodes in k-Group
ListNode* reverseKGroup(ListNode* head, int k) {
    ListNode* curr = head;
    int count = 0;
    
    // Check if there are at least k nodes remaining
    while (curr != nullptr && count < k) {
        curr = curr->next;
        count++;
    }
    
    // If we have k nodes, reverse them
    if (count == k) {
        ListNode* prev = nullptr;
        ListNode* nextNode = nullptr;
        curr = head;
        
        for (int i = 0; i < k; i++) {
            nextNode = curr->next;
            curr->next = prev;
            prev = curr;
            curr = nextNode;
        }
        
        // Recurse for the remaining part and link!
        if (nextNode != nullptr) {
            head->next = reverseKGroup(nextNode, k);
        }
        return prev; // prev becomes the head of this reversed k-group
    }
    return head; // fewer than k nodes left, keep them as is
}

Linked List Merging Patterns

Do ya do se zyada Sorted lists ko single unified sorted list me join karne ke concepts.

Dummy Node Trick O(N) Time Iterative / Recursive
Pattern 5 — Merge Two Sorted Lists
🤝
Merge Two Sorted ListsLeetCode 21
🇬🇧 Core Idea
Use a **Dummy Node** to serve as the start of the merged list. Maintain a tail pointer (initially at dummy). Compare values at the current heads of the two lists. Append the smaller node to the tail, and advance the head of that list. Repeat until one list is exhausted, then append the remainder of the other list directly.
🇮🇳 Hinglish
Do already sorted lists ko aapas me comparison karke ek single sorted list me jodna.
**Dummy Node Trick**: Hum ek temporary (dummy) node banate hain jo final list ke head ko store karne me help karega. Ek pointer tail is dummy par rakhte hain. Hum dono lists ke head nodes ki values ko compare karte hain — jo chota hoga use tail ke aage attach karenge aur aage badhenge. Jab ek list khatam ho jaye, toh bachi hui list ko direct link kar dete hain!

🔵 C++ · Merge Two Sorted Lists (Iterative)
ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
    ListNode dummy(0); // Temporary root
    ListNode* tail = &dummy;
    
    while (list1 != nullptr && list2 != nullptr) {
        if (list1->val <= list2->val) {
            tail->next = list1;
            list1 = list1->next;
        } else {
            tail->next = list2;
            list2 = list2->next;
        }
        tail = tail->next; // tail pointer step forward
    }
    
    // If any list is remaining, link it directly
    tail->next = (list1 != nullptr) ? list1 : list2;
    
    return dummy.next; // return start of merged list
}
