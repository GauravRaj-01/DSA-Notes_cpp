Heap — Basics & Foundation

Priority Queue ka underlying data structure. Fast min/max access — O(log n) insert/delete, O(1) peek.

O(1) peek top O(log n) push/pop O(n) build heap Complete Binary Tree
🏔️
What is a Heap?
🇬🇧 English
A Heap is a complete binary tree stored as an array. It satisfies the heap property:
• Min Heap: Parent ≤ Children (root = smallest element)
• Max Heap: Parent ≥ Children (root = largest element)

For node at index i: left child = 2i+1, right child = 2i+2, parent = (i-1)/2.
🇮🇳 Hinglish
Heap ek complete binary tree hai jise array mein store karte hain. Iska ek rule hai:
• Min Heap: Parent hamesha children se chhota ya equal → root = sabse chhota
• Max Heap: Parent hamesha children se bada ya equal → root = sabse bada

Array mein index i pe node ka left child 2i+1 pe, right child 2i+2 pe hota hai. Yahi magic hai!

Min Heap vs Max Heap
⚖️
Min Heap vs Max Heap — C++ mein
C++ mein priority_queue default Max Heap hoti hai. Min Heap ke liye greater<int> pass karo. Yeh confusion ka sabse common source hai — yaad rakho!
Min Heap — Chhota element top peKth largest, top K, median stream mein use hota hai.
priority_queue<int, vector<int>, greater<int>>
Max Heap — Bada element top peDefault C++ PQ. K smallest dhundhne mein, Greedy problems mein.
priority_queue<int>

// MAX HEAP (default) — bada element top pe

maxHeap.push(3); maxHeap.push(1); maxHeap.push(7);
cout << maxHeap.top(); // 7 → sabse bada

// MIN HEAP — chhota element top pe
priority_queue<int, vector<int>, greater<int>> minHeap;
minHeap.push(3); minHeap.push(1); minHeap.push(7);
cout << minHeap.top(); // 1 → sabse chhota

// Custom comparator — pairs ke liye (freq, val)
auto cmp = [](pair<int,int>& a, pair<int,int>& b){
    return a.first > b.first; // min heap by first element
};
priority_queue<pair<int,int>, vector<pair<int,int>>, decltype(cmp)> pq(cmp);
⚠️ Sabse common mistake: Max heap use kiya jab min heap chahiye tha (ya ulta). Jab bhi Kth largest dhundhna ho → MIN heap use karo (size K). Jab Kth smallest → MAX heap!

Heap Patterns · Pattern 1 of 3

Top K / Kth Element / K Closest Points

Heap se efficiently Kth largest/smallest ya Top K elements nikalo — sorting se better O(n log k).

O(n log k) time O(k) space Min Heap of size K
💡
Core Pattern — Size-K Min Heap
🇬🇧 English
To find Kth Largest: maintain a min-heap of size K. When heap size exceeds K, pop the smallest. At the end, top of heap = Kth largest.

Why min-heap for Kth largest? Because the smallest among the K largest is what we want to track — when something smaller arrives, pop it!
🇮🇳 Hinglish
Kth Largest ke liye: K size ka min heap maintain karo. Jab heap size K se zyada ho, pop karo (chhota nikaalo). End mein heap ka top = Kth largest.

Logic: Top K bade numbers rakhne hain. Min heap mein sabse chhota top pe hoga. Naya element aaya? Agar heap top se bada hai toh top hatao, naya daalo — K bade numbers hamesha heap mein rahenge!

🔵 C++ · Kth Largest Element
int findKthLargest(vector<int>& nums, int k) {
    // Min heap of size k — Kth largest dhundhne ke liye
    priority_queue<int, vector<int>, greater<int>> minH;

    for (int num : nums) {
        minH.push(num);
        if (minH.size() > k)
            minH.pop();   // sabse chhota nikalo — K bade maintain karo
    }
    return minH.top(); // top = Kth largest!
}

// Kth Smallest ke liye: MAX heap of size k use karo
int findKthSmallest(vector<int>& nums, int k) {
    priority_queue<int> maxH;  // max heap
    for (int num : nums) {
        maxH.push(num);
        if (maxH.size() > k)
            maxH.pop();   // sabse bada nikalo — K chhote maintain karo
    }
    return maxH.top(); // top = Kth smallest!
}
💡 Golden Rule: Kth Largest → Min Heap size K · Kth Smallest → Max Heap size K. Ulta lagta hai par sahi hai — kyunki heap ke top pe boundary element hota hai!

🔵 C++ · Top K Frequent Elements
vector<int> topKFrequent(vector<int>& nums, int k) {
    // Step 1: Frequency count karo
    unordered_map<int,int> freq;
    for (int n : nums) freq[n]++;

    // Step 2: Min heap by frequency (freq, num)
    priority_queue<pair<int,int>,
                   vector<pair<int,int>>,
                   greater<pair<int,int>>> minH;

    for (auto& [num, cnt] : freq) {
        minH.push({cnt, num});
        if (minH.size() > k)
            minH.pop(); // sabse kam frequent nikalo
    }

    // Step 3: Result collect karo
    vector<int> result;
    while (!minH.empty()) {
        result.push_back(minH.top().second);
        minH.pop();
    }
    return result;
}
K Closest Points to Origin
📍
K Closest Points to OriginLeetCode 973
Distance calculate karo (sqrt skip kar sakte ho — comparison ke liye). Max heap size K maintain karo distance ke basis pe. Jab heap size > K, bade distance wala pop karo. Heap mein K closest points bachenge.
🔵 C++ · K Closest Points to Origin
vector<vector<int>> kClosest(vector<vector<int>>& points, int k) {
    // Max heap — distance ke basis pe (bade distance ko hatate hain)
    // {dist², x, y} store karo
    priority_queue<tuple<int,int,int>> maxH;

    for (auto& p : points) {
        int dist = p[0]*p[0] + p[1]*p[1]; // sqrt ki zaroorat nahi!
        maxH.push({dist, p[0], p[1]});
        if (maxH.size() > k)
            maxH.pop(); // sabse door wala point nikalo
    }

    vector<vector<int>> result;
    while (!maxH.empty()) {
        auto [d, x, y] = maxH.top(); maxH.pop();
        result.push_back({x, y});
    }
    return result;
}
💡 K Closest → MAX heap size K (bada distance top pe, pop when overflow). K Farthest → MIN heap size K. Distance ke liye sqrt skip karo — comparison mein zaroorat nahi!

Task Scheduler
⏱️
Task SchedulerLeetCode 621
🇬🇧 Intuition
At each time slot, pick the most frequent available task (greedy). If a task was just executed, it must cool down for n slots before it can run again. Use a max heap for frequencies and a queue for cooling tasks with their available time.
🇮🇳 Hinglish
Greedy idea: har time slot mein sabse zyada frequent available task chuno — yahi optimal hai. Max heap mein frequencies rakho. Jo task abhi cool down mein hai use queue mein rakho with available time. Jab queue ka front available ho jaaye, usse heap mein wapas daalo.

🔵 C++ · Task Scheduler
int leastInterval(vector<char>& tasks, int n) {
    unordered_map<char,int> freq;
    for (char t : tasks) freq[t]++;

    // Max heap — sabse frequent task pehle
    priority_queue<int> maxH;
    for (auto& [c, f] : freq) maxH.push(f);

    // Queue: {remaining_freq, available_at_time}
    queue<pair<int,int>> cooldown;
    int time = 0;

    while (!maxH.empty() || !cooldown.empty()) {
        time++;

        // Cooldown se koi task ready? Heap mein wapas daalo
        if (!cooldown.empty() && cooldown.front().second == time)  {
            maxH.push(cooldown.front().first);
            cooldown.pop();
        }

        if (!maxH.empty()) {
            int remaining = maxH.top() - 1; maxH.pop();
            if (remaining > 0)
                cooldown.push({remaining, time + n + 1}); // n slots baad available
        }
        // Agar heap aur cooldown dono empty nahi lekin heap empty → idle time
    }
    return time;
}
💡 Greedy + Heap pattern: Max heap se best task lo → execute → cooldown queue mein daalo → waqt pe wapas heap mein. Yeh simulate karna pattern hai!
Meeting Rooms II
🏢
Meeting Rooms II — Min RoomsLeetCode 253
🇬🇧 Intuition
Sort meetings by start time. Use a min heap of end times. For each meeting: if heap top (earliest ending meeting) ends before current starts → reuse that room (pop heap). Otherwise → need a new room. Push current meeting's end time.
🇮🇳 Hinglish
Start time se sort karo. Min heap mein end times rakho. Har meeting ke liye: agar heap ka top (sabse pehle khatam hone wali meeting) current se pehle khatam ho jaaye → woh room free hai, reuse karo (pop + push). Warna naya room chahiye (sirf push). Heap ka size = rooms in use!
intervals=[[0,30],[5,10],[15,20]] → Expected: 2 rooms
[0,30]
heap empty → new room. Push end=30. heap=[30]
rooms=1
[5,10]
heap top=30 > start=5 → overlap → new room. Push end=10. heap=[10,30]
rooms=2
[15,20]
heap top=10 ≤ start=15 → room free! Pop 10, push 20. heap=[20,30]
rooms=2 (reused)
Answer
Max heap size at any point = 2
✅ return 2
🔵 C++ · Meeting Rooms II
int minMeetingRooms(vector<vector<int>>& intervals) {
    // Start time se sort karo
    sort(intervals.begin(), intervals.end());

    // Min heap of end times — sabse pehle khatam hone wala top pe
    priority_queue<int,vector<int>,greater<int>> minH;

    for (auto& mtg : intervals) {
        // Kya koi room free hua? (earliest end ≤ current start)
        if (!minH.empty() && minH.top() <= mtg[0])
            minH.pop();  // room reuse karo

        minH.push(mtg[1]); // current meeting ka end time daalo
    }
    return minH.size(); // heap size = rooms needed
}
💡 Meeting Rooms = Min Heap of end times. Heap size = currently occupied rooms. Agar top ≤ current start → room free (pop). Simple aur elegant!
Reorganize String
🔀
Reorganize StringLeetCode 767
🇮🇳 Hinglish
String rearrange karo taaki koi bhi do adjacent characters same na hon. Greedy: hamesha sabse frequent available character choose karo — prev se alag hona chahiye. Max heap se har step pe most frequent lo, prev ko temporarily side mein rakho.
🔵 C++ · Reorganize String
string reorganizeString(string s) {
    unordered_map<char,int> freq;
    for (char c : s) freq[c]++;

    // Max heap: {frequency, char}
    priority_queue<pair<int,char>> maxH;
    for (auto& [c, f] : freq) maxH.push({f, c});

    string result;
    // prev = previously placed char (adjacent mein nahi aa sakta)
    pair<int,char> prev = {-1, '#'};

    while (!maxH.empty()) {
        auto [f, c] = maxH.top(); maxH.pop();
        result += c;

        // Prev wala character wapas heap mein daalo (agar freq > 0)
        if (prev.first > 0) maxH.push(prev);

        // Current ko prev banao (next iteration mein side mein rahega)
        prev = {f - 1, c};
    }
    // Agar result length != s length → possible nahi
    return result.size() == s.size() ? result : "";
}
💡 Reorganize String ka pattern: Max heap se pick karo, prev character ko temporarily hold karo (adjacent ban na jaaye), phir prev ko wapas heap mein daalo. "Hold and release" pattern!
Huffman Encoding
🗜️
Huffman EncodingClassic Algorithm
🇬🇧 Intuition
Huffman builds an optimal prefix-free binary encoding. Frequent characters get shorter codes, rare ones get longer.

Algorithm: Use a min heap of frequencies. Repeatedly pick the 2 smallest nodes, merge them (sum = new node), push back. Repeat until 1 node remains = root of Huffman tree.
🇮🇳 Hinglish
Zyada frequent characters → chhota code. Kam frequent → lamba code. Compression ke liye best!

Algorithm: Min heap mein frequencies daalo. Baar baar: 2 sabse chhote nodes nikalao, unhe merge karo (sum = naya node), wapas daalo. Jab ek node bache → Huffman tree ka root!
chars=[a,b,c,d,e,f], freq=[5,9,12,13,16,45]
Init
Min heap: [5,9,12,13,16,45]
Merge 1
Pop 5(a) and 9(b) → merge = 14. Push 14. heap=[12,13,14,16,45]
14=a+b
Merge 2
Pop 12(c) and 13(d) → merge = 25. Push 25. heap=[14,16,25,45]
25=c+d
Merge 3
Pop 14(a+b) and 16(e) → merge = 30. Push 30. heap=[25,30,45]
30=ab+e
Merge 4
Pop 25(c+d) and 30(a+b+e) → merge = 55. heap=[45,55]
55
Merge 5
Pop 45(f) and 55 → merge = 100. heap=[100] → Root!
✅ Huffman Tree built!
🔵 C++ · Huffman Encoding
struct HNode {
    char ch; int freq;
    HNode *left, *right;
    HNode(char c, int f) : ch(c), freq(f), left(nullptr), right(nullptr) {}
};

struct Compare {
    bool operator()(HNode* a, HNode* b) {
        return a->freq > b->freq; // min heap by freq
    }
};

HNode* buildHuffman(vector<char>& chars, vector<int>& freqs) {
    priority_queue<HNode*, vector<HNode*>, Compare> minH;

    for (int i = 0; i < chars.size(); i++)
        minH.push(new HNode(chars[i], freqs[i]));

    while (minH.size() > 1) {
        HNode* l = minH.top(); minH.pop(); // sabse chhota
        HNode* r = minH.top(); minH.pop(); // doosra chhota

        HNode* merged = new HNode('\0', l->freq + r->freq);
        merged->left = l; merged->right = r;
        minH.push(merged); // merged node wapas heap mein
    }
    return minH.top(); // Huffman tree ka root
}

// Codes generate karo (DFS on Huffman tree)
void getCodes(HNode* node, string code,
              unordered_map<char,string>& codes) {
    if (!node) return;
    if (!node->left && !node->right) {  // leaf = actual character
        codes[node->ch] = code;
        return;
    }
    getCodes(node->left,  code + "0", codes); // left = 0
    getCodes(node->right, code + "1", codes); // right = 1
}
💡 Huffman = Min Heap se baar baar 2 chhote lo, merge karo, wapas daalo. Yeh greedy optimal hai — proof: frequent chars tree mein upar honge (chhota code), rare chars neeche (lamba code).
Heap Patterns · Pattern 3 of 3

K-way Merge

K sorted lists/arrays ko efficiently merge karo. Heap se har step pe minimum element nikalo — O(n log k).

O(n log k) time O(k) heap space Min Heap
🔀
Core Concept — K-way Merge
🇬🇧 English
To merge K sorted structures efficiently: put the first element from each into a min heap (with its source index). Repeatedly extract the minimum, add it to result, and push the next element from that source. This gives O(n log k) vs O(nk) brute force.
🇮🇳 Hinglish
K sorted lists/arrays merge karne ke liye: har list ka pehla element min heap mein daalo (list index aur position ke saath). Repeatedly: min nikaalo, result mein add karo, aur usi list ka agla element heap mein push karo. Yahi K-way merge ka core idea hai!

🔵 C++ · Merge K Sorted Linked Lists
struct ListNode { int val; ListNode* next; };

ListNode* mergeKLists(vector<ListNode*>& lists) {
    // Min heap: {val, node*} — val ke basis pe compare
    auto cmp = [](ListNode* a, ListNode* b){ return a->val > b->val; };
    priority_queue<ListNode*, vector<ListNode*>, decltype(cmp)> minH(cmp);

    // Har list ka head heap mein daalo
    for (auto node : lists)
        if (node) minH.push(node);

    ListNode dummy(0);
    ListNode* curr = &dummy;

    while (!minH.empty()) {
        ListNode* node = minH.top(); minH.pop();
        curr->next = node;       // result mein add karo
        curr = curr->next;
        if (node->next) minH.push(node->next); // agla element push karo
    }
    return dummy.next;
}
K Sorted Arrays Merge
📋
Merge K Sorted ArraysClassic
Same K-way merge pattern — bas array index track karo (array number, element index). Heap mein {value, arrayIdx, elemIdx} store karo.
🔵 C++ · Merge K Sorted Arrays
vector<int> mergeKArrays(vector<vector<int>>& arrays) {
    // Min heap: {value, arrayIdx, elemIdx}
    priority_queue<tuple<int,int,int>,
                   vector<tuple<int,int,int>>,
                   greater<>> minH;

    // Har array ka pehla element heap mein daalo
    for (int i = 0; i < arrays.size(); i++)
        if (!arrays[i].empty())
            minH.push({arrays[i][0], i, 0});

    vector<int> result;
    while (!minH.empty()) {
        auto [val, ai, ei] = minH.top(); minH.pop();
        result.push_back(val);
        // Is array mein aur elements hain?
        if (ei + 1 < arrays[ai].size())
            minH.push({arrays[ai][ei+1], ai, ei+1});
    }
    return result;
}

// Kth Smallest in M×N Sorted Matrix (LeetCode 378)
int kthSmallestMatrix(vector<vector<int>>& matrix, int k) {
    int n = matrix.size();
    priority_queue<tuple<int,int,int>,
                   vector<tuple<int,int,int>>,
                   greater<>> minH;

    for (int i = 0; i < n; i++)
        minH.push({matrix[i][0], i, 0}); // har row ka pehla element

    while (--k) {
        auto [val, r, c] = minH.top(); minH.pop();
        if (c + 1 < n) minH.push({matrix[r][c+1], r, c+1});
    }
    return get<0>(minH.top());
}
Median from Data Stream
📊
Find Median from Data StreamLeetCode 295 · Hard
🇬🇧 Intuition
Use two heaps: a max heap for the lower half and a min heap for the upper half. Keep them balanced (sizes differ by at most 1).
• Median = max heap top (odd total) or average of both tops (even total).
🇮🇳 Hinglish
Do heaps use karo: Max heap = lower half ke numbers (bade numbers top pe). Min heap = upper half ke numbers (chhote numbers top pe).
Dono roughly equal size mein rakho. Median = max heap ka top (odd) ya dono tops ka average (even). Har new element pe balance maintain karo!
Stream: 1, 2, 3, 4, 5 → Medians: 1, 1.5, 2, 2.5, 3
add 1
maxH=[1], minH=[]. |maxH|=1 > |minH|+1? No. Median=maxH.top()=1
median=1
add 2
Push to maxH=[2,1], balance: pop max(2) to minH. maxH=[1],minH=[2]. Median=(1+2)/2=1.5
median=1.5
add 3
Push to maxH=[3,1], balance: pop max(3) to minH=[2,3]. maxH=[1]. Wait—rebalance: |minH|>|maxH|, pop min(2) to maxH=[2,1]. median=maxH.top()=2
median=2
add 4,5
Same process... maxH=[lower half], minH=[upper half]
✅ Always O(log n) add, O(1) median
🔵 C++ · Median Finder — Two Heaps
class MedianFinder {
    priority_queue<int> maxH;                            // lower half
    priority_queue<int,vector<int>,greater<int>> minH; // upper half
public:
    void addNum(int num) {
        // Pehle maxH mein daalo
        maxH.push(num);

        // maxH ka top minH ke top se bada? Cross karna nahi chahiye
        if (!minH.empty() && maxH.top() > minH.top()) {
            minH.push(maxH.top()); maxH.pop();
        }

        // Size balance karo — maxH ya minH ek se zyada bada nahi hona chahiye
        if (maxH.size() > minH.size() + 1) {
            minH.push(maxH.top()); maxH.pop();
        } else if (minH.size() > maxH.size()) {
            maxH.push(minH.top()); minH.pop();
        }
    }

    double findMedian() {
        if (maxH.size() > minH.size())
            return maxH.top();                         // odd total → middle
        return (maxH.top() + minH.top()) / 2.0;      // even → average
    }
};
💡 Two Heaps pattern: maxH = lower half (top = largest of small), minH = upper half (top = smallest of large). Balance maintain karo — dono size mein 1 se zyada difference nahi!
