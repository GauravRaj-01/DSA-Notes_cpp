Section 1 — The Monotonic Stack Mechanics
📈
Strict Sorting on LIFOCore Theory
🇬🇧 Core Concept
A Monotonic Stack restricts operations so its internal values are always sorted in a strict range:
• Increasing Monotonic Stack: st.top() is always the largest element. Before pushing x, we pop all elements >= x. Used to discover Previous Smaller or Next Smaller bounds.
• Decreasing Monotonic Stack: st.top() is always the smallest element. Before pushing x, we pop all elements <= x. Used to discover Previous Greater or Next Greater bounds.
🇮🇳 Hinglish
Monotonic Stack me hum push karne ke dauran check lagate hain taaki stack ke andar elements strictly sorted order me hi rahein:
• Increasing Stack: Naya number tabhi push hoga jab woh top se bada ho. Agar chota number aaya, toh jab tak stack ke badhe elements ko pop nahi kar dete, tab tak push nahi hoga. Yeh hume **Next Smaller** ya **Previous Smaller** index nikalne me kaam aata hai.
• Decreasing Stack: Naya number tabhi push hoga jab woh top se chota ho. Agar bada number aaya, toh smaller items ko pop karke rasta saaf karte hain. Yeh hume **Next Greater** ya **Previous Greater** index batata hai.
Section 2 — All 4 Nearest Element Variants

Here is the complete math cheat sheet for nearest neighbors with ready-to-use in-depth implementations.

1
Next Greater Element (NGE)Right Side · Decreasing Stack
🇮🇳 Hinglish Explanation
Right side me sabse pehla strict bada element. Kyunki hume Right side dekhna hai, toh array ko piche se (right to left) scan karenge. Decreasing monotonic structure use karke chote elements ko pop kar denge.
🔵 C++ · NGE (Right to Left)
vector<int> nextGreater(vector<int>& arr) {
    int n = arr.size();
    vector<int> ans(n, -1);
    stack<int> st; // decreasing
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && st.top() <= arr[i]) st.pop();
        if (!st.empty()) ans[i] = st.top();
        st.push(arr[i]);
    }
    return ans;
}
2
Next Smaller Element (NSE)Right Side · Increasing Stack
🇮🇳 Hinglish Explanation
Right side me sabse pehla strict chota element. Scan piche se (right to left) hi hoga, par increasing stack rakhne ke liye badhe numbers ko pop kar denge.
🔵 C++ · NSE (Right to Left)
vector<int> nextSmaller(vector<int>& arr) {
    int n = arr.size();
    vector<int> ans(n, -1);
    stack<int> st; // increasing
    for (int i = n - 1; i >= 0; i--) {
        while (!st.empty() && st.top() >= arr[i]) st.pop();
        if (!st.empty()) ans[i] = st.top();
        st.push(arr[i]);
    }
    return ans;
}
3
Previous Greater Element (PGE)Left Side · Decreasing Stack
🇮🇳 Hinglish Explanation
Left side me sabse pehla strict bada element. Kyunki boundary Left dekhni hai, hum array ko **aage se (left to right)** scan karenge, aur stack me elements maintain karenge.
🔵 C++ · PGE (Left to Right)
vector<int> prevGreater(vector<int>& arr) {
    int n = arr.size();
    vector<int> ans(n, -1);
    stack<int> st; // decreasing
    for (int i = 0; i < n; i++) {
        while (!st.empty() && st.top() <= arr[i]) st.pop();
        if (!st.empty()) ans[i] = st.top();
        st.push(arr[i]);
    }
    return ans;
}
4
Previous Smaller Element (PSE)Left Side · Increasing Stack
🇮🇳 Hinglish Explanation
Left side me sabse pehla strict chota element. Aage se loop chalayenge aur increasing values maintain karenge (popping larger items).
🔵 C++ · PSE (Left to Right)
vector<int> prevSmaller(vector<int>& arr) {
    int n = arr.size();
    vector<int> ans(n, -1);
    stack<int> st; // increasing
    for (int i = 0; i < n; i++) {
        while (!st.empty() && st.top() >= arr[i]) st.pop();
        if (!st.empty()) ans[i] = st.top();
        st.push(arr[i]);
    }
    return ans;
}
Section 3 — The Range / Span Pattern
📊
Online Stock Span MechanicsRange Formula Mapping
🇬🇧 Core Concept
Finding consecutive days before index i where price is smaller or equal mathematically means finding the index of the Previous Greater Element (PGE), say index p.
Formula: span = i - p.
If no previous greater element exists, the price is higher than all previous prices, so span = i + 1.
🇮🇳 Hinglish
Stock ka span nikalna, matlab index i se piche kitne continuous elements chote ya barabar hain, aur kuch nahi balki **Previous Greater Element (PGE)** ka index distance nikalna hai!
Manlo index i se pehle ka strict bada element index p par hai.
Toh span = i - p.
Agar left me koi bada element na ho, matlab aaj ka rate sabse badha hai, toh span = i + 1.

Section 4 — Min & Max Stacks Design
📐
The O(1) Space Encoding FormulaMathematical Proof
🇬🇧 Theoretical Proof
To achieve O(1) extra space in a Min Stack, we encode values dynamically when a new minimum is set. Let minVal be the current minimum, and we push a new value x where x < minVal:
• Push value (encoded): top = 2 * x - minVal. We then set minVal = x.
• Why this holds: Since x < minVal, we know x - minVal < 0. Adding x to both sides gives 2 * x - minVal < x. Thus, the encoded top value pushed to stack is strictly less than the new minVal. This acts as a flag!
• Pop value (decoding): If st.top() < minVal, it means we are popping the current minimum. We recover the old minimum via: oldMin = 2 * minVal - st.top().
🇮🇳 Hinglish Proof
Bina extra stack ke pure Min Stack ko **O(1) auxiliary space** me chalane ka secret mathematical scaling hai. Jab hume naya absolute minimum x milega, hum stack me x ki jagah ek **fake encoded value** push karenge:
• **Push Code**: top = 2 * x - minVal. Phir naya minVal = x update kar do.
• **Kyun chalta hai**: Kyunki x < minVal hai, toh x - minVal negative hoga. Matlab 2 * x - minVal value strictly x se choti banegi. Stack me aisi negative flag values real numbers ke bounds ke niche chali jati hain, jo hume alert karti hain!
• **Pop Code (Decoding)**: Jab hum stack ke top ko pop karenge aur top value minVal se choti milegi, toh hume pata chal jayega ki min change hone wala hai. Purana min formula se niklega: oldMin = 2 * minVal - top.
🔵 C++ · Min Stack (O(1) Space Mathematical Encoding)
class MinStackSpaceOpt {
    stack<long long> st;
    long long minVal;
public:
    void push(int val) {
        if (st.empty()) {
            st.push(val);
            minVal = val;
        } else if (val < minVal) {
            // Encode and update minVal
            st.push(2LL * val - minVal);
            minVal = val;
        } else {
            st.push(val);
        }
    }
    
    void pop() {
        if (st.top() < minVal) {
            // Decode previous minimum before popping flag
            minVal = 2LL * minVal - st.top();
        }
        st.pop();
    }
    
    int top() {
        if (st.top() < minVal) return minVal;
        return st.top();
    }
    
    int getMin() {
        return minVal;
    }
};
📦
Max Stack Design (O(1) Space)Dual Concept
🇮🇳 Hinglish Explanation
Symmetrical concept! Max Stack ke liye push trigger tab hoga jab x > maxVal.
• Push encoded: top = 2 * x - maxVal, set maxVal = x.
• Symmetrical flags: values top strictly maximum node bounds se badhi chali jati hain.
• Pop recovery: oldMax = 2 * maxVal - top.
🔵 C++ · Max Stack (O(1) Space Encoding)
class MaxStackSpaceOpt {
    stack<long long> st;
    long long maxVal;
public:
    void push(int val) {
        if (st.empty()) {
            st.push(val);
            maxVal = val;
        } else if (val > maxVal) {
            st.push(2LL * val - maxVal);
            maxVal = val;
        } else {
            st.push(val);
        }
    }
    
    void pop() {
        if (st.top() > maxVal) {
            maxVal = 2LL * maxVal - st.top(); // Decode previous max
        }
        st.pop();
    }
    
    int top() {
        if (st.top() > maxVal) return maxVal;
        return st.top();
    }
    
    int getMax() {
        return maxVal;
    }
};
Section 5 — Bracket Expression Handling
🧱
Bracket Parsing MachineLeetCode 20
🇮🇳 Hinglish Explanation
Brackets sequence tracking ke liye stack hi kyu use hota hai? Kyunki nested structures me jo inner-most loop (bracket) pehle open hua, use pehle match hona padega (LIFO order!).
🔵 C++ · Standard Valid Parentheses
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') st.push(c);
        else {
            if (st.empty()) return false;
            char top = st.top();
            if ((c == ')' && top == '(') ||
                (c == ']' && top == '[') ||
                (c == '}' && top == '{')) st.pop();
            else return false;
        }
    }
    return st.empty();
}
Section 6 — Expression Evaluation (RPN Calculator)
🧮
Evaluate Reverse Polish NotationLeetCode 150
🇬🇧 Core Idea
Postfix expressions (like "2", "1", "+", "3", "*" representing (2+1)*3) avoid parenthesis ordering completely.
Iterate through tokens. When a number is found, push to stack. When an operator is found, pop two elements: operand2 = pop() and operand1 = pop(). Perform calculation and push the result back.
🇮🇳 Hinglish
Postfix expressions ko parse karna. Jab tak numbers mil rahe hain, unhe stack me push karte jao. Jaise hi koi mathematical operator (+, -, *, /) mile, stack se immediate do elements pop karo: pahla pop kiya hua element right operand (val2) banega aur dusra left operand (val1). Operation karke result ko stack me wapas push kar do!
🔵 C++ · Evaluate RPN
int evalRPN(vector<string>& tokens) {
    stack<int> st;
    for (const string& s : tokens) {
        if (s == "+" || s == "-" || s == "*" || s == "/") {
            int val2 = st.top(); st.pop(); // Second operand popped first
            int val1 = st.top(); st.pop(); // First operand popped second
            
            if (s == "+") st.push(val1 + val2);
            else if (s == "-") st.push(val1 - val2);
            else if (s == "*") st.push(val1 * val2);
            else if (s == "/") st.push(val1 / val2);
        } else {
            st.push(stoi(s)); // Convert string to integer
        }
    }
    return st.top();
}

Section 7 — Largest Rectangle in Histogram (LeetCode 84)
📊
Area Bounds TracingSingle Pass O(N)
🇬🇧 Technical Explanation
To find the maximum rectangular bounds for height heights[i], we require the indices of the **Next Smaller Element (NSE)** and the **Previous Smaller Element (PSE)**.
• Width: NSE_index - PSE_index - 1.
• Optimization to Single Pass: We push indices onto a Monotonic Increasing Stack. When we encounter a bar currHeight at index i smaller than the top of the stack, we know i is the **NSE** for the popped element. The **PSE** for the popped element is the *new* top of the stack. This resolves boundaries instantly!
🇮🇳 Hinglish Explanation
Kisi bar ki height par maximum kitna area ban sakta hai? Jab tak hum right side me pehle chote bar (NSE) aur left side me pehle chote bar (PSE) ke beech boundaries na bana lein.
**Single Pass Optimization Trick**: Hum elements ke indices ko **Increasing Monotonic Stack** me rakhte hain. Jaise hi koi chota element heights[i] milega, hum top ko pop karenge:
1. **NSE index** = i (jo element pop karwa raha hai).
2. **PSE index** = Pop hone ke baad stack ka **naya top** (agar stack khali ho toh matlab pure left me sab bade the, toh boundary is -1).
Formula width: i - st.top() - 1. Area: popped_height * width.
🔵 C++ · Largest Rectangle (Fully Optimized Single Pass)
int largestRectangleArea(vector<int>& heights) {
    int n = heights.size();
    stack<int> st; // Increasing Monotonic Stack for indices
    int maxArea = 0;
    
    for (int i = 0; i <= n; i++) {
        // We push a dummy height of 0 at index 'n' to clear out remaining stack elements
        int currHeight = (i == n) ? 0 : heights[i];
        
        while (!st.empty() && heights[st.top()] > currHeight) {
            int height = heights[st.top()];
            st.pop();
            
            // Calculate boundary width dynamically
            int width = st.empty() ? i : i - st.top() - 1;
            maxArea = max(maxArea, height * width);
        }
        st.push(i);
    }
    return maxArea;
}
Section 8 — Maximal Rectangle in 2D Binary Matrix (LeetCode 85)
📐
2D Area Grid ReductionLeetCode 85 · Hard
🇬🇧 Core Reduction Concept
We can reduce this 2D binary grid problem to the 1D **Largest Rectangle in Histogram** problem!
We construct a 1D height array (representing histogram bars at each column). We iterate row by row:
- If matrix[r][c] == '1': heights[c] += 1.
- If matrix[r][c] == '0': heights[c] = 0 (since the bar is broken).
At each row, we calculate the maximum histogram area on this heights array using our LeetCode 84 subroutine.
🇮🇳 Hinglish Reduction
2D binary grid me '1's se bana sabse bada area rectangle nikalna.
**Ek dimagi reduction trick**: Hum pure 2D grid ko row-by-row parse karke 1D Histogram area problem (LeetCode 84) me badal dete hain!
Hum ek 1D heights array banate hain. Har row par chalte hue:
- Agar cell '1' hai -> column heights badhao -> heights[c] += 1.
- Agar cell '0' hai -> column path break ho gaya -> heights[c] = 0.
Har single row step par, is heights array ko as a histogram pass karke max area compute kar lete hain. Simple!
🔵 C++ · 2D Maximal Rectangle Area
int maximalRectangle(vector<vector<char>>& matrix) {
    if (matrix.empty() || matrix[0].empty()) return 0;
    int cols = matrix[0].size();
    vector<int> heights(cols, 0);
    int maxArea = 0;
    
    for (const auto& row : matrix) {
        for (int c = 0; c < cols; c++) {
            if (row[c] == '1') {
                heights[c] += 1; // Stack upward height
            } else {
                heights[c] = 0;  // Broken ground base
            }
        }
        // Run the LeetCode 84 optimized single-pass algorithm on current heights row
        maxArea = max(maxArea, largestRectangleArea(heights));
    }
    return maxArea;
}
