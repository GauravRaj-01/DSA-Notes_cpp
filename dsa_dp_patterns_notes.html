1D DP & Fibonacci Style

Linear states aur single dimension transitions. State transition equation completely 1D array ya variables pe compute ho sakti hai. O(N) space ko O(1) space me optimization ke liye perfect candidates.

1D Subproblems O(N) Time O(1) Space Optimal
Pattern 1 — Climbing Stairs (Fibonacci Transition)
🧗
Climbing StairsLeetCode 70
🇬🇧 Core Concept
You are climbing a staircase that takes n steps to reach the top. Each time you can either climb 1 or 2 steps. In how many distinct ways can you climb to the top?
Mathematically: To reach step i, you must have either stepped from i-1 (climbing 1 step) or from i-2 (climbing 2 steps). Hence, the recurrence relation is:
dp[i] = dp[i-1] + dp[i-2] with base cases dp[1] = 1, dp[2] = 2.
🇮🇳 Hinglish
Aapko n steps tak chadhna hai. Har baar aap ya toh 1 step le sakte ho ya 2 steps.
**Intuition**: Socho agar aap aakhri step i pe ho, toh wahan kaise pahunche? Ya toh 1 step pehle (i-1) se chhalang lagayi hogi, ya fir 2 steps pehle (i-2) se!
Isliye, i tak pahunchne ke total tarike = (i-1 ke tarike) + (i-2 ke tarike). Yani dp[i] = dp[i-1] + dp[i-2]. Yeh bilkul standard Fibonacci progression hai!

🔵 C++ · Space Optimized O(1) Space
int climbStairs(int n) {
    if (n <= 2) return n;
    
    int prev2 = 1; // represents dp[i-2]
    int prev1 = 2; // represents dp[i-1]
    int curr = 0;
    
    for (int i = 3; i <= n; i++) {
        curr = prev1 + prev2; // recurrence relation
        prev2 = prev1;        // shift values forward
        prev1 = curr;
    }
    return prev1;
}
💡 Space Optimization Trick: Jab hume transition ke liye sirf pichle do values (dp[i-1] aur dp[i-2]) chahiye ho, toh pure array ki jagah sirf do variables use karke space complexity ko O(N) se ghata kar O(1) kiya ja sakta hai!
Pattern 2 — House Robber (Include/Exclude Choice)
💰
House RobberLeetCode 198
🇬🇧 Core Idea
You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. The only constraint is that adjacent houses have security systems connected, and it will automatically contact the police if two adjacent houses are broken into on the same night.
For each house i, you have two choices:
1. **Rob it**: You get nums[i] + max_loot_till[i-2] (cannot rob house i-1).
2. **Skip it**: You get max_loot_till[i-1].
Recurrence Relation: dp[i] = max(nums[i] + dp[i-2], dp[i-1]).
🇮🇳 Hinglish
Aapko ek line me lage gharo me chori karni hai. Shart yeh hai ki aap lagaatar do gharo (adjacent) me chori nahi kar sakte warna alarm baj jaayega!
**Decision Structure**: Har ghar i par aakar aapke paas do raaste hain:
1. **Rob house i**: Agar isko chuna, toh i-1 ko skip karna padega. Total paisa = nums[i] + i-2 tak ka max loot.
2. **Skip house i**: Agar is ghar ko choda, toh jo i-1 tak ka max loot tha, wahi aage aayega.
Maximum nikal lo: dp[i] = max(nums[i] + dp[i-2], dp[i-1]).

🔵 C++ · House Robber (Space Optimized)
int rob(vector<int>& nums) {
    int n = nums.size();
    if (n == 0) return 0;
    if (n == 1) return nums[0];
    
    int prev2 = nums[0];          // represents dp[i-2]
    int prev1 = max(nums[0], nums[1]); // represents dp[i-1]
    int curr = 0;
    
    for (int i = 2; i < n; i++) {
        curr = max(nums[i] + prev2, prev1); // Rob or Skip decision
        prev2 = prev1;                      // Shift window
        prev1 = curr;
    }
    return prev1;
}

Pattern 3 — 0/1 Knapsack Problem (Bounded Choice)
🎒
0/1 KnapsackMother of Bounded DP
🇬🇧 Core Idea
Given weights wt[] and values val[] of n items, put these items in a knapsack of capacity W to get the maximum total value in the knapsack. You can either take an item as a whole (1) or skip it (0).
For item at index i (1-based) and remaining capacity j:
- **Take item** (if wt[i-1] <= j): val[i-1] + dp[i-1][j - wt[i-1]]
- **Skip item**: dp[i-1][j]
Recurrence: dp[i][j] = max(val[i-1] + dp[i-1][j - wt[i-1]], dp[i-1][j]).
🇮🇳 Hinglish
Aapko ek bag diya gaya hai jiski capacity W hai. Kuch items hain jinka weight wt[] aur value val[] hai. Bag me items daal kar maximum profit banana hai. Har item ko lene ka ya toh pura option hai (1) ya chhodne ka (0) — half fraction allow nahi hai.
**Decision Transition**: Agar current item ka weight bag ki capacity j se kam ya equal hai, toh aap maximum nikalte hain:
- Item ko **Bag me daal lo**: Profit badhega, bag ki capacity khatt jayegi -> val[i-1] + dp[i-1][j - wt[i-1]].
- Item ko **Skip kar do**: Wahi capacity j rahegi par item aage nikal jayega -> dp[i-1][j].
wt = [1, 2, 3], val = [10, 15, 40], Capacity W = 4 → DP Grid [i][j]
Items \ Cap j=0 j=1 j=2 j=3 j=4
i=0 (None) 0 0 0 0 0
i=1 (wt=1, v=10) 0 10 10 10 10
i=2 (wt=2, v=15) 0 10 15 25 25
i=3 (wt=3, v=40) 0 10 15 40 50
At dp[3][4]: We can choose item 3 (wt=3, val=40) -> 40 + dp[2][4-3=1] = 40 + 10 = 50. Or skip it -> dp[2][4] = 25. Max is 50!
✅ Max profit = 50
🔵 C++ · Space-Optimized 1D Row DP
int knapsack(int W, vector<int>& wt, vector<int>& val) {
    int n = wt.size();
    // We only need the previous row to calculate the current row.
    // Loop backwards to use a single 1D array in-place!
    vector<int> dp(W + 1, 0);
    
    for (int i = 0; i < n; i++) {
        // Loop capacity backwards from W down to wt[i]
        for (int j = W; j >= wt[i]; j--) {
            dp[j] = max(dp[j], val[i] + dp[j - wt[i]]);
        }
    }
    return dp[W];
}
⚠️ Space-optimization me backward loop (j = W down to wt[i]) chalana crucial hai! Agar aap aage se loop chalayenge toh same index ko bar-bar select kar lenge, jo ki Unbounded Knapsack ban jayega. Backward loop se hum current row me purane row ke values ko bina overwrite kiye use kar pate hain.
Pattern 4 — Subset Sum Problem
➕
Subset SumBoolean Target Verification
🇬🇧 Core Idea
Given a set of non-negative integers arr[] and a value sum, determine if there is a subset of the given set with a sum equal to given sum.
This is a variation of 0/1 Knapsack where target is sum and return type is boolean.
Recurrence: dp[i][j] = dp[i-1][j] || dp[i-1][j - arr[i-1]] (if arr[i-1] <= j).
🇮🇳 Hinglish
Aapko ek numbers ka array arr[] diya hai aur ek target sum. Pucha hai ki kya koi aisa group (subset) ban sakta hai jiska sum target ke barabar ho?
**Intuition**: Yeh 0/1 Knapsack jaisa hi hai, bas isme values aur weight alag nahi hain. Weight hi target sum hai!
Har number ke paas do choices hain:
- Number ko **Include karo** (agar chota hai sum se): Sum se subtract ho jayega target -> check if remaining target can be made: dp[i-1][j - arr[i-1]].
- Number ko **Exclude karo**: Target same rahega -> dp[i-1][j].
Dono me se koi ek bhi true de de, toh overall return true ho jayega (OR operation)!
🔵 C++ · Subset Sum (Space Optimized)
bool isSubsetSum(vector<int>& arr, int sum) {
    int n = arr.size();
    vector<bool> dp(sum + 1, false);
    
    // Base case: Sum 0 is always possible (empty subset)
    dp[0] = true;
    
    for (int i = 0; i < n; i++) {
        for (int j = sum; j >= arr[i]; j--) {
            if (dp[j - arr[i]]) {
                dp[j] = true;
            }
        }
    }
    return dp[sum];
}

Pattern 5 — Longest Common Subsequence (LCS)
✨
Longest Common SubsequenceLeetCode 1143
🇬🇧 Core Idea
Given two strings text1 and text2, return the length of their longest common subsequence. A subsequence of a string is a new string generated from the original string with some characters (can be none) deleted without changing the relative order of the remaining characters.
- **If characters match** (text1[i-1] == text2[j-1]): We increment LCS by 1 and move both indices -> 1 + dp[i-1][j-1].
- **If mismatch**: We take the maximum of keeping one pointer fixed and changing the other -> max(dp[i-1][j], dp[i][j-1]).
🇮🇳 Hinglish
Do strings text1 aur text2 ke beech ka sabse lamba common subsequence (jo bina sequence change kiye characters uthaye) nikalna hai.
**Transition Strategy**: Hum piche se character check karte hain:
- Agar **Characters match ho gaye**: Matlab hume 1 matching mil gayi! Hum dono string me aage wale part pe badh jayenge -> 1 + dp[i-1][j-1].
- Agar **Mismatch hai**: Toh ho sakta hai common part text1 me aage mile ya text2 me. Dono scenarios explore karo aur max choose karo -> max(dp[i-1][j], dp[i][j-1]).
text1 = "abcde", text2 = "ace" → 2D Dependency Filling
Match transition: (i,j) ↘ (i-1,j-1) | Mismatch transition: (i,j) → max( (i-1,j), (i,j-1) )
i \ j Ø a c e
Ø 0 0 0 0
a 0 1 ↘ 0 1 1
b 0 1 1 1
c 0 1 2 ↘ 1 2
d 0 1 2 2
e 0 1 2 3 ↘ 2
✅ LCS length = 3 ("ace")
🔵 C++ · Longest Common Subsequence (Space Optimized)
int longestCommonSubsequence(string text1, string text2) {
    int m = text1.size(), n = text2.size();
    // We only need the previous row's state to calculate the current row!
    vector<int> prev(n + 1, 0), curr(n + 1, 0);
    
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1[i - 1] == text2[j - 1]) {
                curr[j] = 1 + prev[j - 1]; // Match transition
            } else {
                curr[j] = max(prev[j], curr[j - 1]); // Mismatch
            }
        }
        prev = curr; // Shift current state row to previous
    }
    return prev[n];
}
Pattern 6 — Longest Palindromic Subsequence
🔄
Longest Palindromic SubsequenceLeetCode 516
🇬🇧 Core Idea
Given a string s, find the longest palindromic subsequence's length in s.
**Genius Reduction Trick**: A palindrome reads the same backwards as forwards. Therefore, the Longest Palindromic Subsequence of string s is exactly equal to the **Longest Common Subsequence (LCS)** of string s and its reversed version s_reverse!
LPS = LCS(s, reverse(s)).
🇮🇳 Hinglish
Aapko string s me se sabse bada Palindromic (jo aage se aur piche se same ho) subsequence nikalna hai.
**Ek majedar logic trick**: Palindrome wahi hota hai jo piche se reverse karne par badle na! Toh agar hum original string s aur uski ultee (reverse) string s_reverse ke beech ka Longest Common Subsequence (LCS) nikal lein, toh hume wahi maximum palindromic subsequence mil jaayega!
Hume alag se naya code likhne ki zarurat hi nahi hai! Bas input string ko reverse karke LCS call kar do.
🔵 C++ · Longest Palindromic Subsequence
int longestPalindromeSubseq(string s) {
    string r = s;
    reverse(r.begin(), r.end()); // Reverse original string
    
    // reuse the optimized LCS subroutine!
    return longestCommonSubsequence(s, r);
}
