Comparison-Based Simple Sorts

Basic sorting algorithms jo arrays ko adjacent element elements comparison ya elements insertion se sort karte hain. Inka average time complexity O(N²) hota hai.

O(N²) Avg Time O(1) Space In-Place Sorting
Algorithm 1 — Bubble Sort (Sinking Sort)
🧼
Bubble SortSimple & Intuitive
🇬🇧 Core Concept
Repeatedly steps through the list, compares adjacent elements and swaps them if they are in the wrong order. In each pass, the largest unsorted element "bubbles up" to its correct position at the end. An optimization is to use a swapped boolean to stop early if the array is already sorted.
🇮🇳 Hinglish
Isme hum pure array mein adjacent (pass wale) elements ko compare karte hain aur agar pehla element dusre se bada ho, toh unhe swap (apasi badal) kar dete hain. Har pass ke baad, sabse bada element bubble ki tarah aakhri mein apni sahi jagah pe pahunch jata hai! Array agar already sorted ho jaye, toh beech me rukne ke liye hum swapped check lagate hain.

🔵 C++ · Optimized Bubble Sort
void bubbleSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        bool swapped = false;
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                swap(arr[j], arr[j + 1]);
                swapped = true; // elements swap hue
            }
        }
        // Agar kisi pass me swap nahi hua, matlab array sorted hai!
        if (!swapped) break;
    }
}
💡 Key optimization: swapped check lagane se Best-case Time Complexity O(N) ho jati hai (agar input already sorted ho).
Algorithm 2 — Selection Sort
🎯
Selection SortMin Swaps
🇬🇧 Core Concept
Divides the array into a sorted and an unsorted region. It repeatedly finds the minimum element from the unsorted region and swaps it with the first element of that unsorted region. This "selects" the smallest remaining item and places it in order.
🇮🇳 Hinglish
Isme hum poore unsorted part mein se sabse chota (minimum) element dhundhte hain aur use unsorted part ke pehle element ke sath swap (badal) dete hain. Aise karte-karte, sorted boundary aage badhti jati hai. Iska sabse bada advantage yeh hai ki isme maximum **N swaps** hi hote hain.

🔵 C++ · Selection Sort
void selectionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        int minIdx = i; // minimum element ka index track karein
        for (int j = i + 1; j < n; j++) {
            if (arr[j] < arr[minIdx]) {
                minIdx = j; // new minimum found
            }
        }
        // swap minimum with the first element of unsorted part
        swap(arr[i], arr[minIdx]);
    }
}
⚠️ Selection Sort is unstable by default. Kyunki swaps long distances pe hote hain jo duplicate elements ke original order ko change kar sakte hain.
Algorithm 3 — Insertion Sort
🃏
Insertion SortCard Playing Analogy
🇬🇧 Core Concept
Builds the final sorted array one item at a time. It takes each element from the unsorted part and shifts larger elements to the right to make room, then inserts the current element into its correct relative position within the sorted subset (like sorting cards in your hand).
🇮🇳 Hinglish
Jaise hum tash (playing cards) khelte waqt apne haath ke cards ko ek-ek karke unki sahi place par insert karte hain, bilkul wahi Insertion Sort hai! Hum element ko lete hain (jise key bolte hain) aur sorted array ke elements se compare karte hue peeche khiskaate hain, jab tak ki hume uski sahi position na mil jaye.

🔵 C++ · Insertion Sort
void insertionSort(vector<int>& arr) {
    int n = arr.size();
    for (int i = 1; i < n; i++) {
        int key = arr[i]; // Current card to insert
        int j = i - 1;
        
        // Shift elements that are greater than key
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j]; // Shift right
            j--;
        }
        arr[j + 1] = key; // Insert key at correct position
    }
}
💡 Insertion Sort is highly efficient for **nearly sorted** or small datasets. Almost sorted list par iska time complexity O(N) ho jata hai.

Divide & Conquer / Advanced Sorts

Algorithm 4 — Merge Sort
🧩
Merge SortDivide & Conquer · Stable
🇬🇧 Core Idea
Recursively splits the array into two halves until single-element arrays are reached (which are inherently sorted). Then, it merges these sorted sub-arrays back together in a sorted fashion using helper pointers. This algorithm is stable and has guaranteed O(N log N) time complexity, but requires extra space.
🇮🇳 Hinglish
Yeh "Divide and Conquer" approach par kaam karta hai. Array ko tab tak divide (aadha) karo jab tak single elements na bach jayein. Phir do sorted parts ko aapas me comparison karke merge (jodte) hain. Merge karne ke liye hum ek extra helper array banate hain. Iski complexity har condition me **O(N log N)** rehti hai jo boht consistent hai.

🔵 C++ · Merge Sort
void merge(vector<int>& arr, int l, int mid, int r) {
    int n1 = mid - l + 1, n2 = r - mid;
    vector<int> left(n1), right(n2);
    
    for (int i = 0; i < n1; i++) left[i] = arr[l + i];
    for (int i = 0; i < n2; i++) right[i] = arr[mid + 1 + i];
    
    int i = 0, j = 0, k = l;
    while (i < n1 && j < n2) {
        if (left[i] <= right[j]) {
            arr[k++] = left[i++];
        } else {
            arr[k++] = right[j++];
        }
    }
    while (i < n1) arr[k++] = left[i++];
    while (j < n2) arr[k++] = right[j++];
}

void mergeSort(vector<int>& arr, int l, int r) {
    if (l >= r) return;
    int mid = l + (r - l) / 2;
    mergeSort(arr, l, mid);     // Left half sort karo
    mergeSort(arr, mid + 1, r); // Right half sort karo
    merge(arr, l, mid, r);       // Dono ko merge karo
}
💡 Time Complexity is always O(N log N) because the array is recursively split into halves (log N levels) and merging takes O(N) at each level. Space Complexity is O(N).
Algorithm 5 — Quick Sort (Partition Exchange Sort)
⚡
Quick SortPivot Partitioning · Fast
🇬🇧 Core Idea
Selects a 'pivot' element and partitions the array such that all elements smaller than the pivot go to its left, and all elements larger than the pivot go to its right. It then recursively applies the same process to the left and right sub-arrays. Partitioning is done in-place.
🇮🇳 Hinglish
Isme hum ek element ko 'Pivot' chunte hain (jaise last element). Partitioning step me hum pivot ko uski sahi place par fit karte hain taaki uske left me saare chote elements hon, aur right me saare bade elements hon. Iske baad, pivot ke left aur right sub-arrays ko recursively call karke same tareeqe se sort kiya jata hai. In-place hone ki wajah se practical situations me yeh **bohat fast** hota hai.

🔵 C++ · Quick Sort (Lomuto Partition)
int partition(vector<int>& arr, int low, int high) {
    int pivot = arr[high]; // Pivoting last element
    int i = low - 1;       // Pointer for smaller element
    
    for (int j = low; j < high; j++) {
        if (arr[j] < pivot) {
            i++;
            swap(arr[i], arr[j]); // Chota mila, swap it to the left
        }
    }
    swap(arr[i + 1], arr[high]); // Pivot ko correct index pe swap karein
    return i + 1;                // Pivot position return
}

void quickSort(vector<int>& arr, int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, pi - 1);  // Left segment recursive sort
        quickSort(arr, pi + 1, high); // Right segment recursive sort
    }
}
⚠️ Worst Case Complexity of Quick Sort is O(N²). Aisa tab hota hai jab pivot consistently extreme elements (smallest ya largest) banta hai, jaise sorted array par last element pivot lena. Isse bachne ke liye **Randomized Quick Sort** use karte hain.
Algorithm 6 — Heap Sort
🪵
Heap SortBinary Heap · In-Place
🇬🇧 Core Idea
Visualizes the array as a Complete Binary Tree and builds a **Max Heap** (where the parent node is always greater than or equal to its child nodes). The maximum element (at the root) is repeatedly swapped with the last element of the heap and removed. The heap size is decremented, and the root is "heapified" to restore the max-heap property.
🇮🇳 Hinglish
Isme hum array ko ek Complete Binary Tree ki tarah visualize karte hain aur ek **Max Heap** banate hain (jisme root node humesha child nodes se bada ya equal hota hai). Root element array ka sabse bada number hota hai. Hum root ko aakhri element ke sath swap karte hain, tree ka size 1 se ghaata dete hain aur dobara root ko heapify karte hain taaki Max Heap barkarar rahe. Yeh process O(N log N) guaranteed detailed linear log sort in-place hai.
🔵 C++ · Heap Sort
void heapify(vector<int>& arr, int n, int i) {
    int largest = i;       // Root initialize
    int left = 2 * i + 1;  // Left child
    int right = 2 * i + 2; // Right child
    
    // Check if left child exists and is larger than root
    if (left < n && arr[left] > arr[largest])
        largest = left;
        
    // Check if right child exists and is larger than root
    if (right < n && arr[right] > arr[largest])
        largest = right;
        
    // If largest is not root, swap and recursively heapify
    if (largest != i) {
        swap(arr[i], arr[largest]);
        heapify(arr, n, largest);
    }
}

void heapSort(vector<int>& arr) {
    int n = arr.size();
    
    // Max Heap build karein (Non-leaf nodes se initiate)
    for (int i = n / 2 - 1; i >= 0; i--)
        heapify(arr, n, i);
        
    // One by one extract elements from heap
    for (int i = n - 1; i > 0; i--) {
        swap(arr[0], arr[i]); // Move current root to end
        heapify(arr, i, 0);   // Heapify the root node
    }
}
💡 Heap Sort is a great choice when memory is constrained. unlike Merge Sort, it is an In-place algorithm (Space complexity: O(1)), and unlike Quick Sort, its worst-case is guaranteed O(N log N).

Algorithm 7 — Counting Sort
📊
Counting SortInteger Range · O(N + K)
🇬🇧 Core Idea
Sorts the elements of an array by counting the number of occurrences of each unique element. The counts are accumulated to compute the exact target indices in the final sorted array. Best used when the range of input values (K) is not significantly larger than the size of the array (N).
🇮🇳 Hinglish
Isme hum elements ko aapas me compare nahi karte! Hum ek count array banate hain jahan har element ki frequency store karte hain. Phir, is count array ko prefix sum banakar exact position find karte hain ki kaun sa element sorted output me kis index pe jaayega. Yeh tabhi use hota hai jab array elements ki range (K) choti aur limited ho.

🔵 C++ · Stable Counting Sort
void countingSort(vector<int>& arr) {
    int n = arr.size();
    if (n <= 1) return;
    
    int maxVal = *max_element(arr.begin(), arr.end());
    vector<int> count(maxVal + 1, 0);
    vector<int> output(n);
    
    // Step 1: Store frequencies
    for (int x : arr) count[x]++;
    
    // Step 2: Accumulate (Prefix Sum)
    for (int i = 1; i <= maxVal; i++) {
        count[i] += count[i - 1];
    }
    
    // Step 3: Build output in reverse order (to keep it Stable!)
    for (int i = n - 1; i >= 0; i--) {
        output[count[arr[i]] - 1] = arr[i];
        count[arr[i]]--;
    }
    
    // Copy output back
    arr = output;
}
💡 Trick to make Counting Sort stable: Loop output building **backwards** from `n-1` to `0` and decrement `count[arr[i]]`. Isse duplicates ka relative order change nahi hota.
Algorithm 8 — Radix Sort
🔢
Radix SortDigit-by-Digit · O(D * (N + B))
🇬🇧 Core Idea
Sorts numbers digit-by-digit, starting from the Least Significant Digit (LSD) to the Most Significant Digit (MSD). It uses **Counting Sort** as a stable subroutine to sort the array based on the current digit place (1s, 10s, 100s, etc.).
🇮🇳 Hinglish
Yeh algorithm boht badhe numbers ko unki digits ke hisab se sort karta hai. Sabse pehle Least Significant Digit (unit's place) ke basis par, phir ten's place, phir hundred's place par sort karta hai. Is sorting ko stable rakhne ke liye base subroutine ke roop me **Counting Sort** ka use kiya jata hai. Iski total time complexity **O(D * (N + B))** hoti hai, jahan D digits ki count hai aur B numerical base hai (jaise decimal numbers ke liye 10).
🔵 C++ · Radix Sort (LSD)
void countingSortForRadix(vector<int>& arr, int exp) {
    int n = arr.size();
    vector<int> output(n);
    vector<int> count(10, 0); // Base is 10 (decimal digits)
    
    // Store count of occurrences of digit (arr[i]/exp)%10
    for (int i = 0; i < n; i++) {
        int digit = (arr[i] / exp) % 10;
        count[digit]++;
    }
    
    // Prefix sum to get actual placement indices
    for (int i = 1; i < 10; i++) {
        count[i] += count[i - 1];
    }
    
    // Stable output generation
    for (int i = n - 1; i >= 0; i--) {
        int digit = (arr[i] / exp) % 10;
        output[count[digit] - 1] = arr[i];
        count[digit]--;
    }
    
    arr = output;
}

void radixSort(vector<int>& arr) {
    int maxVal = *max_element(arr.begin(), arr.end());
    
    // Do stable counting sort for every digit place.
    // exp represents 10^i (1s, 10s, 100s, etc.)
    for (int exp = 1; maxVal / exp > 0; exp *= 10) {
        countingSortForRadix(arr, exp);
    }
}
Algorithm 9 — Bucket Sort (Bin Sort)
🪣
Bucket SortScatter & Gather · Avg O(N)
🇬🇧 Core Idea
Works by distributing the elements of an array into multiple groups called "buckets". Each bucket is then sorted individually, either using a different sorting algorithm (typically **Insertion Sort**) or recursively. Finally, the sorted buckets are gathered and concatenated to form the sorted output. Ideal for uniformly distributed floating-point numbers.
🇮🇳 Hinglish
Isme hum values ko alag-alag groups (buckets) me baant dete hain, jise hum **Scatter** step bolte hain. Har bucket ko phir hum independent sorted algorithm (usually **Insertion Sort**) se sort karte hain. Last step me, sabhi sorted buckets ke elements ko sequence me aapas me mila (gather) dete hain. Yeh floating-point ya ranges me uniformly distributed numbers ke liye best choice hai.
🔵 C++ · Bucket Sort (Range [0, 1])
void bucketSort(vector<float>& arr) {
    int n = arr.size();
    if (n <= 1) return;
    
    // Step 1: Create empty buckets
    vector<vector<float>> buckets(n);
    
    // Step 2: Distribute elements into buckets (Scatter)
    for (int i = 0; i < n; i++) {
        int bucketIdx = n * arr[i]; // Map float value to bucket index
        buckets[bucketIdx].push_back(arr[i]);
    }
    
    // Step 3: Sort individual buckets
    for (int i = 0; i < n; i++) {
        sort(buckets[i].begin(), buckets[i].end()); // Any sorting, e.g. insertion
    }
    
    // Step 4: Concatenate all buckets (Gather)
    int index = 0;
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < buckets[i].size(); j++) {
            arr[index++] = buckets[i][j];
        }
    }
}
💡 Bucket Sort runs in **O(N)** average time complexity, assuming a uniform distribution of values. Worst case defaults to **O(N²)** if all elements land in a single bucket.
