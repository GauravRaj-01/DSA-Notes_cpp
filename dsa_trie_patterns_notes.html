🌳 Trie — Basics

Prefix Tree — ek tree jahan har node ek character store karta hai. String problems ke liye O(L) insert/search, jahan L = word length.

O(L) insert/search Prefix sharing 26 children per node
🌳
Trie kya hai?
🇬🇧 English
A Trie (Prefix Tree) is a tree where each node represents a character. Words sharing a common prefix share the same path from root. Each node has up to 26 children (for lowercase letters). A isEnd flag marks where a complete word ends.

Key advantage: O(L) search/insert regardless of how many words are stored — far faster than O(L × N) with brute force string comparison.
🇮🇳 Hinglish
Trie (Prefix Tree) ek tree hai jahan har node ek character represent karta hai. Common prefix wale words ek hi path share karte hain root se. Har node mein 26 children (lowercase letters ke liye). isEnd flag batata hai kahan word khatam hota hai.

Key advantage: O(L) search/insert — chahe kitne bhi words stored ho. Brute force O(L×N) se bahut fast!

Trie Node Structure
🧱
TrieNode — C++ Implementation
🔵 C++ · Trie Node & Class
struct TrieNode {
    TrieNode* children[26];  // a-z ke liye
    bool isEnd;              // yahan koi word khatam hota hai?
    int  count;             // optional: kitne words yahan se guzre

    TrieNode() : isEnd(false), count(0) {
        fill(children, children + 26, nullptr);
    }
};

class Trie {
    TrieNode* root;
public:
    Trie() { root = new TrieNode(); }

    // INSERT: O(L) — L = word length
    void insert(string word) {
        TrieNode* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->children[idx])
                cur->children[idx] = new TrieNode();
            cur = cur->children[idx];
            cur->count++;   // prefix count badhao
        }
        cur->isEnd = true;  // word khatam yahan
    }

    // SEARCH: O(L) — exact word match
    bool search(string word) {
        TrieNode* cur = root;
        for (char c : word) {
            int idx = c - 'a';
            if (!cur->children[idx]) return false;
            cur = cur->children[idx];
        }
        return cur->isEnd;  // word exist karta hai?
    }

    // STARTS WITH: O(L) — prefix check
    bool startsWith(string prefix) {
        TrieNode* cur = root;
        for (char c : prefix) {
            int idx = c - 'a';
            if (!cur->children[idx]) return false;
            cur = cur->children[idx];
        }
        return true;  // prefix exist karta hai (word zaruri nahi)
    }
};
💡 Search aur StartsWith ka difference: Search mein cur->isEnd check karna zaroori hai. StartsWith mein sirf path exist karna kaafi hai!

🔤 Prefix Based

Insert/Search, Prefix Match, Autocomplete — Trie ka primary use case. Words ka common prefix share hona efficiently handle karo.

Prefix Match — Count & Find
🔢
Count Words with Prefix / Prefix CountPattern
🇬🇧 Intuition
Store a count (or prefixCount) at each node — incremented during insert. To count words with a prefix: traverse to the prefix end node, return its count. O(L) per query regardless of dictionary size!
🇮🇳 Hinglish
Har node mein ek count store karo — insert ke time badhao. Prefix wale words count karne ke liye: prefix ke end node tak jaao, uska count return karo. O(L) per query — dictionary size se independent!
🔵 C++ · Count Words with Prefix + Sum of Prefix Scores
struct TrieNode {
    TrieNode* ch[26] = {};
    int cnt = 0;   // kitne words yahan se guzre
    bool end = false;
};

class Trie {
    TrieNode* root = new TrieNode();
public:
    void insert(string& w) {
        auto cur = root;
        for (char c : w) {
            int i = c-'a';
            if(!cur->ch[i]) cur->ch[i] = new TrieNode();
            cur = cur->ch[i];
            cur->cnt++;   // EVERY node on path pe increment
        }
        cur->end = true;
    }

    // Prefix se kitne words start hote hain?
    int countPrefix(string& prefix) {
        auto cur = root;
        for (char c : prefix) {
            int i = c-'a';
            if(!cur->ch[i]) return 0; // prefix exists nahi
            cur = cur->ch[i];
        }
        return cur->cnt;   // yahan se guzre words = prefix wale words
    }

    // Sum of Prefix Scores (LC 2416)
    // Each word ka score = sum of countPrefix for all its prefixes
    int scorePath(string& w) {
        auto cur = root; int score = 0;
        for (char c : w) {
            cur = cur->ch[c-'a'];
            if(!cur) break;
            score += cur->cnt; // har prefix ka count add karo
        }
        return score;
    }
};
💡 cnt = yahan se kitne words guzre. Yeh trick prefix frequency O(L) mein deti hai. LC 2416 "Sum of Prefix Scores of Strings" mein yahi approach hai!
Autocomplete / All Words with Prefix
💡
Autocomplete — DFS after prefixPattern
🇬🇧 Intuition
Step 1: Traverse to the end of the prefix node.
Step 2: DFS from that node — collect all words (paths where isEnd=true).
This is the core pattern for search autocomplete (LC 1268).
🇮🇳 Hinglish
Step 1: Prefix ke end node tak traverse karo.
Step 2: Us node se DFS karo — saare words collect karo (jahan isEnd=true ho).
Yahi search autocomplete ka core pattern hai (LC 1268).
🔵 C++ · Autocomplete — All Words with Prefix
void dfsCollect(TrieNode* node, string& cur,
                  vector<string>& results) {
    if (!node) return;
    if (node->end) results.push_back(cur);  // word mila!

    for (int i = 0; i < 26; i++) {
        if (node->ch[i]) {
            cur.push_back('a' + i);         // char add karo
            dfsCollect(node->ch[i], cur, results);
            cur.pop_back();                  // backtrack!
        }
    }
}

vector<string> autocomplete(string prefix) {
    TrieNode* cur = root;
    // Step 1: Prefix tak jaao
    for (char c : prefix) {
        if (!cur->ch[c-'a']) return {}; // prefix nahi hai
        cur = cur->ch[c-'a'];
    }
    // Step 2: Us node se DFS — saare words collect karo
    vector<string> results;
    string current = prefix;
    dfsCollect(cur, current, results);
    return results;
}
// LC 1268: Search Suggestions System
// Top 3 suggestions for each prefix → same approach, limit to 3
💡 Autocomplete = Trie traversal + DFS with backtracking. Lexicographic order automatically milti hai agar children array index order mein traverse karo (a→z)!
Word Search II — Grid + Trie
🔲
Word Search IILeetCode 212
🇬🇧 Intuition
Insert all words into Trie. DFS on grid — at each cell, check if current path exists in Trie. If isEnd=true → word found! If no Trie child matches → prune (backtrack early). This avoids checking each word separately — O(m·n·4^L) instead of O(W·m·n·4^L).
🇮🇳 Hinglish
Saare words Trie mein insert karo. Grid pe DFS karo — har cell pe check karo current path Trie mein exist karta hai. isEnd=true → word mila! Trie child nahi mila → prune (early backtrack). Har word separately check karne ki zaroorat nahi → bahut fast!

🔵 C++ · Word Search II (Grid DFS + Trie)
vector<string> findWords(vector<vector<char>>& board,
                           vector<string>& words) {
    Trie trie;
    for (string& w : words) trie.insert(w); // saare words insert

    int m = board.size(), n = board[0].size();
    vector<string> result;
    int dirs[4][2] = {{0,1},{0,-1},{1,0},{-1,0}};

    function<void(int,int,TrieNode*,string&)> dfs =
        [&](int r, int c, TrieNode* node, string& path) {
        if (r<0||r>=m||c<0||c>=n||board[r][c]=='#') return;
        char ch = board[r][c];
        TrieNode* next = node->ch[ch-'a'];
        if (!next) return;   // Trie mein nahi → PRUNE!

        path.push_back(ch);
        board[r][c] = '#';   // visited mark

        if (next->end) {      // word mila!
            result.push_back(path);
            next->end = false; // duplicate avoid karo
        }

        for (auto& d : dirs)
            dfs(r+d[0], c+d[1], next, path);

        path.pop_back();
        board[r][c] = ch;     // restore (backtrack)
    };

    string path;
    for (int i=0; i<m; i++)
        for (int j=0; j<n; j++)
            dfs(i, j, trie.root, path);

    return result;
}
💡 Key optimization: found word ke baad next->end = false karo — warna same word duplicate aayega. Aur Trie pruning (if(!next) return) is algorithm ko O(W×m×n×4^L) se O(m×n×4^L) kar deta hai!
Replace Words (Shortest Prefix)
🔄
Replace WordsLeetCode 648
🇬🇧 Intuition
Insert all root words into Trie. For each word in sentence, traverse Trie until you hit an isEnd=true node → that's the shortest prefix → replace! If no prefix found → keep original word.
🇮🇳 Hinglish
Saare root words Trie mein insert karo. Sentence ke har word ke liye, Trie traverse karo jab tak isEnd=true node na mile → woh shortest prefix hai → replace karo! Prefix nahi mila → original word rakho.
🔵 C++ · Replace Words
string replaceWords(vector<string>& dictionary, string sentence) {
    Trie trie;
    for (string& root : dictionary) trie.insert(root);

    istringstream iss(sentence);
    string word, result;

    while (iss >> word) {
        TrieNode* cur = trie.root;
        string prefix;
        bool replaced = false;

        for (char c : word) {
            int i = c - 'a';
            if (!cur->ch[i]) break;  // prefix nahi mila
            cur = cur->ch[i];
            prefix += c;
            if (cur->end) {             // shortest prefix mila!
                result += (result.empty() ? "" : " ") + prefix;
                replaced = true;
                break;
            }
        }
        if (!replaced)
            result += (result.empty() ? "" : " ") + word;
    }
    return result;
}
// "the cattle was rattled" with roots ["cat","bat","rat"]
// → "the cat was rat"
💡 Trie mein isEnd milte hi immediately return karo — yahi shortest prefix milta hai! Agar DFS continue karo toh longer prefix milega jo galat hoga.

💡 Bitwise Trie (XOR Trie)

Numbers ko binary (bits) mein store karo — XOR maximize/minimize karo O(32) mein. Integers ke liye Prefix Trie!

32-bit integers O(32) = O(1) effectively Max/Min XOR
💡
Bitwise Trie — Core Concept
🇬🇧 English
Instead of characters (a-z), store bits (0 or 1) at each node. Each number traverses 32 levels (one per bit, MSB to LSB).
To maximize XOR: for each bit of query number, greedily go to the opposite bit child (XOR = 1 when bits differ). If opposite doesn't exist → go same side.
Only 2 children per node (0 or 1) instead of 26!
🇮🇳 Hinglish
Characters (a-z) ki jagah bits (0 ya 1) store karo. Har number 32 levels traverse karta hai (MSB se LSB).
XOR maximize karne ke liye: query number ke har bit ke liye, greedy jaao opposite bit child pe (XOR=1 jab bits alag hoon). Opposite nahi hai toh same side jaao.
Sirf 2 children per node (0 ya 1) — 26 nahi!

Problem 1 — Maximum XOR of Two Numbers
🔝
Maximum XOR of Two NumbersLeetCode 421
🇬🇧 Intuition
Insert all numbers into Bitwise Trie (bit by bit, MSB first). For each number, query the Trie greedily: for each bit, try to go to the opposite bit node (to get XOR=1 at this position). Build the maximum XOR bit by bit. O(32×N) = O(N).

🔵 C++ · Maximum XOR (Bitwise Trie)
struct BitNode {
    BitNode* ch[2] = {};  // sirf 0 aur 1 children!
};

class BitTrie {
    BitNode* root = new BitNode();
public:
    void insert(int num) {
        auto cur = root;
        for (int i = 31; i >= 0; i--) {  // MSB se LSB
            int bit = (num >> i) & 1;
            if (!cur->ch[bit]) cur->ch[bit] = new BitNode();
            cur = cur->ch[bit];
        }
    }

    // query: num ke saath maximum XOR nikalo
    int maxXOR(int num) {
        auto cur = root;
        int result = 0;
        for (int i = 31; i >= 0; i--) {
            int bit = (num >> i) & 1;
            int want = 1 - bit;  // opposite bit chahiye → XOR=1

            if (cur->ch[want]) {
                result |= (1 << i);  // yeh bit 1 ho gaya XOR mein
                cur = cur->ch[want];
            } else {
                cur = cur->ch[bit]; // opposite nahi → same side
            }
        }
        return result;
    }
};

int findMaximumXOR(vector<int>& nums) {
    BitTrie trie;
    for (int x : nums) trie.insert(x);

    int maxVal = 0;
    for (int x : nums)
        maxVal = max(maxVal, trie.maxXOR(x));
    return maxVal;
}
// Time: O(32·N) = O(N). Space: O(32·N) = O(N)
💡 want = 1 - bit — yeh trick opposite bit deta hai. XOR maximum karne ke liye hamesha opposite bit pe jaane ki koshish karo. O(N) brute force O(N²) se bahut better!
Problem 2 — Minimum XOR Pair
🔽
Minimum XOR PairPattern
🇬🇧 Intuition
Opposite of max XOR: for minimum XOR, greedily go to the same bit node (XOR=0 when bits match). If same bit doesn't exist → go opposite. This minimizes XOR.
🇮🇳 Hinglish
Max XOR ka ulta: minimum XOR ke liye, greedy jaao same bit node pe (XOR=0 jab bits match hoon). Same bit nahi hai toh opposite jaao. Isse XOR minimize hota hai.
🔵 C++ · Minimum XOR Query
int minXOR(int num) {
    auto cur = root;
    int result = 0;
    for (int i = 31; i >= 0; i--) {
        int bit = (num >> i) & 1;
        int want = bit;   // SAME bit chahiye → XOR=0 (min ke liye)

        if (cur->ch[want])
            cur = cur->ch[want];        // same bit → XOR bit = 0
        else {
            result |= (1 << i);        // opposite gaye → XOR bit = 1
            cur = cur->ch[1-want];
        }
    }
    return result;
}

// Max XOR: want = 1 - bit (opposite)  → XOR maximize
// Min XOR: want = bit     (same)      → XOR minimize
// Ek hi change! Want ka logic flip karo.
💡 Max XOR vs Min XOR: sirf ek line change hoti hai — want = 1 - bit (max) vs want = bit (min). Same template, same Bitwise Trie!
Max XOR querywant = 1 - bit
Opposite bit dhundo → XOR = 1 at each position
Min XOR querywant = bit
Same bit dhundo → XOR = 0 at each position

Common Mistakes
⚠️ Search vs StartsWith: Search mein isEnd check karna ZAROORI hai. StartsWith mein nahi. Yeh sabse common mistake hai LC 208 mein!
⚠️ Word Search II duplicate: Word milne ke baad node->end = false set karo — warna same word multiple baar result mein aayega.
⚠️ Bitwise Trie bit order: MSB se LSB insert karo (bit 31 to 0). Ulta kiya toh XOR greedy galat hoga!
⚠️ Memory: Trie space-heavy hai — O(N·L·26). Agar space constraint hai toh HashMap children use karo (unordered_map<char, TrieNode*>) — sparse hoga.
