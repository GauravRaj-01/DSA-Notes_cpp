Two Pointer

Do pointers use karke array traverse karo — nested loops ki zaroorat nahi. O(n²) → O(n).

O(n) time O(1) space Sorted Array Pair / Triplet
👆
Core Concept
🇬🇧 English
Two Pointer is a technique where we maintain two index variables — typically left and right — and move them based on conditions. This avoids the need for nested loops, reducing time complexity from O(n²) to O(n). It works best on sorted arrays or problems involving pairs/comparisons.
🇮🇳 Hinglish
Is technique mein hum do variables lete hain — left aur right. Conditions ke hisaab se inhe move karte hain. Iska fayda yeh hai ki hume har element ko har doosre element se compare nahi karna padta — ek hi pass mein kaam ho jaata hai. Sorted arrays mein yeh bahut powerful hota hai!
Brute Force (Nested Loops)
O(n²)
Har element ko har se compare karo
Two Pointer
O(n)
Ek hi pass, dono ends se
🔍
When to use? — Pehchaanoge kaise?
✅ Array sorted haiYa sorting se sort karna padega pehle. Sorted hone ka fayda utha sakte hain.
✅ Pair / Triplet dhundna haiSum equal to target, ya do numbers ka koi condition match karna ho.
✅ Palindrome / Reverse checkDono ends se ek saath compare karna ho to yahi pattern use hota hai.
✅ O(n²) → O(n) karna hoJab nested loop solution obvious lage, two pointer se optimize karo.
💡 Quick test: Kya array sorted hai? Kya pair/triplet dhundna hai? Haan toh → Two Pointer try karo!
Type 1 — Opposite Ends (Left + Right)
↔️
Two Sum II — Sorted Array LeetCode 167
Given a sorted array numbers[], find two indices (1-indexed) such that:
numbers[i] + numbers[j] == target
🇬🇧 Intuition
Since the array is sorted, we place left=0 and right=n-1.
• If sum > target → we need a smaller sum → move right-- (smaller numbers on left)
• If sum < target → we need a larger sum → move left++ (larger numbers on right)
• If sum == target → found it! Return indices.
🇮🇳 Hinglish Intuition
Array sorted hai toh iska fayda uthao!
• sum > target → sum chota karna hai → right-- karo (right pe bade numbers hain)
• sum < target → sum bada karna hai → left++ karo (left pe chhote numbers hain)
• sum == target → mil gaya! Return karo.

🔵 C++ · Two Sum II 
vector<int> twoSum(vector<int>& numbers, int target) {
    int l = 0, r = numbers.size() - 1;

    while (l < r) {                        // jab tak pointers cross na karein
        int sum = numbers[l] + numbers[r];

        if (sum == target)
            return {l + 1, r + 1};         // 1-indexed answer return karo
        else if (sum < target)
            l++;                              // sum chhota → left badhao
        else
            r--;                              // sum bada → right ghataao
    }
    return {-1, -1};
}
💡 Yeh array sorted hone par hi kaam karta hai. Unsorted array ke liye HashMap (Two Sum I) use karo.

Valid Palindrome LeetCode 125
Dono ends se characters compare karo. Non-alphanumeric skip karo. Mismatch mile toh false, warna loop ke end pe true return karo.
🔵 C++ · Valid Palindrome 
bool isPalindrome(string s) {
    int l = 0, r = s.size() - 1;
    while (l < r) {
        while (l < r && !isalnum(s[l])) l++;  // non-alphanumeric skip karo
        while (l < r && !isalnum(s[r])) r--;  // right se bhi skip
        if (tolower(s[l]) != tolower(s[r]))
            return false;                     // mismatch → palindrome nahi
        l++; r--;
    }
    return true;
}

Container With Most Water LeetCode 11
Chhoti line wale pointer ko move karo — badi line move karne se paani kabhi nahi badhega. Width bhi ghatti hai, toh chhoti height hi bottleneck hai.
🔵 C++ · Container With Most Water 
int maxArea(vector<int>& height) {
    int l = 0, r = height.size() - 1, maxWater = 0;
    while (l < r) {
        int water = min(height[l], height[r]) * (r - l); // area calculate karo
        maxWater = max(maxWater, water);
        if (height[l] < height[r]) l++;  // chhoti line ko move karo
        else r--;
    }
    return maxWater;
}

Three Sum LeetCode 15
Ek element fix karo (outer loop = i), baaki do ke liye two pointer lagao (l = i+1, r = n-1). Sort karna mandatory hai. Duplicates skip karna zaroori hai — warna same triplet baar baar aayega!
🔵 C++ · Three Sum 
vector<vector<int>> threeSum(vector<int>& nums) {
    sort(nums.begin(), nums.end());         // pehle sort karo — must!
    vector<vector<int>> result;

    for (int i = 0; i < nums.size(); i++) {
        if (i > 0 && nums[i] == nums[i - 1]) continue; // outer duplicate skip

        int l = i + 1, r = nums.size() - 1;
        while (l < r) {
            int sum = nums[i] + nums[l] + nums[r];
            if (sum == 0) {
                result.push_back({nums[i], nums[l], nums[r]});
                while (l < r && nums[l] == nums[l + 1]) l++; // dup skip
                while (l < r && nums[r] == nums[r - 1]) r--; // dup skip
                l++; r--;
            }
            else if (sum < 0) l++;  // sum chhota → left badhao
            else r--;               // sum bada → right ghataao
        }
    }
    return result;
}
⚠️ Three Sum mein sort + duplicate skip dono zaroori hain. Bhool gaye toh wrong answer aayega!
Type 2 — Same Direction (Fast & Slow)
⏩
Remove Duplicates from Sorted Array LeetCode 26
Slow pointer unique elements track karta hai. Fast pointer aage badhta jaata hai. Jab fast ko naya unique element mile, slow ko aage badhao aur wahan place karo.
🔵 C++ · Remove Duplicates 
int removeDuplicates(vector<int>& arr) {
    int slow = 0;
    for (int fast = 1; fast < arr.size(); fast++) {
        if (arr[fast] != arr[slow]) { // naya unique element mila
            slow++;
            arr[slow] = arr[fast];    // us jagah rakh do
        }
        // duplicate hai toh fast aage badhta rahe, slow rukta hai
    }
    return slow + 1;              // unique elements ki count
}
💡 Slow = "write position", Fast = "read position". Fast aage badhta hai, slow sirf unique milne par badhta hai.
Type 3 — Partition / Dutch National Flag
🚩
Sort Colors (Dutch National Flag) LeetCode 75
Teen pointers use karo — low, mid, high. 0 ko start mein, 2 ko end mein daalo. 1 apni jagah rehte hain. Single pass mein sort ho jaata hai!
🔵 C++ · Dutch National Flag 
void sortColors(vector<int>& nums) {
    int low = 0, mid = 0, high = nums.size() - 1;

    while (mid <= high) {
        if (nums[mid] == 0) {
            swap(nums[low++], nums[mid++]); // 0 ko front mein bhejo
        } else if (nums[mid] == 1) {
            mid++;                          // 1 sahi jagah hai, aage badho
        } else {
            swap(nums[mid], nums[high--]);  // 2 ko end mein bhejo
            // mid++ mat karo — naya element check karna hai
        }
    }
}
💡 Dutch Flag = low boundary (for 0s), mid = current, high boundary (for 2s). Ek pass mein teen sections ban jaate hain.
Array Patterns · Pattern 2 of 5

Sliding Window

Ek khidki (window) array pe khiskaate hain — right se add, left se remove. Subarray/substring problems ke liye perfect.

O(n) time O(1) or O(k) space Subarray / Substring
🪟
Core Concept
🇬🇧 English
Instead of recalculating from scratch each time, slide the window: add the new right element, remove the old left element. Two types: Fixed size (window size = k, constant) and Variable size (expand until condition fails, then shrink from left).
🇮🇳 Hinglish
Socho ek train ki khidki — jaise train aage badhti hai, scene change hota hai. Usi tarah window right mein badhti hai, naya element add hota hai, purana left se remove hota hai. Baar baar poori calculation nahi karni!

k = const
Size change nahi hoti
Variable Window
Expand-Shrink
Condition ke hisaab se size change

🔵 C++ · Max Sum of K Elements
int maxSumK(vector<int>& arr, int k) {
    int windowSum = 0;
    for (int i = 0; i < k; i++)
        windowSum += arr[i];     // pehli window ka sum banao

    int maxSum = windowSum;
    for (int i = k; i < arr.size(); i++) {
        windowSum += arr[i] - arr[i - k]; // right add, left remove
        maxSum = max(maxSum, windowSum);
    }
    return maxSum;
}
Type 2 — Variable Size (Expand-Shrink)
↔️
Longest Subarray with Sum ≤ kVariable
Right pointer se expand karo. Jab condition fail ho (sum > k), left se shrink karo jab tak condition valid na ho jaaye. Har step pe max length track karo.
🔵 C++ · Longest Subarray Sum ≤ k
int longestSubarray(vector<int>& arr, int k) {
    int l = 0, currSum = 0, maxLen = 0;
    for (int r = 0; r < arr.size(); r++) {
        currSum += arr[r];             // window expand karo (right se add)
        while (currSum > k) {          // condition fail → shrink karo
            currSum -= arr[l];
            l++;
        }
        maxLen = max(maxLen, r - l + 1);
    }
    return maxLen;
}
🔤
Longest Substring Without Repeating CharactersLeetCode 3
HashMap mein har character ki last position track karo. Jab duplicate mile, left pointer ko us character ke baad le jao. Window ka size = r - l + 1.
🔵 C++ · Longest Unique Substring
int lengthOfLongestSubstring(string s) {
    unordered_map<char, int> lastSeen;
    int l = 0, maxLen = 0;
    for (int r = 0; r < s.size(); r++) {
        if (lastSeen.count(s[r]) && lastSeen[s[r]] >= l)
            l = lastSeen[s[r]] + 1;   // duplicate mila → window shrink
        lastSeen[s[r]] = r;            // position update karo
        maxLen = max(maxLen, r - l + 1);
    }
    return maxLen;
}
🍊
Minimum Window SubstringLeetCode 76 · Hard
Pehle expand karo jab tak sab required characters na aa jaayein. Phir shrink karo minimum window ke liye. Need map se required characters track karo, have se current window mein kitne hain.
🔵 C++ · Minimum Window Substring
string minWindow(string s, string t) {
    unordered_map<char, int> need, have_map;
    for (char c : t) need[c]++;

    int have = 0, need_cnt = need.size();
    int l = 0, minLen = INT_MAX, start = 0;

    for (int r = 0; r < s.size(); r++) {
        have_map[s[r]]++;
        if (need.count(s[r]) && have_map[s[r]] == need[s[r]])
            have++;                           // ek aur char ki zaroorat poori hui

        while (have == need_cnt) {            // sab mil gaye → shrink karo
            if (r - l + 1 < minLen) {
                minLen = r - l + 1;
                start = l;
            }
            have_map[s[l]]--;
            if (need.count(s[l]) && have_map[s[l]] < need[s[l]])
                have--;                       // char remove kiya → condition fail
            l++;
        }
    }
    return minLen == INT_MAX ? "" : s.substr(start, minLen);
}
⚠️ Yeh Hard level problem hai. have == need_cnt tab hota hai jab t ke sab unique characters required frequency ke saath window mein aa jaayein.
💡 Sliding Window yaad rakho: Fixed → size fixed rakho. Variable → condition fail hone par left badhao (shrink). Expand-Shrink is the key idea!

Prefix Based

Pehle cumulative sum/XOR precompute karo. Phir kisi bhi range query O(1) mein nikaalo.

O(n) build O(1) query Range Queries
∑
Core Concept
🇬🇧 English
Pre-compute a prefix array where pre[i] stores the cumulative sum from index 0 to i-1. Then any range sum [l, r] = pre[r+1] - pre[l] in O(1). Combine with a HashMap to solve "subarray with sum = k" in O(n).
🇮🇳 Hinglish
Ek prefix array banao jisme har jagah tak ka cumulative sum hota hai. Phir kisi bhi range ka sum nikalna? Sirf do values ka difference — O(1) mein! HashMap ke saath combine karo toh "subarray with sum = k" bhi O(n) mein solve ho jaata hai.

🔵 C++ · Prefix Sum + Range Query
vector<int> buildPrefix(vector<int>& arr) {
    int n = arr.size();
    vector<int> pre(n + 1, 0);
    for (int i = 0; i < n; i++)
        pre[i + 1] = pre[i] + arr[i];  // cumulative sum banao
    return pre;
}

// Range [l, r] ka sum — O(1) query!
int rangeSum(vector<int>& pre, int l, int r) {
    return pre[r + 1] - pre[l];
}

// Subarray with sum == k (HashMap ke saath)
int subarraySum(vector<int>& nums, int k) {
    unordered_map<int, int> freq;
    freq[0] = 1;  // empty prefix ki count
    int count = 0, prefSum = 0;
    for (int num : nums) {
        prefSum += num;
        count += freq[prefSum - k]; // (prefSum - k) pehle mila tha?
        freq[prefSum]++;
    }
    return count;
}
💡 Prefix Sum + HashMap = "Subarray with sum = k" ka O(n) solution. Ek pass mein sab kuch!
Type 2 — Prefix XOR
⊕
Count Subarrays with XOR = kGFG / Amazon
XOR ka property: A⊕B = C toh A⊕C = B. Prefix XOR track karo. Agar prefXOR ⊕ k pehle mila tha toh ek valid subarray mila!
🔵 C++ · Subarrays with XOR = k
int countXorSubarrays(vector<int>& arr, int k) {
    unordered_map<int, int> freq;
    freq[0] = 1;     // XOR=0 start mein ek baar
    int count = 0, prefXor = 0;
    for (int num : arr) {
        prefXor ^= num;
        // agar (prefXor ^ k) pehle tha → subarray mila!
        count += freq[prefXor ^ k];
        freq[prefXor]++;
    }
    return count;
}
Type 3 — 2D Prefix Sum
⊞
2D Matrix Range Sum QueryLeetCode 304
2D matrix ka prefix sum banao. Kisi bhi rectangular region ka sum O(1) mein nikaalo — inclusion-exclusion principle use karo!
🔵 C++ · 2D Prefix Sum
class NumMatrix {
    vector<vector<int>> pre;
public:
    NumMatrix(vector<vector<int>>& matrix) {
        int m = matrix.size(), n = matrix[0].size();
        pre.assign(m + 1, vector<int>(n + 1, 0));
        for (int i = 1; i <= m; i++)
            for (int j = 1; j <= n; j++)
                pre[i][j] = matrix[i-1][j-1]
                           + pre[i-1][j] + pre[i][j-1]
                           - pre[i-1][j-1];  // overlap na double count ho
    }

    int sumRegion(int r1, int c1, int r2, int c2) {
        return pre[r2+1][c2+1]
             - pre[r1][c2+1]
             - pre[r2+1][c1]
             + pre[r1][c1];                 // inclusion-exclusion
    }
};
💡 2D Prefix = 1D ka extension. Build O(mn), Query O(1). Rectangle sum = bottom-right − top − left + top-left.
Array Patterns · Pattern 4 of 5

Kadane's / Subarray

Har index pe decide karo — purana subarray extend karun ya fresh start karun? Greedy + DP ka mix.

O(n) time O(1) space DP flavour
🧠
Core Concept
🇬🇧 English
At each index, make a local decision: extend the previous subarray (curr + arr[i]) OR start fresh (arr[i]). Take the max. Track the global max at every step. This single-pass O(n) approach is Kadane's algorithm.
🇮🇳 Hinglish
Har index pe ek simple sawaal: "Kya main purana subarray extend karun, ya naya shuru karun?" Agar purana carry karna faydemand hai toh extend karo, warna fresh start. Har step pe global max update karo. Yahi Kadane ka idea hai!

🔵 C++ · Kadane's Algorithm
int maxSubArray(vector<int>& nums) {
    int maxSum = nums[0], curr = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        curr = max(nums[i], curr + nums[i]); // extend ya fresh start?
        maxSum = max(maxSum, curr);          // global max update karo
    }
    return maxSum;
}

// Bonus: Subarray ka actual range bhi track karo
pair<int,int> maxSubarrayRange(vector<int>& nums) {
    int maxSum = nums[0], curr = nums[0];
    int start = 0, end = 0, tempStart = 0;
    for (int i = 1; i < nums.size(); i++) {
        if (nums[i] > curr + nums[i]) {
            curr = nums[i];
            tempStart = i;            // fresh start ki position save karo
        } else {
            curr += nums[i];
        }
        if (curr > maxSum) {
            maxSum = curr;
            start = tempStart;
            end = i;
        }
    }
    return {start, end};
}
💡 Kadane ka decision: curr = max(nums[i], curr + nums[i]). Agar curr negative hai aur nums[i] positive hai toh fresh start always better hai.

🔵 C++ · Max Product Subarray
int maxProduct(vector<int>& nums) {
    int maxP = nums[0], minP = nums[0], result = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        // negative × negative = positive → isliye minP bhi track karo!
        int tempMax = max({nums[i], maxP * nums[i], minP * nums[i]});
        minP        = min({nums[i], maxP * nums[i], minP * nums[i]});
        maxP = tempMax;
        result = max(result, maxP);
    }
    return result;
}
⚠️ tempMax pehle save karna zaroori hai! Agar seedha maxP update karo toh minP calculation mein galat value aayegi.

Binary Search

Search space ko har baar half karo. Sorted arrays ya monotonic conditions pe kaam karta hai.

O(log n) time O(1) space Sorted / Monotonic
🔍
Core Concept
🇬🇧 English
Binary Search eliminates half the search space each iteration. Works on sorted arrays (classic "on index") OR when you can define a monotonic condition — "if X is valid, X+1 is also valid" (search "on answer"). Always ask yourself: "Can I binary search the answer?"
🇮🇳 Hinglish
Har baar search space aadha karo. Sorted array mein element dhundna ho (on index), ya koi minimum/maximum answer range mein ho (on answer) — dono mein binary search kaam aata hai. Jab bhi "minimum valid X kya hai" type question ho — pehle binary search try karo!

🔵 C++ · Classic Binary Search
int binarySearch(vector<int>& arr, int target) {
    int l = 0, r = arr.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;  // overflow se bachne ka C++ trick
        if (arr[mid] == target)
            return mid;
        else if (arr[mid] < target)
            l = mid + 1;              // target right half mein hai
        else
            r = mid - 1;              // target left half mein hai
    }
    return -1;                     // nahi mila
}

// Lower Bound — pehla index jahan arr[i] >= target
int lowerBound(vector<int>& arr, int target) {
    int l = 0, r = arr.size();
    while (l < r) {
        int mid = l + (r - l) / 2;
        if (arr[mid] < target) l = mid + 1;
        else r = mid;
    }
    return l;
}
💡 Overflow trick: mid = l + (r-l)/2 use karo, (l+r)/2 nahi — bade numbers mein integer overflow ho sakta hai.

Search in Rotated Sorted ArrayLeetCode 33
Array rotated hai lekin binary search phir bhi chalega! Har step pe check karo — left half sorted hai ya right half? Sorted half mein target fit hota hai kya? Usi side jao.
🔵 C++ · Rotated Sorted Array Search
int search(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;

        if (nums[l] <= nums[mid]) {     // left half sorted hai
            if (nums[l] <= target && target < nums[mid])
                r = mid - 1;            // target left mein fit hota hai
            else
                l = mid + 1;
        } else {                         // right half sorted hai
            if (nums[mid] < target && target <= nums[r])
                l = mid + 1;            // target right mein fit hota hai
            else
                r = mid - 1;
        }
    }
    return -1;
}

Koko Eating Bananas — Min SpeedLeetCode 875
Answer ek range mein hai [1, max(piles)]. Check karo kya speed = mid mein Koko h hours mein finish kar sakti hai. Agar haan → speed aur kam bhi chal sakti hai (r=mid). Agar nahi → speed badhani padegi (l=mid+1).
🔵 C++ · Koko Eating Bananas
int minEatingSpeed(vector<int>& piles, int h) {
    int l = 1, r = *max_element(piles.begin(), piles.end());
    while (l < r) {
        int mid = l + (r - l) / 2;
        long long hours = 0;
        for (int p : piles)
            hours += (p + mid - 1) / mid; // ceil without float: (p+mid-1)/mid
        if (hours <= h)
            r = mid;    // yeh speed kaam karti hai, aur kam try karo
        else
            l = mid + 1; // speed bahut kam hai, badhao
    }
    return l;
}

Minimum Capacity to Ship PackagesLeetCode 1011
Same "on answer" pattern! Capacity ki range [max(weights), sum(weights)] hai. Check karo kya capacity = mid se sab packages D days mein ship ho sakte hain.
🔵 C++ · Ship Packages in D Days
int shipWithinDays(vector<int>& weights, int days) {
    int l = *max_element(weights.begin(), weights.end());
    int r = accumulate(weights.begin(), weights.end(), 0);

    while (l < r) {
        int mid = l + (r - l) / 2;
        int daysNeeded = 1, currLoad = 0;
        for (int w : weights) {
            if (currLoad + w > mid) {
                daysNeeded++;        // naya din shuru karo
                currLoad = 0;
            }
            currLoad += w;
        }
        if (daysNeeded <= days)
            r = mid;                 // capacity aur kam bhi chal sakti hai
        else
            l = mid + 1;           // capacity badhani padegi
    }
    return l;
}
💡 "On Answer" pattern pehchaan: Jab answer ek range mein ho + ek check function ho (valid/invalid) → binary search on that range! l=min_possible, r=max_possible.
