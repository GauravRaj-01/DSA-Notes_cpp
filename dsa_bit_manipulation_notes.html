Essential Bit Tricks — O(1) Operations
🔵 C++ · All Essential Bit Operations
int n = 13;  // 1101 in binary
int i = 1;   // bit position (0-indexed from right)

// ── SET bit i (make it 1) ──────────────────────
int set   = n | (1 << i);        // 1101 | 0010 = 1111 = 15

// ── CLEAR bit i (make it 0) ───────────────────
int clear = n & ~(1 << i);       // 1101 & 1101 = 1101 = 13 (bit 1 was 0)

// ── TOGGLE bit i (flip it) ────────────────────
int tog   = n ^ (1 << i);        // 1101 ^ 0010 = 1111 = 15

// ── CHECK if bit i is set ─────────────────────
bool isSet = (n >> i) & 1;       // shift right by i, check LSB
// OR: bool isSet2 = n & (1 << i);

// ── CLEAR lowest set bit ──────────────────────
int clrLow = n & (n - 1);        // 1101 & 1100 = 1100 = 12  ← Brian Kernighan!

// ── GET lowest set bit ────────────────────────
int lowBit = n & (-n);            // 1101 & 0011 = 0001 = 1  (rightmost 1)

// ── CHECK power of 2 ──────────────────────────
bool isPow2 = n > 0 && (n & (n-1)) == 0; // true if exactly one bit set

// ── COUNT set bits (popcount) ─────────────────
int cnt = __builtin_popcount(n);  // GCC built-in, O(1)

// ── MULTIPLY / DIVIDE by 2 ────────────────────
int mul2 = n << 1;               // n * 2
int div2 = n >> 1;               // n / 2 (floor)

// ── CHECK if ODD ──────────────────────────────
bool isOdd = n & 1;              // LSB = 1 means odd

⚡ XOR Pattern

XOR ka jaadu — same number XOR karoge toh 0 milega. Isse missing/unique numbers O(n) time, O(1) space mein dhundo!

XOR Properties — The Magic Rules
🔮
XOR ke 4 Magic Properties
🇬🇧 English
1. a ^ a = 0 — any number XOR itself = 0 (self-cancellation)
2. a ^ 0 = a — any number XOR 0 = itself (identity)
3. Commutative: a ^ b = b ^ a
4. Associative: (a ^ b) ^ c = a ^ (b ^ c)

Together: XOR all numbers → duplicates cancel out, unique remains!
🇮🇳 Hinglish
1. a ^ a = 0 — koi bhi number khud se XOR karo = 0 (cancel ho jaata hai)
2. a ^ 0 = a — koi bhi number 0 se XOR karo = wahi number
3. Commutative: a ^ b = b ^ a (order matter nahi karta)
4. Associative: grouping matter nahi karti

Matlab: sab numbers ka XOR karo → duplicates cancel, unique bacha rehta hai!
XOR all of [1,2,1,3,2] → only 3 remains
1^2^1^3^2
= (1^1) ^ (2^2) ^ 3 = 0 ^ 0 ^ 3
= 3 ✅
Problem 1 — Single Number
1️⃣
Single Number — Every element twice except oneLeetCode 136
🇬🇧 Intuition
Every element appears twice except one. Find it in O(n) time, O(1) space.
XOR all elements. Pairs cancel (a^a=0), lone number survives (x^0=x).
🇮🇳 Hinglish
Har element do baar aata hai except ek. O(n) time, O(1) space mein dhundo.
Sab elements ka XOR karo. Pairs cancel ho jaate hain, akela bacha rehta hai.
🔵 C++ · Single Number I, II, III
// LC 136 — Single Number (every element twice except one)
int singleNumber(vector<int>& nums) {
    int res = 0;
    for (int x : nums) res ^= x;  // pairs cancel out
    return res;
}

// LC 137 — Single Number II (every element 3x except one)
int singleNumberII(vector<int>& nums) {
    int ones = 0, twos = 0;
    for (int x : nums) {
        ones = (ones ^ x) & ~twos;
        twos = (twos ^ x) & ~ones;
    }
    return ones;
}

// LC 260 — Single Number III (two unique numbers)
vector<int> singleNumberIII(vector<int>& nums) {
    int xorAll = 0;
    for (int x : nums) xorAll ^= x;  // = a ^ b
    int diff = xorAll & (-xorAll);    // rightmost differing bit
    int a = 0;
    for (int x : nums)
        if (x & diff) a ^= x;          // split into two groups
    return {a, xorAll ^ a};
}

// LC 268 — Missing Number
int missingNumber(vector<int>& nums) {
    int res = nums.size(); // start with n
    for (int i = 0; i < nums.size(); i++)
        res ^= i ^ nums[i]; // XOR index and value together
    return res;
    // [0..n] indices ^ array values → pairs cancel, missing remains
}

Count Set Bits — Brian Kernighan's Algorithm
🔢
Count Set Bits (Popcount)LeetCode 191
🇬🇧 Intuition
Count how many 1-bits are in n.
Naive: Loop 32 times, check each bit — O(32).
Brian Kernighan: n = n & (n-1) removes lowest set bit each time. Loop runs only as many times as set bits — O(set bits count).
Built-in: __builtin_popcount(n) — O(1) in GCC.
🇮🇳 Hinglish
n mein kitne 1-bits hain count karo.
Naive: 32 baar loop, har bit check karo — O(32).
Brian Kernighan: n = n & (n-1) — har baar sabse chhota set bit remove hota hai. Loop sirf utni baar chalta hai jitne set bits hain.
Built-in: __builtin_popcount(n) — GCC mein O(1).
🔵 C++ · Count Bits — 3 Ways
// 1. Naive — O(32)
int countBitsNaive(int n) {
    int cnt = 0;
    while (n) { cnt += n & 1; n >>= 1; }
    return cnt;
}

// 2. Brian Kernighan — O(set bits) ← BEST
int countBitsKernighan(int n) {
    int cnt = 0;
    while (n) { n &= (n - 1); cnt++; }  // clears lowest set bit
    return cnt;
}

// 3. GCC Built-in — O(1)
int cnt = __builtin_popcount(n);

// LC 338 — Counting Bits (DP + bit trick)
vector<int> countBits(int n) {
    vector<int> dp(n+1);
    for (int i = 1; i <= n; i++)
        dp[i] = dp[i >> 1] + (i & 1); // dp[i] = dp[i/2] + LSB of i
    return dp;
}

🔵 C++ · Power of 2 / Reverse Bits / Hamming Distance
// LC 231 — Power of Two
bool isPowerOfTwo(int n) {
    return n > 0 && (n & (n-1)) == 0;
    // Power of 2 has exactly 1 set bit → n&(n-1) clears it → 0
}

// LC 190 — Reverse Bits
uint32_t reverseBits(uint32_t n) {
    uint32_t res = 0;
    for (int i = 0; i < 32; i++) {
        res = (res << 1) | (n & 1); // shift res left, add LSB of n
        n >>= 1;
    }
    return res;
}

// LC 461 — Hamming Distance
int hammingDistance(int x, int y) {
    return __builtin_popcount(x ^ y); // XOR → differing bits → count them
}
// Why XOR? Bits that differ become 1 in x^y. popcount counts those 1s.

🗂️ Subset via Bits

n elements ka har possible subset ek bitmask se represent hota hai. 0 to (2^n - 1) tak loop karo — sab subsets cover!

Enumerate All Subsets of a Set
🗂️
All Subsets using Bitmask
🇬🇧 Intuition
For n elements, there are 2^n subsets. Each subset maps to a bitmask from 0 to 2^n - 1.
Bit i in mask = 1 → element i is included in this subset.
Loop mask from 0 to (1<<n)-1. For each mask, check which bits are set.
🇮🇳 Hinglish
n elements ke liye 2^n subsets hote hain. Har subset ek bitmask se represent hota hai (0 se 2^n-1 tak).
Mask mein bit i = 1 → element i us subset mein hai.
Mask 0 se (1<<n)-1 tak loop karo. Har mask mein set bits check karo.
🔵 C++ · Print All Subsets
void printAllSubsets(vector<int>& arr) {
    int n = arr.size();
    for (int mask = 0; mask < (1 << n); mask++) {
        cout << "{ ";
        for (int i = 0; i < n; i++) {
            if (mask >> i & 1)      // is bit i set in mask?
                cout << arr[i] << " ";
        }
        cout << "}\n";
    }
}

Iterate Submasks of a Mask
🔽
Submask Enumeration — All subsets of a bitmask
🇬🇧 Intuition
Given a mask, iterate all its submasks (subsets of set bits).
Trick: Start with sub=mask. Each step: sub = (sub-1) & mask. Stop when sub=0.
Total iterations across all masks = 3^n (each element: in mask but not sub, in sub, not in mask).
Used in Bitmask DP problems (SOS DP, TSP).
🇮🇳 Hinglish
Ek mask ke sare submasks iterate karo (sirf woh bits jo mask mein hain).
Trick: sub=mask se shuru. Har step: sub = (sub-1) & mask. sub=0 par stop.
Sab masks ke total iterations = 3^n (har element teen options: mask mein but sub mein nahi, sub mein, mask mein hi nahi).
Bitmask DP mein use hota hai (SOS DP, TSP).
🔵 C++ · Enumerate All Submasks
// All submasks of 'mask'
for (int sub = mask; sub > 0; sub = (sub-1) & mask) {
    // process sub (submask of mask)
    // the loop also excludes empty mask; add 0 separately if needed
}

// All masks and all their submasks — O(3^n) total
for (int mask = 0; mask < (1<<n); mask++) {
    for (int sub = mask; sub > 0; sub = (sub-1) & mask) {
        // process (mask, sub) pair
    }
}

// SOS DP (Sum over Subsets) — prefix sum over bitmask
vector<int> dp(1<<n);
// init dp[mask] = value of mask
for (int i = 0; i < n; i++)
    for (int mask = 0; mask < (1<<n); mask++)
        if (mask >> i & 1)
            dp[mask] += dp[mask ^ (1<<i)]; // O(n × 2^n)

🔵 C++ · All Bit Check Tricks
int n = -7;

// ── ODD / EVEN ─────────────────────────────────
bool isOdd  = n & 1;           // LSB=1 → odd
bool isEven = !(n & 1);

// ── SIGN CHECK ────────────────────────────────
bool isNeg  = n >> 31;         // MSB=1 → negative (signed right shift)
bool isPos  = !(n >> 31) && n; // MSB=0 and not 0

// ── SAME SIGN CHECK ───────────────────────────
bool sameSign = !((n ^ m) >> 31); // XOR MSBs; if same sign → MSB=0

// ── ABSOLUTE VALUE (no branch) ────────────────
int mask2 = n >> 31;           // all 0s if positive, all 1s if negative
int absVal = (n + mask2) ^ mask2; // branchless abs

// ── MIN / MAX (no branch) ─────────────────────
int a = 5, b = 3;
int minVal = b + ((a-b) & ((a-b) >> 31));
int maxVal = a - ((a-b) & ((a-b) >> 31));

// ── MULTIPLY / DIVIDE by 2^k ──────────────────

// ── NEXT POWER OF 2 (≥ n) ────────────────────
int nextPow2(int n) {
    n--;
    n |= n >> 1; n |= n >> 2;
    n |= n >> 4; n |= n >> 8;
    n |= n >> 16;
    return n + 1;
}
XOR Swap — No temp variable
🔄
XOR Swap + Two's Complement
🇬🇧 English
XOR Swap: Swap two variables without a temp using XOR properties.
a = a^b, b = a^b (= (a^b)^b = a), a = a^b (= (a^b)^a = b).

Two's Complement: ~n + 1 = -n. So -n = ~n + 1 and ~n = -n - 1.
This is how negative numbers are stored in binary.
🇮🇳 Hinglish
XOR Swap: Temp variable ke bina do variables swap karo XOR use karke.
a = a^b, b = a^b (ab b = original a hai), a = a^b (ab a = original b hai).

Two's Complement: ~n + 1 = -n. Negative numbers aise hi binary mein store hote hain.
🔵 C++ · XOR Swap & Two's Complement
// XOR Swap (no temp) — works only when a != b address!
void xorSwap(int& a, int& b) {
    if (&a == &b) return;  // same variable? skip!
    a ^= b;  // a = a^b
    b ^= a;  // b = (a^b)^b = a
    a ^= b;  // a = (a^b)^a = b
}

// Two's complement: -n = ~n + 1
int n = 5;
int neg = ~n + 1;   // = -5
// 5  = 0101
// ~5 = 1010  (flip all bits)
// +1 = 1011  = -5 in two's complement ✅
⚠️ XOR Swap kabhi bhi same variable par mat karo! a=5; xorSwap(a,a) → a becomes 0 (a^a=0). Isliye &a==&b check zaruri hai.

🔗 Prefix XOR

Prefix sum ki tarah — prefix XOR array banao, phir kisi bhi subarray ka XOR O(1) mein nikalo. Range queries ke liye!

pre[i] = arr[0]^...^arr[i] XOR[l,r] = pre[r]^pre[l-1] O(n) build O(1) query
Prefix XOR — Concept
🔗
Prefix XOR Array
🇬🇧 English
Prefix XOR: pre[i] = arr[0] ^ arr[1] ^ ... ^ arr[i].
XOR of subarray [l, r] = pre[r] ^ pre[l-1].
Why? pre[r] = arr[0]^...^arr[r]. pre[l-1] = arr[0]^...^arr[l-1].
XORing them: arr[0..l-1] cancels out (same XOR twice = 0) → arr[l..r] remains!
Same idea as prefix sums but with XOR.
🇮🇳 Hinglish
Prefix XOR: pre[i] = arr[0] ^ arr[1] ^ ... ^ arr[i].
Subarray [l, r] ka XOR = pre[r] ^ pre[l-1].
Kyun? pre[r] mein arr[0..r] sab hain. pre[l-1] mein arr[0..l-1] hain.
Dono XOR karo: arr[0..l-1] cancel ho jaata hai (a^a=0) → sirf arr[l..r] bachta hai!
Bilkul prefix sum jaisi trick hai — bas + ki jagah ^ hai.

🔵 C++ · Prefix XOR Build & Query
vector<int> buildPrefixXOR(vector<int>& arr) {
    int n = arr.size();
    vector<int> pre(n+1, 0);  // pre[0]=0 (empty prefix)
    for (int i = 1; i <= n; i++)
        pre[i] = pre[i-1] ^ arr[i-1];
    return pre;
}

int queryXOR(vector<int>& pre, int l, int r) {
    return pre[r+1] ^ pre[l];   // 0-indexed l, r
}
Subarray XOR Problems
🎯
Count Subarrays with XOR = kLeetCode 1442 / Classic
🇬🇧 Intuition
Count subarrays whose XOR equals k.
XOR[l,r] = pre[r] ^ pre[l-1] = k → pre[l-1] = pre[r] ^ k.
Algorithm: Keep a frequency map of prefix XOR values seen so far.
For each r, count how many prev prefix XORs equal (current_prefix ^ k).
Exactly like "subarray sum = k" but with XOR and map!
🇮🇳 Hinglish
Jinke XOR = k hon aise subarrays count karo.
XOR[l,r] = pre[r] ^ pre[l-1] = k → pre[l-1] = pre[r] ^ k.
Algorithm: Prefix XOR values ka frequency map rakho.
Har r ke liye count karo kitne pehle ke prefix XOR = (current_prefix ^ k) hain.
Bilkul "subarray sum = k" jaisi trick hai — bas + ki jagah ^!
🔵 C++ · Count Subarrays with XOR = k
int countSubarraysXOR(vector<int>& arr, int k) {
    unordered_map<int,int> freq;
    freq[0] = 1;  // empty prefix XOR = 0
    int prefXOR = 0, count = 0;
    for (int x : arr) {
        prefXOR ^= x;
        count += freq[prefXOR ^ k]; // need pre[l-1] = prefXOR^k
        freq[prefXOR]++;
    }
    return count;
}
// Time: O(n), Space: O(n)

Common Bit Manipulation Mistakes
⚠️ Operator precedence trap! n & 1 == 0 → WRONG! == has higher priority than &. Write (n & 1) == 0 with parentheses. Always!
⚠️ Left shift overflow! 1 << 31 on int is undefined behavior. Use 1LL << 31 or 1u << 31 for large bit positions.
⚠️ Signed right shift! n >> k on negative numbers is implementation-defined in C (arithmetic shift on most compilers, but not guaranteed). Use unsigned or be careful.
⚠️ XOR swap on same variable! xorSwap(a, a) → a becomes 0. Always check &a != &b before XOR swapping.
