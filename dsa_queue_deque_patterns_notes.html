🚦 Queue / Deque — Basics

Queue = FIFO (First In First Out). Deque = Double Ended Queue — dono taraf se insert/delete. BFS ka backbone!

FIFO BFS backbone O(1) enqueue/dequeue
🚦
Queue kya hai?
🇬🇧 English
A Queue is a linear data structure that follows FIFO — First In, First Out. Like a real-life queue (line). Elements are added at the back and removed from the front.
Key operations: enqueue (push), dequeue (pop), front/peek — all O(1).
🇮🇳 Hinglish
Queue ek line ki tarah hai — FIFO (pehle aaya, pehle gaya). Jaise movie ticket line mein pehla banda pehle andar jaata hai. Elements back se daalo aur front se nikalo.
Key operations: enqueue (daalo), dequeue (nikalo), front (dekho) — sab O(1).

Deque — Double Ended Queue
↔️
Deque vs Queue
🇬🇧 English
A Deque (Double Ended Queue) allows insert and delete from both front and back — O(1). It's a superset of both Queue and Stack. Used in sliding window problems, monotonic deque, and palindrome checking.
🇮🇳 Hinglish
Deque mein dono taraf se (front aur back) insert aur delete O(1) mein hota hai. Queue aur Stack dono ka superset hai. Sliding window maximum, monotonic deque aur palindrome check mein use hota hai.

🔄 FIFO Processing

Queue ka core use — BFS (Breadth First Search). Grid problems, shortest path, multi-source BFS.

BFS = Queue Shortest path Multi-source BFS
🔄
Core Concept — FIFO / BFS
🇬🇧 English
BFS uses a queue to process nodes level by level. All nodes at distance 1 first, then distance 2, etc. This guarantees the shortest path in an unweighted graph/grid.
Multi-source BFS: enqueue ALL starting nodes simultaneously. BFS from multiple sources at once — used in Rotten Oranges, Walls & Gates.
🇮🇳 Hinglish
BFS queue use karke nodes ko level by level process karta hai. Pehle distance 1 wale, phir 2, etc. Unweighted graph/grid mein shortest path guarantee karta hai.
Multi-source BFS: saare starting nodes ek saath queue mein daalo. Ek hi BFS se multiple sources simultaneously process — Rotten Oranges, Walls & Gates mein use hota hai.

Rotten OrangesLeetCode 994
🇬🇧 Intuition
Multi-source BFS: First enqueue ALL rotten oranges (value=2) into the queue. Each minute, spread rot to all 4 neighbors. Count minutes = BFS levels. If any fresh orange remains → return -1.

🔵 C++ · Rotten Oranges (Multi-Source BFS)
int orangesRotting(vector<vector<int>>& grid) {
    int m = grid.size(), n = grid[0].size();
    queue<pair<int,int>> q;
    int fresh = 0, minutes = 0;

    // Step 1: Saare rotten enqueue karo + fresh count karo
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 2) q.push({i, j});
            if (grid[i][j] == 1) fresh++;
        }

    int dirs[4][2] = {{0,1},{0,-1},{1,0},{-1,0}};

    // Step 2: Multi-source BFS — level by level
    while (!q.empty() && fresh > 0) {
        int sz = q.size();           // current level size
        for (int k = 0; k < sz; k++) {
            auto [r, c] = q.front(); q.pop();
            for (auto& d : dirs) {
                int nr = r+d[0], nc = c+d[1];
                if (nr>=0 && nr<m && nc>=0 && nc<n && grid[nr][nc]==1) {
                    grid[nr][nc] = 2;   // rot spread karo
                    fresh--;
                    q.push({nr, nc});
                }
            }
        }
        minutes++;
    }
    return fresh == 0 ? minutes : -1;
}
💡 Level size sz = q.size() snapshot lena CRITICAL hai — usi level ke nodes process karo, naye wale next level ke hain. Yahi BFS level tracking ka trick hai!
Problem 2 — Walls & Gates (Multi-Source BFS)
🚪
Walls & GatesLeetCode 286
🇬🇧 Intuition
Fill each empty room with the distance to its nearest gate. Enqueue ALL gates (value=0) simultaneously. BFS naturally fills minimum distances level by level. Walls (value=-1) are skipped.
🇮🇳 Hinglish
Har empty room ko nearest gate ki distance se fill karo. Saare gates (value=0) ek saath queue mein daalo. BFS automatically minimum distances level by level fill karta hai. Walls (-1) skip karo.
🔵 C++ · Walls & Gates
void wallsAndGates(vector<vector<int>>& rooms) {
    int m = rooms.size(), n = rooms[0].size();
    const int INF = 2147483647;
    queue<pair<int,int>> q;

    // Saare gates queue mein daalo
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (rooms[i][j] == 0) q.push({i, j});

    int dirs[4][2] = {{0,1},{0,-1},{1,0},{-1,0}};
    while (!q.empty()) {
        auto [r, c] = q.front(); q.pop();
        for (auto& d : dirs) {
            int nr = r+d[0], nc = c+d[1];
            if (nr>=0 && nr<m && nc>=0 && nc<n && rooms[nr][nc]==INF) {
                rooms[nr][nc] = rooms[r][c] + 1; // distance update
                q.push({nr, nc});
            }
        }
    }
}
💡 Multi-source BFS = saare sources ek saath queue mein. BFS ki property: pehli baar kisi cell pe pahuncho → wo minimum distance hai. Dobara visit ki zaroorat nahi!
Problem 3 — Snakes and Ladders
🐍
Snakes & LaddersLeetCode 909
🇬🇧 Intuition
Minimum moves = BFS on a graph where nodes are board positions 1..n². From each cell, roll dice (1–6) → reach 6 neighbors. If snake/ladder exists at destination → jump. BFS level = number of moves.
🇮🇳 Hinglish
Minimum moves = BFS. Nodes = board positions 1..n². Har cell se dice roll karo (1–6) → 6 neighbors. Destination pe snake/ladder hai → jump karo. BFS level = moves count. Shortest path guaranteed!
🔵 C++ · Snakes & Ladders (BFS)
int snakesAndLadders(vector<vector<int>>& board) {
    int n = board.size();

    // Cell number (1-indexed) → {row, col} converter
    auto getPos = [&](int cell) -> pair<int,int> {
        cell--;  // 0-indexed
        int row = n - 1 - cell / n;   // bottom se upar
        int col = (cell / n % 2 == 0) ? cell % n : n - 1 - cell % n;
        return {row, col};
    };

    vector<bool> visited(n*n+1, false);
    queue<int> q;
    q.push(1); visited[1] = true;
    int moves = 0;

    while (!q.empty()) {
        int sz = q.size();
        while (sz--) {
            int cell = q.front(); q.pop();
            if (cell == n*n) return moves;

            for (int dice = 1; dice <= 6 && cell+dice <= n*n; dice++) {
                auto [r, c] = getPos(cell + dice);
                int next = (board[r][c] != -1) ? board[r][c] : cell+dice;
                if (!visited[next]) {
                    visited[next] = true;
                    q.push(next);
                }
            }
        }
        moves++;
    }
    return -1;
}
💡 Board → graph conversion: cell number 1..n² ko grid coordinate mein convert karo. Bottom-left se shuru, alternating direction (boustrophedon). BFS se minimum moves guaranteed!

🌳 Level-wise Processing

Binary tree ko level by level process karo — BFS + queue. Level order, zigzag, right view sab isi se.

Tree BFS Level snapshot sz = q.size() trick
🌳
Core Concept — Level Snapshot Trick
🇬🇧 English
Key trick: int sz = q.size() before processing each level. Loop exactly sz times → processes all nodes of current level. New children added during this loop belong to next level. This separates levels cleanly.
🇮🇳 Hinglish
Key trick: har level process karne se pehle int sz = q.size() snapshot lo. Exactly sz baar loop chalao → current level ke saare nodes process ho jaate hain. Is loop mein add hone wale children next level ke hain. Levels cleanly separate ho jaate hain!

🔵 C++ · Level Order Traversal
vector<vector<int>> levelOrder(TreeNode* root) {
    if (!root) return {};
    vector<vector<int>> result;
    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int sz = q.size();           // ← Level snapshot!
        vector<int> level;

        for (int i = 0; i < sz; i++) {
            TreeNode* node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back(level);      // ek level complete
    }
    return result;
}
💡 Yeh template bahut powerful hai — Level Order ke sab variants isi se bante hain. Bas andar kya karna hai woh change karo!
Problem 2 — Zigzag Level Order
⚡
Zigzag Level OrderLeetCode 103
🇬🇧 Intuition
Same as Level Order but alternate direction each level. Use a boolean leftToRight flag. When false, reverse the level vector before adding to result. OR use a deque per level — add to front when going right-to-left.
🇮🇳 Hinglish
Level Order jaisa hi — but har level ki direction alternate karo. Boolean leftToRight flag use karo. False hone par level vector reverse karo. Ya level ke liye deque use karo — right-to-left mein front pe add karo.
🔵 C++ · Zigzag Level Order
vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
    if (!root) return {};
    vector<vector<int>> result;
    queue<TreeNode*> q;
    q.push(root);
    bool leftToRight = true;

    while (!q.empty()) {
        int sz = q.size();
        deque<int> level;  // deque for flexible insertion

        for (int i = 0; i < sz; i++) {
            TreeNode* node = q.front(); q.pop();
            if (leftToRight)
                level.push_back(node->val);   // L→R: back mein
            else
                level.push_front(node->val);  // R→L: front mein
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        result.push_back({level.begin(), level.end()});
        leftToRight = !leftToRight;  // direction flip!
    }
    return result;
}
💡 Deque ka use level ke andar karo — push_front se right-to-left automatically ho jaata hai. BFS queue alag hai, level deque alag — confuse mat hona!
Problem 3 — Binary Tree Right Side View
👁️
Right Side ViewLeetCode 199
🇬🇧 Intuition
Level Order traversal — just pick the last element of each level. That's the rightmost node visible from the right side. One-line addition to the level order template.
🇮🇳 Hinglish
Level Order karo — bas har level ka last element result mein lo. Wahi right side se visible hota hai. Level order template mein sirf ek line ka change!
🔵 C++ · Right Side View
vector<int> rightSideView(TreeNode* root) {
    if (!root) return {};
    vector<int> result;
    queue<TreeNode*> q;
    q.push(root);

    while (!q.empty()) {
        int sz = q.size();
        for (int i = 0; i < sz; i++) {
            TreeNode* node = q.front(); q.pop();
            if (i == sz - 1)               // ← last node of level!
                result.push_back(node->val);
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
    }
    return result;
}

// Left Side View: i == 0 → first node of each level
// Max per Level: track max in inner loop
// Average per Level: sum/sz in inner loop
💡 Level Order template bahut versatile hai — sirf inner loop ke andar change karo: last element (right view), first element (left view), max/min/avg (various problems).

🔁 Circular Queue Pattern

Fixed-size queue jahan last position ke baad wapas first position pe aao — modular arithmetic use karta hai.

Modulo trick Fixed capacity O(1) all ops
🔁
Core Concept — Circular Queue
🇬🇧 English
A circular queue reuses empty space at the front. Use two pointers head and tail, and count to track size. Advance pointers using modulo: (ptr + 1) % capacity. This "wraps around" the array.
🇮🇳 Hinglish
Circular queue front ki khali jagah reuse karti hai. head, tail pointers aur count use karo. Pointer advance karne ke liye modulo: (ptr + 1) % capacity. Array ke end ke baad automatically start pe wapas aa jaata hai!

Problem 1 — Design Circular Queue
⚙️
Design Circular QueueLeetCode 622
🔵 C++ · Circular Queue Implementation
class MyCircularQueue {
    vector<int> data;
    int head, tail, count, cap;
public:
    MyCircularQueue(int k) : data(k), head(0), tail(-1), count(0), cap(k) {}

    bool enQueue(int val) {
        if (isFull()) return false;
        tail = (tail + 1) % cap;  // modulo wrap!
        data[tail] = val;
        count++;
        return true;
    }

    bool deQueue() {
        if (isEmpty()) return false;
        head = (head + 1) % cap;  // modulo wrap!
        count--;
        return true;
    }

    int  Front()   { return isEmpty() ? -1 : data[head]; }
    int  Rear()    { return isEmpty() ? -1 : data[tail]; }
    bool isEmpty() { return count == 0; }
    bool isFull()  { return count == cap; }
};
// Trick: Full/Empty distinguish → count variable use karo
// (head == tail+1 se dono cases same dikhte hain — confusing!)
💡 Full aur Empty dono mein head == (tail+1)%cap ho sakta hai — isliye alag count variable rakhna best practice hai!
Problem 2 — Hit Counter (Circular Queue Application)
🎯
Hit CounterLeetCode 362
🇬🇧 Intuition
Count hits in the last 300 seconds. Use a circular array of size 300. For each second slot: store hit count. When querying, sum up valid slots (within 300 second window). Old data automatically overwritten.
🇮🇳 Hinglish
Last 300 seconds mein hits count karo. Size 300 ka circular array use karo. Har second slot mein hit count store karo. Query karte waqt valid slots (300 second window ke andar) sum karo. Purana data automatically overwrite ho jaata hai!
🔵 C++ · Hit Counter
class HitCounter {
    int times[300] = {}, hits[300] = {};
public:
    void hit(int timestamp) {
        int idx = timestamp % 300;     // circular slot
        if (times[idx] != timestamp) { // naya timestamp → reset
            times[idx] = timestamp;
            hits[idx] = 0;
        }
        hits[idx]++;
    }

    int getHits(int timestamp) {
        int total = 0;
        for (int i = 0; i < 300; i++)
            // Sirf valid window ke hits count karo
            if (timestamp - times[i] < 300)
                total += hits[i];
        return total;
    }
};
💡 timestamp % 300 circular array index deta hai. Same slot pe purana data automatically overwrite hota hai. O(300) = O(1) effectively!
Queue/Deque · Pattern 4 of 4

↔️ Deque Based

Sliding window ke saath deque — window ka max/min O(n) mein nikalo. Monotonic deque ka magic!

Monotonic Deque O(n) overall Sliding Window Max
📐
Core Concept — Monotonic Deque
🇬🇧 English
A Monotonic Deque maintains elements in decreasing (or increasing) order. For sliding window maximum:
1. Remove elements from back that are smaller than current (they can never be max)
2. Remove elements from front that are outside the window
3. Front always = current window's maximum!
Each element is pushed/popped at most once → O(n) total.
🇮🇳 Hinglish
Monotonic Deque mein elements decreasing (ya increasing) order mein hote hain. Sliding window maximum ke liye:
1. Back se woh elements hatao jo current se chhote hain (woh kabhi max nahi ban sakte)
2. Front se woh elements hatao jo window se bahar ho gaye
3. Front hamesha = current window ka maximum!
Har element zyada se zyada ek baar push/pop hota hai → O(n) total.

🔵 C++ · Sliding Window Maximum (Monotonic Deque)
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    deque<int> dq;   // stores INDICES, decreasing value order
    vector<int> result;

    for (int i = 0; i < nums.size(); i++) {
        // Step 1: Back se smaller elements hatao
        while (!dq.empty() && nums[dq.back()] <= nums[i])
            dq.pop_back();

        dq.push_back(i);  // current index add

        // Step 2: Front se out-of-window elements hatao
        if (dq.front() <= i - k)
            dq.pop_front();

        // Step 3: Window complete hote hi max record karo
        if (i >= k - 1)
            result.push_back(nums[dq.front()]); // front = max!
    }
    return result;
}
// Time: O(n) — har element zyada se zyada ek push + ek pop
// Space: O(k) — deque mein zyada se zyada k elements
💡 Deque mein values nahi, indices store karo! Isse window check (front <= i-k) easy ho jaata hai. Front hamesha current window ka max index hai.
⚠️ Back se pop karte waqt <= use karo — equal values pe bhi pop karo warna duplicate maxes aa sakte hain.

🔵 C++ · First Negative in Every Window of Size K
vector<int> firstNegInWindow(vector<int>& arr, int k) {
    deque<int> dq;  // negative elements ke indices
    vector<int> result;
    int n = arr.size();

    for (int i = 0; i < n; i++) {
        // Front: window se bahar nikla?
        if (!dq.empty() && dq.front() <= i - k)
            dq.pop_front();

        // Negative hai toh deque mein daalo
        if (arr[i] < 0)
            dq.push_back(i);

        // Window complete hone ke baad result add karo
        if (i >= k - 1)
            result.push_back(dq.empty() ? 0 : arr[dq.front()]);
    }
    return result;
}
💡 Yahan deque mein sirf negative indices store hote hain — window max jaisa hi pattern hai but condition alag hai. Deque ka front = first (leftmost) negative in window.

Common Mistakes
⚠️ Level Order: sz = q.size() snapshot lena mat bhoolo! Agar directly q.size() loop condition mein use karo toh naye children bhi same level mein process ho jaate hain.
⚠️ Multi-source BFS: Saare sources ek saath enqueue karo initialization mein — ek ek karke nahi. Warna distances wrong honge.
⚠️ Monotonic Deque: Values nahi, indices store karo. Values se out-of-window check impossible hai.
⚠️ Circular Queue: Full aur empty dono mein head == (tail+1)%cap ho sakta hai — alag count variable rakhna best practice hai confusion avoid karne ke liye.
💡 BFS vs DFS: Shortest path → BFS (queue). Explore all paths → DFS (stack/recursion). "Minimum steps/distance" wale problems mein hamesha BFS prefer karo!
